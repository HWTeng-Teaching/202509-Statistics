## 題目

使用練習 1-2 (練習 1 和 3, 12.2 節) 中給定的資訊，構建一個簡單線性迴歸分析的 **ANOVA 表**。

1.  **n = 8** 對 $(x, y)$ 觀測值， $S_{xx} = 4$, $S_{yy} = 20$, $S_{xy} = 8$。

**要求：**
1.  使用 ANOVA F 檢定，在 $\alpha = .05$ 的顯著水準下，檢驗虛無假設 $H_0: \beta = 0$。

2.  計算迴歸係數 $b$ 及其標準誤 (standard error)。

3.  使用 $t$ 統計量，在 $\alpha = .05$ 的顯著水準下，檢驗虛無假設 $H_0: \beta = 0$。

4.  驗證在捨入誤差內 $t^2 = F$。

---

## 解答

### 1. 計算必要的迴歸統計量

給定：
* 樣本數 $n = 8$

* $S_{xx} = \sum (x_i - \bar{x})^2 = 4$

* $S_{yy} = \sum (y_i - \bar{y})^2 = 20$

* $S_{xy} = \sum (x_i - \bar{x})(y_i - \bar{y}) = 8$

#### a. 計算斜率 $b$

斜率 $b$ 的計算公式為：

$$b = \frac{S_{xy}}{S_{xx}}$$

$$b = \frac{8}{4} = 2$$

#### b. 計算 ANOVA 所需的平方和 (Sum of Squares, SS)

**總平方和 (SST):**

$$SST = S_{yy} = 20$$

**迴歸平方和 (SSR):**

$$SSR = b \cdot S_{xy}$$

$$SSR = 2 \cdot 8 = 16$$

**殘差平方和 (SSE):**

$$SSE = SST - SSR$$

$$SSE = 20 - 16 = 4$$

### 2. 構建 ANOVA 表格

| 變異來源 (Source) | 自由度 (df) | 平方和 (SS) | 均方 (MS) | F 統計量 (F) |
| :--- | :--- | :--- | :--- | :--- |
| **迴歸 (Regression)** | $df_R = 1$ | $SSR = 16$ | $MSR = SSR/df_R = 16/1 = 16$ | $F = MSR/MSE = 16/0.667 = 23.88$ |
| **殘差 (Error)** | $df_E = n-2 = 6$ | $SSE = 4$ | $MSE = SSE/df_E = 4/6 \approx 0.6667$ | |
| **總和 (Total)** | $df_T = n-1 = 7$ | $SST = 20$ | | |

#### 檢定 $H_0: \beta = 0$ (使用 F 檢定)

* **F 統計量**：$F = 23.88$

* **臨界值/P 值**：對於 $df_1=1, df_2=6$ 且 $\alpha = 0.05$，$F_{0.05, 1, 6} = 5.987$。

* **結論**：由於 $F = 23.88 > 5.987$，我們 **拒絕 $H_0$**。有足夠證據顯示斜率 $\beta$ 不為零，即 $x$ 與 $y$ 之間存在線性關係。

### 3. 計算 $b$ 的標準誤並進行 $t$ 檢定

#### a. 估計變異數 $\sigma^2$ (Mean Square Error)

從 ANOVA 表可知：

$$\hat{\sigma}^2 = MSE = 0.6667$$

#### b. 計算 $b$ 的標準誤 $s_b$

$$s_b = \sqrt{\frac{MSE}{S_{xx}}}$$

$$s_b = \sqrt{\frac{0.6667}{4}} = \sqrt{0.16667} \approx 0.40825$$

**迴歸係數 $b$ 及其標準誤：**

$$b = 2$$

$$s_b \approx 0.40825$$

#### c. $t$ 統計量檢定 $H_0: \beta = 0$
$$t = \frac{b - 0}{s_b}$$
$$t = \frac{2}{0.40825} \approx 4.8989$$

* **臨界值/P 值**：對於 $df = n-2 = 6$ 且 $\alpha = 0.05$ (雙尾)， $t_{0.025, 6} = 2.447$。
* **結論**：由於 $|t| = 4.8989 > 2.447$，我們 **拒絕 $H_0$**。結論與 F 檢定一致。

### 4. 驗證 $t^2 = F$

$$t^2 = (4.8989)^2 \approx 24.00$$
$$F = 32$$

**重要註記：** 這裡存在一個捨入誤差的累積。讓我們使用精確的分數值：

* $MSE = 4/6 = 2/3$

* $s_b = \sqrt{\frac{2/3}{4}} = \sqrt{\frac{2}{12}} = \sqrt{\frac{1}{6}}$

* $t = \frac{2}{\sqrt{1/6}} = 2\sqrt{6} \approx 4.898979$

**精確驗證：**

$$t^2 = (2\sqrt{6})^2 = 4 \cdot 6 = 24$$

$$F = 24$$
