# 題目 關於手機 (Cell Phones)
怎麼去定義多小的年紀，而不該擁有手機呢?

針對一群八年級的男生與女生進行調查，詢問他們是否擁有手機，結果如下：

|Item|有手機 (Cell Phone)|沒有手機 (No Cell Phone)|
|-----|------------------|-----------------------|
|男孩 Boys |52|48|
|女孩 Girls|55|45|

# Answer  ( c ) 說明相似處與不同之處

結論 

男女生都有約一半以上擁有手機，比例很接近。

男生擁有手機的比例：52/100=52%

女生擁有手機的比例：55/100=55%

總體來說，男女在手機持有狀況上非常相似，但女生略高於男生。
