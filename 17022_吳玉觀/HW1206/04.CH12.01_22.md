### **📝 答案卷格式**

#### **a. Scatterplot & Relationship**

**散佈圖描述：**
- The scatterplot shows a **strong positive linear relationship** between armspan and height
- As armspan increases, height tends to increase
- Correlation coefficient: r ≈ 0.84 (strong positive correlation)
- Points cluster closely around a line with positive slope

---

#### **b. Expected Slope (da Vinci's Claim)**

**Answer:** If da Vinci is correct and armspan equals height, then:
```
Height = Armspan
ŷ = x
```
**The slope should be b = 1**

---

#### **c. Calculate Regression Line**

**計算 slope b:**
```
b = [nΣxy - (Σx)(Σy)] / [nΣx² - (Σx)²]
  = [8(221414) - (1328)(1331)] / [8(221016) - (1328)²]
  = [1771312 - 1767968] / [1768128 - 1763584]
  = 3344 / 4544
  = 0.736
```

**計算 intercept a:**
```
a = ȳ - bx̄
  = 166.375 - 0.736(166)
  = 166.375 - 122.176
  = 44.20
```

**Regression Equation:**
```
ŷ = 44.20 + 0.736x
```

**結論：** The slope b = 0.736 is **less than 1**, which suggests that da Vinci's claim is **not fully confirmed**. While there is a strong positive relationship, armspan does not exactly equal height (slope ≠ 1).

---

#### **d. Prediction for Armspan = 157 cm**
```
ŷ = 44.20 + 0.736(157)
  = 44.20 + 115.55
  = 159.75 ≈ 160 cm
```

**Answer:** A person with an armspan of 157 cm would be predicted to have a height of approximately **160 centimeters**.
