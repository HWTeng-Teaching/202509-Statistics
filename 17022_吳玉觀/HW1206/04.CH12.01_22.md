## b. 預期斜率

如果達文西的說法正確，臂展等於身高，則迴歸線應為 ŷ = x。

**答案：斜率應為 b = 1**

---

## c. 計算迴歸線

### 斜率計算
```
b = [nΣxy - (Σx)(Σy)] / [nΣx² - (Σx)²]
  = [8(221414) - (1328)(1331)] / [8(221016) - (1328)²]
  = [1771312 - 1767968] / [1768128 - 1763584]
  = 3344 / 4544
  = 0.736
```

### 截距計算
```
a = ȳ - bx̄
  = 166.375 - 0.736(166)
  = 44.20
```

### 迴歸方程式
```
ŷ = 44.20 + 0.736x
```

### 斜率是否驗證 b 部分？

否。斜率 b = 0.736 不等於 1，因此數據不支持達文西的說法（臂展等於身高）。

---

## d. 預測臂展 = 157 cm 的身高
```
ŷ = 44.20 + 0.736(157)
  = 44.20 + 115.55
  = 159.75
```

**答案：約 160 公分**
