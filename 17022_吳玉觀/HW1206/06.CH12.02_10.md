# 第10題：Body Mass Index (BMI vs Income)

## 基本數據
```
n = 6
Income (x): 15, 20.5, 30, 40, 60, 75
BMI (y): 31.2, 29.3, 27.4, 27.3, 26.8, 20.0
```

---

## a. 確認自變數與應變數

**答案：**
- **自變數 (Independent variable, x):** Income (收入)
- **應變數 (Dependent variable, y):** BMI

---

## b. 最小平方迴歸線

### 計算基本統計量
```
Σx = 240.5, x̄ = 40.083
Σy = 162.0, ȳ = 27.0
Σx² = 12370.25
Σy² = 4446.22
Σxy = 6090.65
```

### 計算斜率與截距

**斜率：**
```
b = [nΣxy - (Σx)(Σy)] / [nΣx² - (Σx)²]
  = [6(6090.65) - (240.5)(162)] / [6(12370.25) - (240.5)²]
  = [36543.9 - 38961] / [74221.5 - 57840.25]
  = -2417.1 / 16381.25
  = -0.148
```

**截距：**
```
a = ȳ - bx̄
  = 27.0 - (-0.148)(40.083)
  = 27.0 + 5.93
  = 32.93
```

**最小平方迴歸線：**
```
ŷ = 32.93 - 0.148x
```

---

## c. ANOVA Table

### 計算 SS

**Total SS:**
```
SST = Σ(y - ȳ)² = 72.22
```

**Regression SS:**
```
SSR = b²·Sxx
Sxx = Σx² - (Σx)²/n = 12370.25 - 9640.04 = 2730.21
SSR = (-0.148)² × 2730.21 = 59.76
```

**Error SS:**
```
SSE = SST - SSR = 72.22 - 59.76 = 12.46
```
