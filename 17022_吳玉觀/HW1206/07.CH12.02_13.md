# 第13題：Sleep Deprivation (線性迴歸分析)

## 基本數據
```
n = 10
x (Hours without sleep): 8, 8, 12, 12, 16, 16, 20, 20, 24, 24
y (Number of errors): 8, 6, 6, 10, 8, 14, 14, 12, 16, 12
```

---

## a. 觀測值對數

**答案：10 pairs**（10對觀測值）

---

## b. 總自由度
```
Total df = n - 1 = 10 - 1 = 9
```

**答案：9**

---

## c. 完成 MS Excel Printout

### ANOVA Table

| Source     | df | SS    | MS    | F      | Significance F |
|------------|---:|------:|------:|-------:|---------------:|
| Regression |  1 | 72.2  | 72.2  | 14.368 | 0.0053        |
| Residual   |  8 | 40.2  | 5.025 |        |               |
| Total      |  9 | 112.4 |       |        |               |

### Coefficients Table

| Coefficients | Value | Standard Error | t Stat | P-value |
|--------------|------:|---------------:|-------:|--------:|
| Intercept    | 3.000 | 2.127          | 1.411  | 0.1960  |
| x            | 0.475 | 0.125          | 3.791  | 0.0053  |

### 計算過程
```
Regression df = 1
Residual df = Total df - Regression df = 9 - 1 = 8
Total df = 9

Residual SS = Residual MS × Residual df = 5.025 × 8 = 40.2
Total SS = Regression SS + Residual SS = 72.2 + 40.2 = 112.4
```

---

## d. 最小平方預測方程式

從 Coefficients Table 可得：
```
ŷ = 3 + 0.475x
```

**答案：ŷ = 3 + 0.475x**

---

## e. 預測未睡眠10小時的錯誤數
```
ŷ = 3 + 0.475(10)
  = 3 + 4.75
  = 7.75
```

**答案：約 7.75 或 8 個錯誤**
