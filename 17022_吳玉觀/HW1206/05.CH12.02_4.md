# 第4題：ANOVA Table for Simple Linear Regression

## 基本資訊
```
n = 20 (因為 Total df = 19, n-1 = 19)
Total SS = 12.5
Regression SS = 4.3
```

---

## 計算步驟

### 1. 計算 df (自由度)
```
Regression df = 1 (簡單線性迴歸永遠是1)
Total df = n - 1 = 20 - 1 = 19 ✓
Error df = Total df - Regression df = 19 - 1 = 18
```

### 2. 計算 SS (平方和)
```
Total SS = Regression SS + Error SS
12.5 = 4.3 + Error SS
Error SS = 12.5 - 4.3 = 8.2
```

### 3. 計算 MS (均方)
```
Regression MS = Regression SS / Regression df
              = 4.3 / 1
              = 4.3

Error MS = Error SS / Error df
         = 8.2 / 18
         = 0.456
```

---

## 完整 ANOVA Table

| Source     | df | SS   | MS    |
|------------|---:|-----:|------:|
| Regression |  1 | 4.3  | 4.30  |
| Error      | 18 | 8.2  | 0.456 |
| Total      | 19 | 12.5 |       |
