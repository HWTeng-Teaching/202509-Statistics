# 題目 25：抗生素製造 - 估計平均產量和誤差界限

## 題目資訊

**樣本資料：**
- 樣本大小：n = 100 小時
- 樣本平均數：x̄ = 1020 克/小時
- 樣本標準差：s = 90 克/小時

**目標：**
估計母體平均每小時產量，並計算誤差界限

---

## 解答

### 第一部分：估計母體平均數

**點估計 (Point Estimate)：**

母體平均數 μ 的最佳點估計就是樣本平均數 x̄
```
μ̂ = x̄ = 1020 克/小時
```

**答案：估計的平均每小時產量為 1020 克**

---

### 第二部分：計算誤差界限 (Margin of Error)

誤差界限（也稱為抽樣誤差）衡量估計值的不確定性。

#### 公式

**標準誤 (Standard Error)：**
```
SE = s / √n
```

**誤差界限（95% 信賴水準）：**
```
ME = z* × SE
```

其中 z* 是信賴係數：
- 90% 信賴水準：z* = 1.645
- 95% 信賴水準：z* = 1.96
- 99% 信賴水準：z* = 2.576

**註：** 因為 n = 100 很大，可以用 z 分配。如果樣本小，應該用 t 分配。

---

#### 計算過程

**步驟1：計算標準誤**
```
SE = s / √n
   = 90 / √100
   = 90 / 10
   = 9 克/小時
```

**步驟2：計算誤差界限（假設 95% 信賴水準）**
```
ME = z* × SE
   = 1.96 × 9
   = 17.64 克/小時
```

---

### 答案

| 項目 | 數值 |
|------|------|
| 估計的平均產量 | 1020 克/小時 |
| 標準誤 SE | 9 克/小時 |
| 誤差界限 ME (95%) | 17.64 克/小時 |

---

## 95% 信賴區間

**信賴區間公式：**
```
x̄ ± ME
```

**計算：**
```
1020 ± 17.64
= (1002.36, 1037.64)
```

**解釋：**
我們有 95% 的信心，真實的母體平均每小時產量落在 **1002.36 到 1037.64 克**之間。

---

## 不同信賴水準的誤差界限

如果題目沒有指定信賴水準，以下是不同情況：

### 90% 信賴水準
```
ME = 1.645 × 9 = 14.81 克/小時
信賴區間：1020 ± 14.81 = (1005.19, 1034.81)
```

### 95% 信賴水準（最常用）
```
ME = 1.96 × 9 = 17.64 克/小時
信賴區間：1020 ± 17.64 = (1002.36, 1037.64)
```

### 99% 信賴水準
```
ME = 2.576 × 9 = 23.18 克/小時
信賴區間：1020 ± 23.18 = (996.82, 1043.18)
```

**觀察：**
- 信賴水準越高，誤差界限越大
- 信賴水準越高，區間越寬
- 更有信心，但精確度降低

---

## 完整解題步驟

### 步驟1：確認給定資料
- n = 100
- x̄ = 1020
- s = 90

### 步驟2：計算標準誤
```
SE = s / √n = 90 / 10 = 9
```

### 步驟3：選擇信賴水準
- 通常用 95%，z* = 1.96
- 如果題目有指定，用指定的

### 步驟4：計算誤差界限
```
ME = z* × SE = 1.96 × 9 = 17.64
```

### 步驟5：給出估計值和誤差界限
```
估計值：1020 克/小時
誤差界限：±17.64 克/小時
```

---

## 重要概念

### 標準誤 (Standard Error)

**意義：**
- 衡量樣本平均數的變異程度
- 樣本越大，標準誤越小
- 標準誤越小，估計越精確

**公式：**
```
SE = σ / √n  （已知母體標準差）
SE = s / √n  （未知母體標準差，用樣本標準差）
```

### 誤差界限 (Margin of Error)

**意義：**
- 估計值的「上下容許範圍」
- 反映估計的不確定性
- ME 越小，估計越精確

**影響因素：**
1. 信賴水準：越高 → ME 越大
2. 樣本標準差：越大 → ME 越大
3. 樣本大小：越大 → ME 越小

### 信賴區間 (Confidence Interval)

**公式：**
```
點估計 ± 誤差界限
x̄ ± ME
x̄ ± z* × (s/√n)
```

**解釋：**
「我們有 95% 的信心，真實的母體平均數落在這個區間內」

---

## 如果要減少誤差界限

### 方法1：增加樣本大小

**原本：** n = 100, ME = 17.64

**如果 n = 400：**
```
SE = 90 / √400 = 90 / 20 = 4.5
ME = 1.96 × 4.5 = 8.82
```
誤差界限減半！

### 方法2：降低信賴水準

**95% → 90%：**
```
ME = 1.645 × 9 = 14.81
```
但信心降低了

### 方法3：減少變異性

改進製程，降低標準差 s

---

## 公式總整理

| 統計量 | 公式 | 本題計算 |
|--------|------|---------|
| 點估計 | μ̂ = x̄ | 1020 |
| 標準誤 | SE = s/√n | 90/10 = 9 |
| 誤差界限 (95%) | ME = 1.96×SE | 1.96×9 = 17.64 |
| 信賴區間 (95%) | x̄ ± ME | (1002.36, 1037.64) |

## 實際應用

**對抗生素製造商的意義：**

1. **平均產量估計**：約 1020 克/小時
2. **變異範圍**：在 1002 到 1038 克之間（95% 信心）
3. **品質控制**：可以用此資訊設定生產標準
4. **產能規劃**：可以預測每日、每月產量

**如果想要更精確的估計：**
- 增加觀察時段（增加樣本大小）
- 改善製程穩定性（降低標準差）
