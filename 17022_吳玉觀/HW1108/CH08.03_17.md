# 題目 17：二項分配比例的 95% 信賴區間

## 題目資訊

- 樣本大小：n = 500 次試驗
- 成功次數：x = 27 次
- 信賴水準：95%

---

## 解答步驟

### 步驟1：計算樣本比例 p̂
```
p̂ = x / n
  = 27 / 500
  = 0.054
```

---

### 步驟2：檢查常態近似條件

**條件：** np̂ ≥ 10 且 n(1-p̂) ≥ 10

**檢查：**
```
np̂ = 500 × 0.054 = 27 ≥ 10 ✓
n(1-p̂) = 500 × 0.946 = 473 ≥ 10 ✓
```

**結論：兩個條件都滿足，可以使用常態近似！**

---

### 步驟3：計算標準誤
```
SE(p̂) = √[p̂(1-p̂) / n]
       = √[0.054 × 0.946 / 500]
       = √[0.051084 / 500]
       = √0.00010217
       = 0.0101
```

---

### 步驟4：找出 z* 值

**95% 信賴水準：** z* = 1.96

---

### 步驟5：計算誤差界限
```
ME = z* × SE(p̂)
   = 1.96 × 0.0101
   = 0.0198
   ≈ 0.020
```

---

### 步驟6：建構信賴區間

**公式：**
```
p̂ ± ME
```

**計算：**
```
下限 = 0.054 - 0.020 = 0.034
上限 = 0.054 + 0.020 = 0.074
```

---

## 答案

### 95% 信賴區間
```
(0.034, 0.074)
或
(3.4%, 7.4%)
```

### 各項數值總結

| 項目 | 數值 | 百分比 |
|------|------|--------|
| 樣本比例 p̂ | 0.054 | 5.4% |
| 標準誤 SE | 0.0101 | 1.01% |
| 誤差界限 ME | 0.020 | 2.0% |
| 信賴區間下限 | 0.034 | 3.4% |
| 信賴區間上限 | 0.074 | 7.4% |

---

## 詳細計算過程

### 計算 p̂(1-p̂)
```
p̂ = 0.054
1 - p̂ = 0.946

p̂(1-p̂) = 0.054 × 0.946
        = 0.051084
```

### 計算 p̂(1-p̂)/n
```
0.051084 / 500 = 0.00010217
```

### 計算標準誤
```
SE = √0.00010217
   = 0.01011
   ≈ 0.0101
```

### 計算誤差界限
```
ME = 1.96 × 0.0101
   = 0.01980
   ≈ 0.020
```

---

## 信賴區間解釋

**統計解釋：**
我們有 95% 的信心，真實的母體比例 p 落在 **0.034 到 0.074** 之間。

**實際意義：**
- 在 500 次試驗中，只有 27 次成功（5.4%）
- 真實的成功率可能在 3.4% 到 7.4% 之間
- 這是一個相對較低的成功率

---

## 完整公式

### 信賴區間公式
```
p̂ ± z* × √[p̂(1-p̂) / n]
```

### 代入數值
```
0.054 ± 1.96 × √[0.054 × 0.946 / 500]
= 0.054 ± 1.96 × 0.0101
= 0.054 ± 0.020
= (0.034, 0.074)
```

---

## 如果用不同信賴水準

### 90% 信賴區間
```
z* = 1.645
ME = 1.645 × 0.0101 = 0.0166
信賴區間：0.054 ± 0.017 = (0.037, 0.071) 或 (3.7%, 7.1%)
```

### 95% 信賴區間（本題）
```
z* = 1.96
ME = 1.96 × 0.0101 = 0.020
信賴區間：0.054 ± 0.020 = (0.034, 0.074) 或 (3.4%, 7.4%)
```

### 99% 信賴區間
```
z* = 2.576
ME = 2.576 × 0.0101 = 0.026
信賴區間：0.054 ± 0.026 = (0.028, 0.080) 或 (2.8%, 8.0%)
```

## 圖形理解

想像一條數線：
```
    |------[=====]=====|
  0.034   0.054      0.074
    ↑       ↑          ↑
   下限   點估計      上限
   3.4%   5.4%       7.4%
```

**中心點**：p̂ = 0.054（樣本比例）  
**向左向右各延伸**：±0.020（誤差界限）  
**區間長度**：0.074 - 0.034 = 0.040 或 4%

## 重要提醒

### 常態近似條件

**必須檢查：**
- np̂ ≥ 10
- n(1-p̂) ≥ 10

如果不滿足，不能使用這個方法，要用：
- Wilson score interval
- Exact binomial interval (Clopper-Pearson)

**本題情況：**
27 ≥ 10 且 473 ≥ 10，所以可以安全使用常態近似。

---

## 實際應用

**這個區間告訴我們什麼？**

1. **點估計**：5.4% 的成功率
2. **不確定性**：真實值可能在 3.4% 到 7.4% 之間
3. **樣本大小的影響**：n = 500 已經很大，但因為 p 很小，所以區間還是有一定寬度

**如果想要更窄的區間：**
- 增加樣本大小（例如 n = 1000）
- 或降低信賴水準（但信心會下降）
