# 抽樣分配練習題解答

## Population III 背景資訊

- 母體數字：10, 15, 21, 22
- 母體大小：N = 4
- 母體平均數：μ = 17
- 樣本大小：n = 2

---

## 題目 7：不放回抽樣 (Without Replacement)

### 步驟1：列出所有可能的樣本

從 4 個數字中抽 2 個，共有 6 種可能的樣本：

1. (10, 15) → x̄ = (10+15)/2 = 12.5
2. (10, 21) → x̄ = (10+21)/2 = 15.5
3. (10, 22) → x̄ = (10+22)/2 = 16.0
4. (15, 21) → x̄ = (15+21)/2 = 18.0
5. (15, 22) → x̄ = (15+22)/2 = 18.5
6. (21, 22) → x̄ = (21+22)/2 = 21.5

### 步驟2：抽樣分配表

| 樣本平均數 x̄ | 次數 | 機率 P(x̄) |
|-------------|------|-----------|
| 12.5 | 1 | 1/6 ≈ 0.1667 |
| 15.5 | 1 | 1/6 ≈ 0.1667 |
| 16.0 | 1 | 1/6 ≈ 0.1667 |
| 18.0 | 1 | 1/6 ≈ 0.1667 |
| 18.5 | 1 | 1/6 ≈ 0.1667 |
| 21.5 | 1 | 1/6 ≈ 0.1667 |

---

## 題目 8：放回抽樣 (With Replacement)

### 步驟1：列出所有可能的樣本

因為是放回抽樣，可以抽到相同數字，共有 16 種可能的樣本：

1. (10, 10) → x̄ = 10.0
2. (10, 15) → x̄ = 12.5
3. (10, 21) → x̄ = 15.5
4. (10, 22) → x̄ = 16.0
5. (15, 10) → x̄ = 12.5
6. (15, 15) → x̄ = 15.0
7. (15, 21) → x̄ = 18.0
8. (15, 22) → x̄ = 18.5
9. (21, 10) → x̄ = 15.5
10. (21, 15) → x̄ = 18.0
11. (21, 21) → x̄ = 21.0
12. (21, 22) → x̄ = 21.5
13. (22, 10) → x̄ = 16.0
14. (22, 15) → x̄ = 18.5
15. (22, 21) → x̄ = 21.5
16. (22, 22) → x̄ = 22.0

### 步驟2：抽樣分配表

| 樣本平均數 x̄ | 出現次數 | 機率 P(x̄) |
|-------------|---------|-----------|
| 10.0 | 1 | 1/16 = 0.0625 |
| 12.5 | 2 | 2/16 = 0.1250 |
| 15.0 | 1 | 1/16 = 0.0625 |
| 15.5 | 2 | 2/16 = 0.1250 |
| 16.0 | 2 | 2/16 = 0.1250 |
| 18.0 | 2 | 2/16 = 0.1250 |
| 18.5 | 2 | 2/16 = 0.1250 |
| 21.0 | 1 | 1/16 = 0.0625 |
| 21.5 | 2 | 2/16 = 0.1250 |
| 22.0 | 1 | 1/16 = 0.0625 |

---

## 題目 9：計算期望值並比較

### 不放回抽樣的 E(x̄)
```
E(x̄) = (12.5 + 15.5 + 16 + 18 + 18.5 + 21.5) / 6
     = 102 / 6
     = 17
```

### 放回抽樣的 E(x̄)
```
E(x̄) = (10×1 + 12.5×2 + 15×1 + 15.5×2 + 16×2 + 18×2 + 18.5×2 + 21×1 + 21.5×2 + 22×1) / 16
     = (10 + 25 + 15 + 31 + 32 + 36 + 37 + 21 + 43 + 22) / 16
     = 272 / 16
     = 17
```

### 比較結果

| 抽樣方式 | E(x̄) | 與母體平均數比較 |
|---------|------|----------------|
| 不放回抽樣 | 17 | E(x̄) = μ ✓ |
| 放回抽樣 | 17 | E(x̄) = μ ✓ |
| 母體平均數 | 17 | μ = 17 |

### 結論

**無論是放回還是不放回抽樣，樣本平均數的期望值都等於母體平均數 (E(x̄) = μ = 17)**
