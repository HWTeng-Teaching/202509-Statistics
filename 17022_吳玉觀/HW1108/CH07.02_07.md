題目 7：不放回抽樣（Without Replacement）
什麼是不放回？ 就是抽了一個數字後，不放回去，再抽第二個。
步驟1：列出所有可能的樣本
從 4 個數字中抽 2 個，有幾種組合？
所有可能的樣本：

(10, 15)
(10, 21)
(10, 22)
(15, 21)
(15, 22)
(21, 22)

答案：共有 6 種可能的樣本
步驟2：計算每個樣本的平均數 x̄

(10, 15) → x̄ = (10+15)/2 = 12.5
(10, 21) → x̄ = (10+21)/2 = 15.5
(10, 22) → x̄ = (10+22)/2 = 16
(15, 21) → x̄ = (15+21)/2 = 18
(15, 22) → x̄ = (15+22)/2 = 18.5
(21, 22) → x̄ = (21+22)/2 = 21.5

步驟3：做成表格（抽樣分配表）
樣本平均數 x̄次數機率 P(x̄)12.511/615.511/61611/61811/618.511/621.511/6

## 02.CH07.02_08
題目 8：放回抽樣（With Replacement）
什麼是放回？ 就是抽了一個數字後，把它放回去，再抽第二個。所以同一個數字可能被抽到兩次。
步驟1：列出所有可能的樣本
因為是放回抽樣，所以可以抽到相同的數字。
所有可能的樣本：

(10, 10)
(10, 15)
(10, 21)
(10, 22)
(15, 10)
(15, 15)
(15, 21)
(15, 22)
(21, 10)
(21, 15)
(21, 21)
(21, 22)
(22, 10)
(22, 15)
(22, 21)
(22, 22)

答案：共有 16 種可能的樣本
步驟2：計算每個樣本的平均數 x̄

(10, 10) → x̄ = (10+10)/2 = 10
(10, 15) → x̄ = (10+15)/2 = 12.5
(10, 21) → x̄ = (10+21)/2 = 15.5
(10, 22) → x̄ = (10+22)/2 = 16
(15, 10) → x̄ = (15+10)/2 = 12.5
(15, 15) → x̄ = (15+15)/2 = 15
(15, 21) → x̄ = (15+21)/2 = 18
(15, 22) → x̄ = (15+22)/2 = 18.5
(21, 10) → x̄ = (21+10)/2 = 15.5
(21, 15) → x̄ = (21+15)/2 = 18
(21, 21) → x̄ = (21+21)/2 = 21
(21, 22) → x̄ = (21+22)/2 = 21.5
(22, 10) → x̄ = (22+10)/2 = 16
(22, 15) → x̄ = (22+15)/2 = 18.5
(22, 21) → x̄ = (22+21)/2 = 21.5
(22, 22) → x̄ = (22+22)/2 = 22

步驟3：整理相同的 x̄ 值（做成表格）
樣本平均數 x̄出現次數機率 P(x̄)1011/1612.522/16 = 1/81511/1615.522/16 = 1/81622/16 = 1/81822/16 = 1/818.522/16 = 1/82111/1621.522/16 = 1/82211/16

## 03.CH07.02_09
題目 9：計算兩種抽樣方式的平均數 E(x̄)
不放回抽樣的 E(x̄)：
E(x̄) = (12.5 + 15.5 + 16 + 18 + 18.5 + 21.5) / 6
E(x̄) = 102 / 6 = 17
放回抽樣的 E(x̄)：
E(x̄) = (10×1 + 12.5×2 + 15×1 + 15.5×2 + 16×2 + 18×2 + 18.5×2 + 21×1 + 21.5×2 + 22×1) / 16
E(x̄) = (10 + 25 + 15 + 31 + 32 + 36 + 37 + 21 + 43 + 22) / 16
E(x̄) = 272 / 16 = 17
比較：
兩種抽樣方式的樣本平均數的平均值都是 17，跟母體平均數 μ = 17 一模一樣！
結論：無論是放回還是不放回，樣本平均數的期望值都等於母體平均數！
