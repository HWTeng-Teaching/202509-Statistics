# 題目 23：電池壽命的抽樣分配機率

## 題目資訊

- 母體平均數：μ = 1110 天
- 母體標準差：σ = 80 天
- 樣本大小：n = 400



## 步驟1：確認抽樣分配

因為 n = 400 > 30，根據**中央極限定理**，樣本平均數 x̄ 近似常態分配：
```
x̄ ~ N(μ, σ/√n)
```

**計算標準誤：**
```
SE = σ / √n
   = 80 / √400
   = 80 / 20
   = 4
```

所以：**x̄ ~ N(1110, 4)**



## 步驟2：標準化 (計算 Z 分數)

將 x̄ 轉換成標準常態分配：

**公式：**
```
Z = (x̄ - μ) / SE
```



## (a) P(1100 < x̄ < 1110)

**計算 Z 分數：**

當 x̄ = 1100：
```
Z₁ = (1100 - 1110) / 4
   = -10 / 4
   = -2.5
```

當 x̄ = 1110：
```
Z₂ = (1110 - 1110) / 4
   = 0 / 4
   = 0
```

**求機率：**
```
P(1100 < x̄ < 1110) = P(-2.5 < Z < 0)
                     = P(Z < 0) - P(Z < -2.5)
                     = 0.5000 - 0.0062
                     = 0.4938
```

**答案：P(1100 < x̄ < 1110) = 0.4938 或 49.38%**



## (b) P(x̄ > 1120)

**計算 Z 分數：**

當 x̄ = 1120：
```
Z = (1120 - 1110) / 4
  = 10 / 4
  = 2.5
```

**求機率：**
```
P(x̄ > 1120) = P(Z > 2.5)
             = 1 - P(Z < 2.5)
             = 1 - 0.9938
             = 0.0062
```

**答案：P(x̄ > 1120) = 0.0062 或 0.62%**



## (c) P(x̄ < 900)

**計算 Z 分數：**

當 x̄ = 900：
```
Z = (900 - 1110) / 4
  = -210 / 4
  = -52.5
```

**求機率：**
```
P(x̄ < 900) = P(Z < -52.5)
            ≈ 0
```

**答案：P(x̄ < 900) ≈ 0（幾乎不可能發生）**



## 總結答案

| 問題 | Z 分數範圍 | 機率 |
|------|-----------|------|
| (a) 1100 < x̄ < 1110 | -2.5 < Z < 0 | 0.4938 (49.38%) |
| (b) x̄ > 1120 | Z > 2.5 | 0.0062 (0.62%) |
| (c) x̄ < 900 | Z < -52.5 | ≈ 0 (幾乎不可能) |



## 常用 Z 值對照表

| Z 值 | P(Z < z) | 說明 |
|------|----------|------|
| -2.5 | 0.0062 | 左尾 0.62% |
| 0 | 0.5000 | 中位數 |
| 2.5 | 0.9938 | 右尾 0.62% |



## 解題關鍵

1. **標準誤 SE = 4** - 樣本大小 400 很大，所以標準誤很小
2. **Z 分數** - 將問題標準化，方便查表或計算
3. **常態分配性質** - 對稱、68-95-99.7 規則
4. **實際意義** - 400 顆電池的平均壽命非常穩定，不太可能偏離母體平均數太遠
