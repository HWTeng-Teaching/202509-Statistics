# 題目 15：抽樣分配的形狀、平均數和標準誤

## 題目資訊

- 母體平均數：μ = 53
- 母體標準差：σ = 21
- 樣本大小：n = 49

---

## 解答

### (a) 抽樣分配的形狀 (Shape of Sampling Distribution)

根據**中央極限定理 (Central Limit Theorem, CLT)**：

當樣本大小 n ≥ 30 時，無論母體分配形狀如何，樣本平均數 x̄ 的抽樣分配會近似於**常態分配 (Normal Distribution)**。

**結論：**
- 因為 n = 49 > 30，所以樣本平均數的抽樣分配近似於**常態分配**
- 形狀：**鐘型對稱曲線 (Bell-shaped, symmetric)**

---

### (b) 抽樣分配的平均數 (Mean of Sampling Distribution)

樣本平均數的期望值等於母體平均數：
```
E(x̄) = μ
```

**計算：**
```
E(x̄) = μ = 53
```

**答案：抽樣分配的平均數 = 53**

---

### (c) 標準誤 (Standard Error)

樣本平均數的標準差稱為**標準誤 (Standard Error, SE)**：

**公式：**
```
SE = σ / √n
```

**計算：**
```
SE = σ / √n
   = 21 / √49
   = 21 / 7
   = 3
```

**答案：標準誤 (SE) = 3**

---

## 總結

| 項目 | 數值 | 說明 |
|------|------|------|
| 抽樣分配形狀 | 近似常態分配 | n = 49 > 30，符合 CLT |
| 平均數 E(x̄) | 53 | 等於母體平均數 μ |
| 標準誤 SE | 3 | σ / √n = 21 / 7 |

---

## 重要概念整理

### 中央極限定理 (CLT)

當樣本大小足夠大 (通常 n ≥ 30) 時：
1. 樣本平均數 x̄ 的分配近似常態分配
2. 平均數：E(x̄) = μ
3. 標準差 (標準誤)：SE = σ / √n

### 標準誤的意義

- 標準誤衡量**樣本平均數的變異程度**
- 樣本越大 (n 越大)，標準誤越小
- 標準誤越小，表示樣本平均數越接近母體平均數
