# 題目 26：更生計畫 - 估計成功率和誤差界限

## 題目資訊

**樣本資料：**
- 樣本大小：n = 121 人
- 成功人數：x = 79 人（3年內沒有再犯罪）
- 樣本比例：p̂ = 79/121

**目標：**
1. 找出 p（成功率）的點估計
2. 計算誤差界限

---

## 解答

### 第一部分：點估計

**計算樣本比例：**
```
p̂ = x / n
  = 79 / 121
  = 0.6529
  ≈ 0.653 或 65.3%
```

**答案：母體比例 p 的點估計為 p̂ = 0.653 或 65.3%**

**解釋：**
估計約有 65.3% 的受刑人在接受此更生技術後，能在出獄後 3 年內不再犯罪。

---

### 第二部分：計算誤差界限

#### 公式

**樣本比例的標準誤：**
```
SE(p̂) = √[p̂(1-p̂) / n]
```

**誤差界限（95% 信賴水準）：**
```
ME = z* × SE(p̂)
```

其中：
- z* = 1.96（95% 信賴水準）
- z* = 1.645（90% 信賴水準）
- z* = 2.576（99% 信賴水準）

---

#### 計算過程

**步驟1：計算 p̂**
```
p̂ = 79/121 = 0.6529
```

**步驟2：計算 1 - p̂**
```
1 - p̂ = 1 - 0.6529 = 0.3471
```

**步驟3：計算標準誤**
```
SE(p̂) = √[p̂(1-p̂) / n]
       = √[0.6529 × 0.3471 / 121]
       = √[0.2266 / 121]
       = √0.001873
       = 0.0433
```

**步驟4：計算誤差界限（95% 信賴水準）**
```
ME = z* × SE(p̂)
   = 1.96 × 0.0433
   = 0.0848
   ≈ 0.085 或 8.5%
```

---

### 答案總結

| 項目 | 數值 |
|------|------|
| 點估計 p̂ | 0.653 (65.3%) |
| 標準誤 SE | 0.0433 (4.33%) |
| 誤差界限 ME (95%) | 0.085 (8.5%) |

**誤差界限：±0.085 或 ±8.5%**

---

## 95% 信賴區間

**公式：**
```
p̂ ± ME
```

**計算：**
```
0.653 ± 0.085
= (0.568, 0.738)
或 (56.8%, 73.8%)
```

**解釋：**
我們有 95% 的信心，真實的成功率（母體比例）落在 **56.8% 到 73.8%** 之間。

---

## 不同信賴水準的誤差界限

### 90% 信賴水準
```
ME = 1.645 × 0.0433
   = 0.0712
   ≈ 0.071 或 7.1%

信賴區間：0.653 ± 0.071 = (0.582, 0.724) 或 (58.2%, 72.4%)
```

### 95% 信賴水準（最常用）
```
ME = 1.96 × 0.0433
   = 0.0848
   ≈ 0.085 或 8.5%

信賴區間：0.653 ± 0.085 = (0.568, 0.738) 或 (56.8%, 73.8%)
```

### 99% 信賴水準
```
ME = 2.576 × 0.0433
   = 0.1115
   ≈ 0.112 或 11.2%

信賴區間：0.653 ± 0.112 = (0.541, 0.765) 或 (54.1%, 76.5%)
```

## 完整解題步驟

### 步驟1：計算樣本比例
```
p̂ = 79/121 = 0.6529
```

### 步驟2：檢查常態近似條件
```
np̂ = 121 × 0.6529 = 79 ≥ 10 ✓
n(1-p̂) = 121 × 0.3471 = 42 ≥ 10 ✓
```
條件滿足，可以使用常態近似！

### 步驟3：計算標準誤
```
SE = √[p̂(1-p̂)/n]
   = √[0.6529 × 0.3471 / 121]
   = 0.0433
```

### 步驟4：計算誤差界限
```
ME = 1.96 × 0.0433 = 0.085
```

### 步驟5：建構信賴區間
```
(0.653 - 0.085, 0.653 + 0.085)
= (0.568, 0.738)
```

## 詳細計算過程（手算版）

### 計算 p̂(1-p̂)
```
p̂ = 0.6529
1-p̂ = 0.3471

p̂(1-p̂) = 0.6529 × 0.3471
        = 0.226596
```

### 計算 p̂(1-p̂)/n
```
0.226596 / 121 = 0.001873
```

### 計算平方根
```
√0.001873 = 0.04328
          ≈ 0.0433
```

### 計算誤差界限
```
1.96 × 0.0433 = 0.08487
               ≈ 0.085
```

---

## 重要公式總整理

### 樣本比例
```
p̂ = x / n
```

### 標準誤
```
SE(p̂) = √[p̂(1-p̂) / n]
```

### 誤差界限
```
ME = z* × SE(p̂)
```

### 信賴區間
```
p̂ ± z* × √[p̂(1-p̂) / n]
```

---

## 本題公式應用

| 公式 | 數值代入 | 結果 |
|------|---------|------|

| SE = √[p̂(1-p̂)/n] | √[0.653×0.347/121] | 0.0433 |
| ME = 1.96×SE | 1.96×0.0433 | 0.085 |
| 下限 | 0.653 - 0.085 | 0.568 |
| 上限 | 0.653 + 0.085 | 0.738 |

## 實際意義

### 對更生計畫的啟示

**點估計：65.3%**
- 約三分之二的受刑人成功更生
- 看起來是有效的計畫

**誤差界限：±8.5%**
- 真實成功率可能在 56.8% 到 73.8% 之間
- 在最壞的情況下，仍有超過一半的成功率

### 如果想要更精確的估計

**增加樣本大小到 n = 400：**
```
SE = √[0.653×0.347/400]
   = √0.000567
   = 0.0238

ME = 1.96 × 0.0238 = 0.047 或 4.7%
```
誤差界限幾乎減半！

---

## 比例估計 vs 平均數估計

### 相似之處
- 都用樣本統計量估計母體參數
- 都需要計算標準誤
- 都用 z* 或 t* 計算誤差界限

### 不同之處

| 項目 | 平均數 | 比例 |
|------|--------|------|
| 參數 | μ | p |
| 估計值 | x̄ | p̂ |
| 標準誤 | s/√n | √[p̂(1-p̂)/n] |
| 資料類型 | 連續數值 | 二元分類 |
| 常態條件 | n≥30 或母體常態 | np̂≥10 且 n(1-p̂)≥10 |
