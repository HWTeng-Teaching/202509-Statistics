# 題目 28：水中細菌 - Poisson 分配與中央極限定理

## 問題

為什麼 Poisson 隨機變數（例如一公升水中某種細菌的數量）在平均數 μ 很大時，其分配可以用常態分配來近似？

提示：1 公升水 = 1000 立方公分



## 解答：用中央極限定理解釋

### 關鍵概念

**Poisson 分配可以視為許多小單位的總和**



### 步驟1：將 1 公升水分解成小單位

假設：
- 1 公升水 = 1000 立方公分（cc）
- 每 1 cc 水中含有細菌數量是一個隨機變數

我們可以把 1 公升水中的細菌總數看成：
```
X = X₁ + X₂ + X₃ + ... + X₁₀₀₀
```

其中：
- X = 1 公升水中的細菌總數
- Xᵢ = 第 i 個立方公分水中的細菌數
- i = 1, 2, 3, ..., 1000



### 步驟2：每個小單位的性質

假設 1 公升水中平均有 μ 個細菌，則：

**每 1 cc 水中的平均細菌數：**
```
E(Xᵢ) = μ / 1000
```

**每個 Xᵢ 都是獨立同分配的 Poisson 隨機變數**



### 步驟3：應用中央極限定理

根據**中央極限定理 (Central Limit Theorem)**：

當我們將**大量獨立同分配**的隨機變數相加時，無論這些隨機變數原本的分配是什麼，其總和的分配會趨近於**常態分配**。

**數學表示：**
```
X = X₁ + X₂ + ... + X₁₀₀₀
```

當 n = 1000（很大）且 μ 很大時：
```
X ~ 近似 N(μ, σ²)
```

其中對於 Poisson 分配：
```
σ² = μ（Poisson 分配的特性：變異數 = 平均數）
```


### 步驟4：為什麼需要 μ 很大？

對於 Poisson 分配來說：

1. **當 μ 很小時**：
   - 分配是右偏的（skewed right）
   - 大部分值集中在 0, 1, 2
   - 不對稱

2. **當 μ 很大時**（例如 μ ≥ 10 或更大）：
   - 分配變得越來越對稱
   - 形狀接近鐘型曲線
   - 可以用常態分配很好地近似



## 數學證明概要

### Poisson 分配的性質

如果 X₁, X₂, ..., Xₙ 都是獨立的 Poisson 隨機變數：
- X₁ ~ Poisson(λ₁)
- X₂ ~ Poisson(λ₂)
- ...
- Xₙ ~ Poisson(λₙ)

則它們的總和：
```
X = X₁ + X₂ + ... + Xₙ ~ Poisson(λ₁ + λ₂ + ... + λₙ)
```

### 應用到細菌問題
```
X = ΣXᵢ ~ Poisson(1000 × μ/1000) = Poisson(μ)
```

當 μ 很大且可以分解成很多小部分的總和時，根據 CLT：
```
X ~ 近似 N(μ, μ)
```



## 實際例子

假設 1 公升水平均含有 **μ = 100** 個細菌：

### 精確的 Poisson 分配
```
P(X = k) = (e^(-100) × 100^k) / k!
```

### 常態近似
```
X ~ 近似 N(100, 100)
即 X ~ 近似 N(100, 10²)
標準差 σ = √100 = 10
```



## 總結

### 為什麼 Poisson 可以用常態近似？

1. **分解原理**：
   - 1 公升 = 1000 個小單位
   - 總細菌數 = 1000 個獨立隨機變數的總和

2. **中央極限定理**：
   - 大量獨立隨機變數的總和 → 常態分配

3. **μ 要夠大**：
   - μ 大 → 分配對稱
   - μ 大 → 常態近似更準確
   - 經驗法則：μ ≥ 10 時近似效果良好

### 關鍵公式
```
當 μ 很大時：
Poisson(μ) ≈ N(μ, μ)

即：
平均數 = μ
變異數 = μ
標準差 = √μ
```



## 圖形理解

想像 Poisson 分配的形狀變化：

| μ 值 | 分配形狀 | 對稱性 |
|------|---------|--------|
| μ = 1 | 極度右偏 | 不對稱 |
| μ = 5 | 略微右偏 | 輕微不對稱 |
| μ = 10 | 接近對稱 | 基本對稱 |
| μ = 30 | 鐘型 | 對稱 |
| μ = 100 | 標準鐘型 | 完全對稱 |

當 μ ≥ 30 時，常態近似非常準確！
