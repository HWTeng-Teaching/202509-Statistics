# 題目 31：環保意識調查 - 樣本比例的抽樣分配

## 題目資訊

- 母體比例：p = 0.47（47% 的美國人將回收與地球日聯想在一起）
- 樣本大小：n = 100



## (a) 樣本比例 p̂ 的分配

### 檢查常態近似條件

樣本比例 p̂ 在以下條件滿足時可以用常態分配近似：

**條件：**
```
np ≥ 10  且  n(1-p) ≥ 10
```

**檢查：**
```
np = 100 × 0.47 = 47 ≥ 10 ✓
n(1-p) = 100 × 0.53 = 53 ≥ 10 ✓
```

**結論：兩個條件都滿足，可以用常態近似！**



### 樣本比例的分配

根據中央極限定理，樣本比例 p̂ 近似常態分配：
```
p̂ ~ N(p, √[p(1-p)/n])
```

**平均數（期望值）：**
```
E(p̂) = p = 0.47
```

**標準差（標準誤）：**
```
SE(p̂) = √[p(1-p)/n]
       = √[0.47 × 0.53 / 100]
       = √[0.2491 / 100]
       = √0.002491
       = 0.0499
       ≈ 0.05
```

### 答案

**是的，p̂ 有近似常態分配**
```
p̂ ~ N(0.47, 0.05)
```

| 參數 | 數值 |
|------|------|
| 平均數 μ_p̂ | 0.47 |
| 標準差 σ_p̂ | 0.0499 ≈ 0.05 |



## (b) P(p̂ < 0.45)

### 計算步驟

**標準化：**
```
Z = (p̂ - p) / SE(p̂)
  = (0.45 - 0.47) / 0.0499
  = -0.02 / 0.0499
  = -0.401
  ≈ -0.40
```

**查 Z 表或用計算機：**
```
P(p̂ < 0.45) = P(Z < -0.40)
             = 0.3446
```

### 答案

**P(p̂ < 0.45) = 0.3446 或 34.46%**

**解釋：**
約有 34.46% 的機會，從 100 人的樣本中得到的比例會少於 45%。



## (c) P(0.42 < p̂ < 0.45)

### 計算步驟

**計算兩個 Z 分數：**

當 p̂ = 0.42：
```
Z₁ = (0.42 - 0.47) / 0.0499
   = -0.05 / 0.0499
   = -1.002
   ≈ -1.00
```

當 p̂ = 0.45：
```
Z₂ = (0.45 - 0.47) / 0.0499
   = -0.02 / 0.0499
   = -0.401
   ≈ -0.40
```

**查 Z 表：**
```
P(0.42 < p̂ < 0.45) = P(-1.00 < Z < -0.40)
                     = P(Z < -0.40) - P(Z < -1.00)
                     = 0.3446 - 0.1587
                     = 0.1859
```

### 答案

**P(0.42 < p̂ < 0.45) = 0.1859 或 18.59%**

**解釋：**
約有 18.59% 的機會，樣本比例會落在 42% 到 45% 之間。



## (d) 如果觀察到 p̂ < 0.30，該如何解釋？

### 計算 P(p̂ < 0.30)

**標準化：**
```
Z = (0.30 - 0.47) / 0.0499
  = -0.17 / 0.0499
  = -3.406
  ≈ -3.41
```

**查 Z 表：**
```
P(p̂ < 0.30) = P(Z < -3.41)
             ≈ 0.0003
             = 0.03%
```

### 答案與結論

**機率極低：只有 0.03%！**

**結論：**

如果在樣本中觀察到 p̂ < 0.30，我們可以做出以下推論：

1. **母體比例 p = 0.47 可能不正確**
   - 這個結果太不尋常了
   - 如果真的 p = 0.47，出現 p̂ < 0.30 的機會只有千分之三

2. **可能的原因：**
   - 母體真實比例可能遠低於 47%
   - 抽樣方法有問題（不是隨機抽樣）
   - 樣本有偏差（sampling bias）
   - 調查時間或地點不具代表性

3. **統計推論：**
   - 這是一個**顯著的偏差** (significant deviation)
   - 在統計假設檢定中，我們會**拒絕** p = 0.47 這個假設
   - 有充分證據懷疑真實比例與 47% 不同

**簡單說：**
如果樣本比例低於 30%，這結果太離譜了，我們有理由相信：
- 要嘛真實比例不是 47%
- 要嘛抽樣過程出了問題

## 重要公式




## 實際應用

這題告訴我們：

1. **樣本變異是正常的**
   - 即使 p = 0.47，樣本比例也會上下波動
   - 34.46% 的機會得到低於 45% 的結果

2. **極端結果需要警惕**
   - p̂ < 0.30 的機率只有 0.03%
   - 這麼罕見的結果通常意味著某處有問題

3. **統計推論的基礎**
   - 用樣本資料推論母體參數
   - 評估觀察結果的合理性
