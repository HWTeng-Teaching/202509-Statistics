# 題目 31：超市熟食區銷售額

## 題目資訊

**單一顧客的購買金額：**
- 平均：μ = $8.50
- 標準差：σ = $2.50

**某天的顧客數：**
- n = 30 位顧客

**總銷售額 S：**
- S = 所有顧客購買金額的總和

---

## (a) 總銷售額 S 的機率分配類型

### 分析

總銷售額 S 是由許多顧客的購買金額相加而成：
```
S = X₁ + X₂ + X₃ + ... + X₃₀
```

其中：
- Xᵢ = 第 i 位顧客的購買金額
- i = 1, 2, 3, ..., 30

### 答案

**S 的機率分配：近似常態分配 (Approximately Normal Distribution)**

### 解釋

根據**中央極限定理 (Central Limit Theorem)**：

1. **條件滿足**：
   - 每位顧客的購買金額是獨立的隨機變數
   - 樣本數 n = 30 ≥ 30（足夠大）

2. **結論**：
   - 無論個別顧客購買金額的原始分配是什麼
   - 30 位顧客購買金額的**總和**會近似常態分配

3. **為什麼是常態分配？**
   - 總和 = 大量獨立隨機變數相加
   - CLT 保證：大量獨立隨機變數的總和 → 常態分配

**注意：** 
- 如果問的是「平均銷售額」x̄，那也是常態分配
- 這裡問的是「總銷售額」S（總和），同樣也是常態分配

---

## (b) 總銷售額 S 的平均數和標準差

### 公式推導

當 S = X₁ + X₂ + ... + Xₙ，且每個 Xᵢ 都是獨立同分配時：

**總和的期望值：**
```
E(S) = E(X₁ + X₂ + ... + Xₙ)
     = E(X₁) + E(X₂) + ... + E(Xₙ)
     = n × μ
```

**總和的變異數（因為獨立）：**
```
Var(S) = Var(X₁) + Var(X₂) + ... + Var(Xₙ)
       = n × σ²
```

**總和的標準差：**
```
SD(S) = √Var(S) = √(n × σ²) = σ × √n
```

---

### 計算

**給定資料：**
- μ = $8.50（每位顧客平均購買金額）
- σ = $2.50（每位顧客購買金額的標準差）
- n = 30（顧客數）

**總銷售額的平均數：**
```
E(S) = n × μ
     = 30 × 8.50
     = $255
```

**總銷售額的標準差：**
```
SD(S) = σ × √n
      = 2.50 × √30
      = 2.50 × 5.477
      = $13.69
```

---

### 答案

**總銷售額 S 的機率分配：**
```
S ~ N(255, 13.69²)
```

或寫成：
```
S ~ N(255, 187.42)
```

| 參數 | 數值 | 單位 |
|------|------|------|
| 平均數 E(S) | $255.00 | 美元 |
| 標準差 SD(S) | $13.69 | 美元 |
| 變異數 Var(S) | $187.42 | 美元² |

---

## 重要公式總結

### 對於總和 S = X₁ + X₂ + ... + Xₙ

| 統計量 | 公式 | 本題計算 |
|--------|------|---------|
| 期望值 | E(S) = n × μ | 30 × 8.50 = $255 |
| 變異數 | Var(S) = n × σ² | 30 × 2.50² = 187.5 |
| 標準差 | SD(S) = σ√n | 2.50 × √30 ≈ $13.69 |

### 對比：樣本平均數 x̄ = S/n

如果是問樣本平均數（每位顧客平均）：

| 統計量 | 公式 | 數值 |
|--------|------|------|
| 期望值 | E(x̄) = μ | $8.50 |
| 標準差 | SE(x̄) = σ/√n | $0.456 |

**注意差異：**
- 總和的標準差：σ√n（越加越大）
- 平均的標準差：σ/√n（越平均越穩定）

---

## 實際意義

### 平均數 $255

30 位顧客的總銷售額期望值是 $255

### 標準差 $13.69

- 總銷售額的變異程度
- 約 68% 的日子，總銷售額會落在：
```
  $255 ± $13.69
  即 $241.31 到 $268.69 之間
```

- 約 95% 的日子，總銷售額會落在：
```
  $255 ± 2×$13.69
  即 $227.62 到 $282.38 之間
```

---

## 關鍵概念

1. **總和 vs 平均**
   - 總和：S = ΣXᵢ，標準差 = σ√n（變大）
   - 平均：x̄ = S/n，標準差 = σ/√n（變小）

2. **中央極限定理**
   - n = 30 足夠大
   - 總和 S 近似常態分配

3. **獨立性假設**
   - 每位顧客的購買互不影響
   - 才能用 Var(S) = n×σ²
