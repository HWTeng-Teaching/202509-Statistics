# 題目 24：六個月大男嬰的成長數據

## 題目資訊

**樣本資料：**
- 樣本大小：n = 50 個六個月大男嬰

**體重數據：**
- 樣本平均數：x̄ = 8.0 公斤
- 樣本標準差：s = 0.30 公斤

**身高數據：**
- 樣本平均數：x̄ = 67.3 公分
- 樣本標準差：s = 0.64 公分



## (a) 體重的 95% 信賴區間

### 步驟1：確認資料
- n = 50
- x̄ = 8.0 kg
- s = 0.30 kg
- 信賴水準 = 95%

### 步驟2：計算標準誤
```
SE = s / √n
   = 0.30 / √50
   = 0.30 / 7.071
   = 0.0424 kg
```

### 步驟3：找臨界值

因為 n = 50 > 30，樣本夠大，可以使用 **z 分配**：
```
z* = 1.96（95% 信賴水準）
```

**註：** 如果要更精確，可以用 t 分配，自由度 df = 49：
```
t* ≈ 2.010
```

我們用 z* = 1.96（較常見且簡單）

### 步驟4：計算誤差界限
```
ME = z* × SE
   = 1.96 × 0.0424
   = 0.0831 kg
   ≈ 0.083 kg
```

### 步驟5：建構信賴區間
```
x̄ ± ME
= 8.0 ± 0.083
= (7.917, 8.083)
```

### 答案：體重的 95% 信賴區間
```
(7.917, 8.083) 公斤
或
(7.92, 8.08) 公斤（四捨五入到小數點後兩位）
```

**解釋：**
我們有 95% 的信心，所有六個月大男嬰的平均體重落在 **7.92 到 8.08 公斤**之間。



## (b) 身高的 99% 信賴區間

### 步驟1：確認資料
- n = 50
- x̄ = 67.3 cm
- s = 0.64 cm
- 信賴水準 = 99%

### 步驟2：計算標準誤
```
SE = s / √n
   = 0.64 / √50
   = 0.64 / 7.071
   = 0.0905 cm
```

### 步驟3：找臨界值

**99% 信賴水準：**
```
z* = 2.576
```

或使用 t 分配（df = 49）：
```
t* ≈ 2.680
```

我們用 z* = 2.576

### 步驟4：計算誤差界限
```
ME = z* × SE
   = 2.576 × 0.0905
   = 0.2331 cm
   ≈ 0.233 cm
```

### 步驟5：建構信賴區間
```
x̄ ± ME
= 67.3 ± 0.233
= (67.067, 67.533)
```

### 答案：身高的 99% 信賴區間
```
(67.067, 67.533) 公分
或
(67.07, 67.53) 公分（四捨五入到小數點後兩位）
```

**解釋：**
我們有 99% 的信心，所有六個月大男嬰的平均身高落在 **67.07 到 67.53 公分**之間。



## (c) 推論的假設條件

要從這個樣本推論到**所有六個月大男嬰**，我們需要以下假設：

### 假設 1：隨機抽樣 (Random Sampling)

**要求：**
- 這 50 個男嬰必須是從資料庫中**隨機選取**的
- 每個六個月大男嬰都有相同的機會被選中

**為什麼重要：**
- 避免選擇偏差 (selection bias)
- 確保樣本能代表母體

**潛在問題：**
- 如果只選擇某些特定的嬰兒（例如健康的、早產的、特定族群等）
- 樣本就無法代表所有六個月大男嬰



### 假設 2：樣本代表性 (Representativeness)

**要求：**
- 這個兒科診所的資料庫必須能代表**所有六個月大男嬰**
- 不只是這個診所或這個地區的男嬰

**可能的限制：**
- 地理限制：診所可能只服務特定地區
- 社經地位：來這個診所的家庭可能有特定的社經背景
- 族群分布：可能無法代表所有族群

**例如：**
如果這是一個高收入社區的診所，嬰兒的營養狀況可能優於全國平均



### 假設 3：獨立性 (Independence)

**要求：**
- 每個嬰兒的測量結果互相獨立
- 一個嬰兒的體重/身高不影響另一個嬰兒的測量

**通常滿足：**
因為是從資料庫中隨機選取



### 假設 4：母體分配接近常態或樣本夠大

**要求：**
- 體重和身高的母體分配接近常態分配
- 或樣本大小夠大（n ≥ 30）使得中央極限定理適用

**本題情況：**
- n = 50 > 30 ✓
- 體重和身高通常接近常態分配 ✓
- 兩個條件都滿足



### 答案總結

**必須假設的條件：**

1. **隨機抽樣**
   - 50 個男嬰是從資料庫中隨機選取的
   
2. **母體代表性**
   - 這個兒科診所的資料庫能代表所有六個月大男嬰
   - 不限於特定地區、族群或社經地位
   
3. **獨立性**
   - 每個測量值互相獨立
   
4. **常態性（已滿足）**
   - 樣本夠大（n=50）或母體接近常態分配

**最關鍵的假設：**
樣本必須是**隨機的**且**有代表性**，才能將結果推論到所有六個月大男嬰。

## 觀察與比較

### 為什麼身高的區間較寬？

**體重：**
- ME = 0.083 kg
- s = 0.30 kg（較小的變異）

**身高：**
- ME = 0.233 cm
- s = 0.64 cm（較大的變異）
- 99% 信賴水準（需要更高的 z*）

**兩個原因：**
1. 身高的標準差較大（0.64 vs 0.30）
2. 使用更高的信賴水準（99% vs 95%）


## 計算公式整理

### 信賴區間公式
```
x̄ ± z* × (s/√n)
```

### 本題應用

**體重（95%）：**
```
8.0 ± 1.96 × (0.30/√50)
= 8.0 ± 0.083
= (7.92, 8.08)
```

**身高（99%）：**
```
67.3 ± 2.576 × (0.64/√50)
= 67.3 ± 0.233
= (67.07, 67.53)
```
