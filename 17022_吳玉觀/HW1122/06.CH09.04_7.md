# Exercise 7 - Why Diet? (數學白癡版)

## 題目背景

**USA Today 調查：** 隨機抽樣 500 位女性，詢問她們考慮節食的原因

**調查結果：**
- 68% - 改善健康 (Improve my health)
- 51% - 看起來更好 (Look my best)
- 39% - 更有活力 (Have more energy)
- 20% - 樹立好榜樣 (Set a good example)
- 17% - 為了家人 (For my family)
- 11% - 其他 (Other)

*注意：受訪者可以選擇多個理由*

**研究問題：** 
> 我們能否得出結論：超過 60% 的女性考慮節食是為了「改善健康」？

---

## 🎯 整體理解

### 已知資訊

- **樣本數 n = 500**
- **樣本中選擇「改善健康」的比例 p̂ = 68% = 0.68**
- **要檢驗的門檻：p > 0.60（超過 60%）**

### 邏輯思路

樣本中 68% 選了「改善健康」，看起來確實超過 60%，但：
- 這個差異（68% vs 60%）是真的？
- 還是只是抽樣誤差造成的巧合？

**需要用統計檢驗來確認！**

---

## 題目 a：設定假設

### 🎯 這題在問什麼？

**「如何用統計語言表達『是否超過 60%』？」**

---

### 答案

**H₀（虛無假設）：p = 0.60**
- 恰好 60% 的女性會因「改善健康」而考慮節食
- 沒有超過 60%

**Hₐ（對立假設）：p > 0.60**
- 超過 60% 的女性會因「改善健康」而考慮節食
- 有超過 60%

### 📌 白話解釋

- **H₀：** 「只有 60% 會為健康節食，沒有更多」
- **Hₐ：** 「超過 60% 會為健康節食」

**這是右尾檢驗**（因為要看「是否大於」）

---

## 題目 b：計算檢定統計量與 p-value

### 🎯 這題在問什麼？

**「把數據轉成統計量，並找出拒絕域」**

---

### 計算步驟

#### 1️⃣ 確認數據

- **樣本數 n = 500**
- **樣本比例 p̂ = 0.68**
- **假設比例 p₀ = 0.60**

#### 2️⃣ 計算檢定統計量 z

**公式：**

$$z = \frac{\hat{p} - p_0}{\sqrt{\frac{p_0(1-p_0)}{n}}}$$

**步驟：**

**計算標準誤 (SE)：**

$$SE = \sqrt{\frac{p_0(1-p_0)}{n}} = \sqrt{\frac{0.60 \times 0.40}{500}} = \sqrt{\frac{0.24}{500}} = \sqrt{0.00048} \approx 0.0219$$

**計算 z：**

$$z = \frac{0.68 - 0.60}{0.0219} = \frac{0.08}{0.0219} \approx 3.65$$

### 📌 檢定統計量

**z ≈ 3.65**

---

#### 3️⃣ 計算 p-value

**p-value = P(Z > 3.65)**

查標準常態分配表：
- P(Z < 3.65) ≈ 0.9999
- P(Z > 3.65) = 1 - 0.9999 ≈ 0.0001

**p-value ≈ 0.0001 (或 < 0.0001)**

### 📌 p-value 的意義

> 「假設真實比例是 60%，我們觀察到 68% 或更高的機率只有 0.01%」
> 
> 這個機率極小，幾乎不可能是巧合！

---

#### 4️⃣ 找拒絕域 (α = 0.01)

**查表：**
- 這是右尾檢驗
- 顯著水準 α = 0.01
- 臨界值 **z₀.₀₁ = 2.326**

**拒絕域：**

$$RR = \{z : z > 2.326\}$$

**白話：** 如果 z > 2.326，就拒絕 H₀

---

### 📊 判斷結果

| 項目 | 數值 |
|------|------|
| 計算的 z | 3.65 |
| 臨界值 (α=0.01) | 2.326 |
| 比較 | 3.65 > 2.326 ✅ |
| p-value | 0.0001 |
| α | 0.01 |
| 比較 | 0.0001 < 0.01 ✅ |

**z = 3.65 > 2.326，落在拒絕域內！**

**∴ 拒絕 H₀**

---

## 題目 c：結論

### 🎯 這題在問什麼？

**「根據 part b 的結果，我們對 p 能下什麼結論？」**

---

### 答案

**結論：拒絕 H₀，接受 Hₐ**

### 📌 白話結論

> **是的，我們有充分證據得出結論：超過 60% 的女性考慮節食是為了改善健康。**

### 詳細解釋

1. **樣本數據：** 68% 的女性選擇「改善健康」
2. **統計檢驗：** z = 3.65，p-value < 0.0001
3. **顯著性：** 在 α = 0.01 的嚴格標準下仍然顯著
4. **結論：** 真實比例 p 顯著大於 60%

### 這意味著什麼？

- ✅ 不只是樣本巧合，而是真實趨勢
- ✅ 「改善健康」確實是女性考慮節食的主要原因
- ✅ 真實比例很可能在 60% 以上（我們的樣本估計是 68%）

---

## 📊 完整結果總整理

| 項目 | 數值 |
|:-----|:------|
| 樣本數 (n) | 500 |
| 樣本比例 (p̂) | 0.68 (68%) |
| 假設比例 (p₀) | 0.60 (60%) |
| 標準誤 (SE) | 0.0219 |
| 檢定統計量 (z) | 3.65 |
| 臨界值 (α=0.01) | 2.326 |
| 拒絕域 | z > 2.326 |
| p-value | < 0.0001 |
| 決策 | **拒絕 H₀** |

### 最終結論

✅ **超過 60% 的女性考慮節食是為了改善健康**
- 樣本顯示 68%
- 統計上高度顯著 (p < 0.0001)
- 即使用嚴格標準 (α = 0.01) 仍然顯著

---

## 🎓 深入理解

### 為什麼 α = 0.01？

題目要求用 **α = 0.01**，這比一般的 α = 0.05 更嚴格：

| 顯著水準 | 意義 | 錯誤風險 |
|:---:|:---|:---|
| α = 0.05 | 一般標準 | 5% 機會誤判 |
| α = 0.01 | 嚴格標準 | 1% 機會誤判 |

**使用嚴格標準的原因：**
- 減少「假陽性」（錯誤地說有差異）
- 讓結論更可靠
- 這題即使用嚴格標準，仍然顯著！

---

### z = 3.65 有多極端？

讓我們視覺化：
```
              標準常態分配
                  
    -3    -2    -1    0    1    2    3   3.65
    |-----|-----|-----|-----|-----|-----|--→
                              ↑        ↑
                           α=0.05  α=0.01
                          (1.645) (2.326)
                          
    我們的 z=3.65 在這裡 ↗
    (非常極端！)
```

**z = 3.65 的意義：**
- 偏離假設值 3.65 個標準差
- 在標準常態分配下，這是極端罕見的
- 出現機率 < 0.01%

---

### p-value < 0.0001 代表什麼？

**白話翻譯：**

> 「如果真實比例是 60%，我們看到 68% 或更高的機率不到萬分之一」

這麼小的機率告訴我們：
- 🚫 不太可能是隨機誤差
- ✅ 更可能是真實比例確實 > 60%
- 💪 這是非常強的證據

## 🤔 常見問題

### Q1: 為什麼不用 t 分配？

**A:** 因為這是**比例檢驗**，不是平均數檢驗
- 比例檢驗用 **z 分配**
- 平均數檢驗才用 **t 分配**

### Q2: 樣本比例 68% 就是真實比例嗎？

**A:** 不一定！
- 68% 是樣本估計
- 真實比例可能在 65-71% 之間
- 但我們有 99% 信心說：真實比例 > 60%

### Q3: 為什麼用右尾檢驗？

**A:** 因為問題是「是否**超過** 60%」
- 超過 = 大於 = 右尾
- 小於 = 左尾
- 不等於 = 雙尾

## ✅ 完整解題流程
```
a. 設假設
   H₀: p = 0.60
   Hₐ: p > 0.60

   z = (0.68 - 0.60) / 0.0219 = 3.65

   拒絕域: z > 2.326

c. 下結論
   z = 3.65 > 2.326 ✅
   拒絕 H₀

```
