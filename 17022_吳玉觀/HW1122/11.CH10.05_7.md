# Exercise 7 - Right-Tailed Test for Population Variance

## Problem Statement

**Given:**
- n = 25
- x̄ = 126.3
- s² = 21.4
- H₀: σ² = 15 versus Hₐ: σ² > 15
- α = 0.05

**Tasks:**
1. Test the hypothesis
2. Construct a 95% confidence interval for σ²

---

## Solution

### (1) Hypothesis Testing

**This is a right-tailed test**

**Test Statistic:**

$$\chi^2_{STAT} = \frac{(n-1)s^2}{\sigma_0^2} = \frac{(25-1) \times 21.4}{15} = \frac{513.6}{15} = 34.24$$

**Critical Value:**
- df = n - 1 = 24
- α = 0.05
- χ²₀.₀₅,₂₄ = 36.415

**Rejection Region:**

$$RR = \{\chi^2 : \chi^2 > 36.415\}$$

**Decision:**

Since χ² = 34.24 < 36.415 (does not fall in RR),

**∴ Do not reject H₀**

**Conclusion:** There is insufficient evidence at the 0.05 significance level to conclude that the population variance is greater than 15.

---

### (2) 95% Confidence Interval for σ²

For a right-tailed test, the confidence interval is:

$$\left[\frac{(n-1)s^2}{\chi^2_{(n-1), \alpha}}, \infty\right)$$

**Calculation:**

$$\left[\frac{24 \times 21.4}{36.415}, \infty\right) = \left[\frac{513.6}{36.415}, \infty\right) \approx [14.10, \infty)$$

**Result: 95% CI for σ² = [14.10, ∞)**

---

## Summary

| Item | Value |
|:-----|:------|
| Sample Size (n) | 25 |
| Sample Mean (x̄) | 126.3 |
| Sample Variance (s²) | 21.4 |
| Test Statistic (χ²) | 34.24 |
| Critical Value | χ²₀.₀₅,₂₄ = 36.415 |
| Decision | Do not reject H₀ |
| 95% CI for σ² | [14.10, ∞) |

**Interpretation:** The sample does not provide sufficient evidence that the population variance exceeds 15. The 95% confidence interval suggests the true variance could be as low as 14.10, which includes the hypothesized value of 15.
