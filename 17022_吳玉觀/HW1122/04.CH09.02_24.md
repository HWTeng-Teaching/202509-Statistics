# Exercise 24 - O Baby!

## 題目背景

**已知資訊：**
- 3 個月大女嬰的平均體重是 5.86 公斤（全國數據）

**某市區兒科診所的懷疑：**
- 他們診所的 3 個月大女嬰平均體重可能低於 5.86 公斤

**實際調查：**
- 隨機抽樣 n = 40 位 3 個月大女嬰
- 樣本平均體重 x̄ = 5.56 公斤
- 樣本標準差 s = 0.70 公斤

**問題：** 數據是否顯示這個診所的嬰兒平均體重確實較低？

---

## 🎯 整體理解

### 情境分析

**全國平均：** 5.86 公斤
**診所樣本：** 5.56 公斤

**差異：** 5.86 - 5.56 = 0.30 公斤（輕了 300 克）

**問題：**
- 這 0.3 公斤的差異是真的（診所嬰兒較輕）？
- 還是只是隨機誤差？

**醫學意義：**
- 如果確實較輕 → 可能反映該地區營養、健康問題
- 需要進一步調查原因

---

## 題目 a：假設檢驗 (α = 0.05)

### 🎯 這題在問什麼？

**「診所嬰兒的平均體重是否顯著低於 5.86 公斤？」**

---

## 解題步驟

### Step 1: 設定假設

**H₀（虛無假設）：μ = 5.86 公斤**
- 診所嬰兒的平均體重等於全國平均
- 沒有差異

**Hₐ（對立假設）：μ < 5.86 公斤**
- 診所嬰兒的平均體重低於全國平均
- 有差異

**這是左尾檢驗**（檢查是否較輕）

---

### Step 2: 整理數據

| 項目 | 數值 |
|------|------|
| 全國平均 (μ₀) | 5.86 kg |
| 樣本數 (n) | 40 |
| 樣本平均 (x̄) | 5.56 kg |
| 樣本標準差 (s) | 0.70 kg |
| 顯著水準 (α) | 0.05 |

---

### Step 3: 計算檢定統計量 t

**公式：**

$$t = \frac{\bar{x} - \mu_0}{s / \sqrt{n}}$$

#### 1️⃣ 計算標準誤 (SE)

$$SE = \frac{s}{\sqrt{n}} = \frac{0.70}{\sqrt{40}} = \frac{0.70}{6.325} \approx 0.1107$$

#### 2️⃣ 計算 t 統計量

$$t = \frac{5.56 - 5.86}{0.1107} = \frac{-0.30}{0.1107} \approx -2.71$$

### 📌 檢定統計量

**t ≈ -2.71**

---

### Step 4: 查表找臨界值

**查 t 分配表：**
- 自由度 df = n - 1 = 39
- 顯著水準 α = 0.05（左尾）
- 臨界值 **t₀.₀₅,₃₉ ≈ -1.685**

---

### Step 5: 拒絕域

$$RR = \{t : t < -1.685\}$$

**白話：** 如果 t < -1.685，就拒絕 H₀

---

### Step 6: 判斷

| 項目 | 數值 |
|------|------|
| 計算的 t | -2.71 |
| 臨界值 | -1.685 |
| 比較 | -2.71 < -1.685 ✅ |

**t = -2.71 落在拒絕域內！**

---

### 📌 題目 a 結論

**∴ 拒絕 H₀**

### 白話結論

> **是的，數據顯示該診所 3 個月大女嬰的平均體重顯著低於全國平均 5.86 公斤。**
> 
> 在 α = 0.05 的顯著水準下，我們有充分證據支持診所的懷疑。

---

## 題目 b：計算 p-value

### 🎯 這題在問什麼？

**「這個結果的 p-value 是多少？能否用 p-value 法得到相同結論？」**

---

### 計算 p-value

對於 t = -2.71，df = 39：

**查表或用計算機：**

**p-value = P(T < -2.71) ≈ 0.005**

（介於 0.005 和 0.01 之間）

---

### 用 p-value 判斷

#### 判斷準則

- 如果 p-value < α → 拒絕 H₀
- 如果 p-value ≥ α → 不拒絕 H₀

#### 比較

| 項目 | 數值 |
|------|------|
| p-value | 0.005 |
| α | 0.05 |
| 比較 | 0.005 < 0.05 ✅ |

**p-value < α，所以拒絕 H₀**

---

### 📌 題目 b 答案

**p-value ≈ 0.005**

**能否用 p-value 拒絕 H₀？**
- ✅ **是的，可以拒絕 H₀**
- p-value (0.005) < α (0.05)
- 結論與 part a 完全一致

---

### p-value 的意義

**白話翻譯：**

> 「如果診所嬰兒的真實平均體重確實是 5.86 公斤，我們觀察到 5.56 公斤或更輕的機率只有 0.5%」

這個機率極小，所以：
- 🚫 不太可能是隨機誤差
- ✅ 更可能是診所嬰兒真的較輕

---

## 📊 完整結果總整理

| 項目 | 數值 |
|:-----|:------|
| 假設 | H₀: μ = 5.86 vs Hₐ: μ < 5.86 |
| 樣本數 (n) | 40 |
| 樣本平均 (x̄) | 5.56 kg |
| 樣本標準差 (s) | 0.70 kg |
| 標準誤 (SE) | 0.1107 kg |
| t 統計量 | -2.71 |
| 自由度 (df) | 39 |
| 臨界值 (α=0.05) | -1.685 |
| 拒絕域 | t < -1.685 |
| p-value | ≈ 0.005 |
| 決策 | **拒絕 H₀** |

### 最終結論

✅ **診所的 3 個月大女嬰平均體重顯著低於全國平均**
- 全國平均：5.86 kg
- 診所平均：5.56 kg
- 差異：0.30 kg（300 克）
- 統計上高度顯著 (t = -2.71, p = 0.005)

---

## 🎓 深入理解

### 為什麼 0.3 公斤的差異很顯著？

**表面上看：**
- 5.86 kg vs 5.56 kg
- 只差 300 克（約 5%）

**但統計上看：**
- 標準差 0.70 kg
- 樣本數 40 個
- 標準誤只有 0.11 kg
- 所以 0.3 kg = **2.71 個標準誤**
- 這是顯著的差異！

---

### t = -2.71 有多極端？

視覺化：
```
         t 分配 (df=39)
              
   -3   -2.71  -2   -1.685  0    1    2
   |-----|-----|-----|------|-----|-----|
         ↑           ↑
      我們的 t   臨界值 α=0.05
      
   拒絕域 ←---------------
```

**t = -2.71 的意義：**
- 偏離假設值 2.71 個標準誤
- 機率只有 0.5%
- 強烈證據證明確實較輕

---

### 兩種方法對照

#### 方法 1：臨界值法 (part a)
```
1. 算 t = -2.71
2. 查表找臨界值 = -1.685
3. 比較：-2.71 < -1.685 ✅
4. 結論：拒絕 H₀
```

#### 方法 2：p-value 法 (part b)
```
1. 算 t = -2.71
2. 查表找 p-value = 0.005
3. 比較：0.005 < 0.05 ✅
4. 結論：拒絕 H₀
```

**兩種方法結論永遠一致！** ✓

## 🤔 常見問題

### Q1: p-value = 0.005 很小嗎？

**A:** 非常小！

| p-value | 證據強度 |
|:---:|:---|
| > 0.10 | 無證據 |
| 0.05-0.10 | 弱證據 |
| 0.01-0.05 | 中等證據 |
| 0.001-0.01 | 強證據 |
| < 0.001 | 極強證據 |

**我們的 p = 0.005** → 強證據！

### Q2: 如果用 α = 0.01 會怎樣？

**A:** 讓我們看看：
- p-value = 0.005
- α = 0.01
- 0.005 < 0.01 ✅
- **仍然拒絕 H₀**！

即使用更嚴格標準，結論不變！

### Q3: 為什麼用 t 分配？

**A:** 因為：
- ❌ 母體標準差 σ 未知
- ✅ 只有樣本標準差 s = 0.70
- ✅ 樣本數 n = 40（中等樣本）

雖然 n=40 已經接近大樣本，但標準做法還是用 t 分配

## ✅ 完整答案總結

### a. 假設檢驗

**Hypotheses:**
- H₀: μ = 5.86 kg
- Hₐ: μ < 5.86 kg (left-tailed test)

**Test Statistic:**

$$t = \frac{5.56 - 5.86}{0.70/\sqrt{40}} = \frac{-0.30}{0.1107} \approx -2.71$$

**Critical Value:** t₀.₀₅,₃₉ ≈ -1.685

**Decision:** Since t = -2.71 < -1.685, we reject H₀

**Conclusion:** 

Yes, the data indicate that the average weight of 3-month-old baby girls at this facility is significantly less than 5.86 kilograms at the α = 0.05 level.

---

### b. p-value

**p-value ≈ 0.005**

**Can we reject H₀ using p-value?**

Yes, we can reject H₀ at the 5% level of significance using the p-value method because:
- p-value (0.005) < α (0.05)

This confirms the conclusion from part a. The p-value indicates strong evidence against the null hypothesis.
