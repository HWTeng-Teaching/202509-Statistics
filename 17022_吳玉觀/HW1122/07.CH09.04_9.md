# Exercise 9 - New Tax Laws

## 題目背景

**新稅法的目標：** 幫助小企業存活

**已知資訊：**
- 目前有 20% 的小企業在第一年倒閉
- 研究抽樣了 n = 200 家新開的小企業
- 追蹤一年後，發現 30 家倒閉

**要檢驗：** 新稅法是否真的有幫助？（失敗率是否降低？）

---

## 🎯 整體概念理解

### 邏輯思路

**如果新稅法有效：**
- 失敗率應該「低於」20%
- 也就是說，p < 0.20

**我們的樣本數據：**
- 200 家中有 30 家倒閉
- 樣本失敗率 p̂ = 30/200 = 0.15 = 15%

**問題：**
> 這個 15% 是真的比 20% 低（稅法有效），還是只是隨機誤差？

---

## 題目 a：設定假設

### 🎯 這題在問什麼？

**「如何用統計語言表達『稅法是否有幫助』？」**

---

### 答案

**H₀（虛無假設）：p = 0.20**
- 失敗率沒有改變
- 新稅法沒有幫助

**Hₐ（對立假設）：p < 0.20**
- 失敗率降低了
- 新稅法有幫助

### 📌 白話解釋

- **H₀：** 「稅法沒用，失敗率還是 20%」
- **Hₐ：** 「稅法有用，失敗率降到低於 20%」

**這是左尾檢驗**（因為要看「是否變小」）

---

## 題目 b：計算檢定統計量

### 🎯 這題在問什麼？

**「把樣本數據轉換成一個可以判斷的數字」**

---

### 計算步驟

#### 1️⃣ 樣本比例

$$\hat{p} = \frac{30}{200} = 0.15$$

#### 2️⃣ 檢定統計量公式（z 檢定）

對於比例檢驗，使用：

$$z = \frac{\hat{p} - p_0}{\sqrt{\frac{p_0(1-p_0)}{n}}}$$

其中：
- p̂ = 0.15（樣本失敗率）
- p₀ = 0.20（假設的失敗率）
- n = 200（樣本數）

#### 3️⃣ 計算標準誤 (SE)

$$SE = \sqrt{\frac{p_0(1-p_0)}{n}} = \sqrt{\frac{0.20 \times 0.80}{200}} = \sqrt{\frac{0.16}{200}} = \sqrt{0.0008} \approx 0.0283$$

#### 4️⃣ 計算 z 統計量

$$z = \frac{0.15 - 0.20}{0.0283} = \frac{-0.05}{0.0283} \approx -1.77$$

### 📌 答案

**檢定統計量 z ≈ -1.77**

---

## 題目 c：拒絕域與結論

### 🎯 這題在問什麼？

**「在 α = 0.05 的標準下，什麼情況會拒絕 H₀？新稅法有效嗎？」**

---

### 解題步驟

#### 1️⃣ 查表找臨界值

- 這是**左尾檢驗**
- 顯著水準 α = 0.05
- 查標準常態分配表：**z₀.₀₅ = -1.645**

#### 2️⃣ 拒絕域

$$RR = \{z : z < -1.645\}$$

**白話：** 如果 z 比 -1.645 還要負（更左邊），就拒絕 H₀

#### 3️⃣ 判斷

| 項目 | 數值 |
|------|------|
| 計算的 z | -1.77 |
| 臨界值 | -1.645 |
| 比較 | -1.77 < -1.645 ✅ |

**z = -1.77 落在拒絕域內！**

#### 4️⃣ 結論

**∴ 拒絕 H₀**

### 📌 白話結論

> **是的，我們可以得出結論：在 α = 0.05 的顯著水準下，新稅法確實幫助小企業存活。**
> 
> 失敗率從 20% 顯著降低到約 15%。

---

## 題目 d：計算 p-value

### 🎯 這題在問什麼？

**「得到這個結果的機率有多小？會不會改變結論？」**

---

### 什麼是 p-value？

**白話解釋：**
> 「假設 H₀ 是對的（失敗率還是 20%），我們觀察到『15% 或更低』失敗率的機率有多大？」

- p-value 越小 → 越不可能是巧合 → 越有理由拒絕 H₀
- p-value 越大 → 可能是巧合 → 沒理由拒絕 H₀

---

### 計算步驟

#### 1️⃣ 找 p-value

我們的 z = -1.77

**p-value = P(Z < -1.77)**

查標準常態分配表或用計算機：

**p-value ≈ 0.0384**

#### 2️⃣ 判斷準則

- 如果 p-value < α → 拒絕 H₀
- 如果 p-value ≥ α → 不拒絕 H₀

#### 3️⃣ 比較

| 項目 | 數值 |
|------|------|
| p-value | 0.0384 |
| α | 0.05 |
| 比較 | 0.0384 < 0.05 ✅ |

**p-value < α，所以拒絕 H₀**

### 📌 答案

**p-value ≈ 0.0384**

**結論是否改變？** 
- ❌ **沒有改變**
- 用 p-value 方法和用拒絕域方法，結論一樣
- 都是「拒絕 H₀，稅法有效」

---

## 📊 完整結果總整理

| 項目 | 數值 |
|:-----|:------|
| 樣本數 (n) | 200 |
| 失敗企業數 | 30 |
| 樣本失敗率 (p̂) | 0.15 (15%) |
| 假設失敗率 (p₀) | 0.20 (20%) |
| 標準誤 (SE) | 0.0283 |
| 檢定統計量 (z) | -1.77 |
| 臨界值 (α=0.05) | -1.645 |
| 拒絕域 | z < -1.645 |
| p-value | 0.0384 |
| 決策 | **拒絕 H₀** |

### 最終結論

✅ **新稅法顯著降低了小企業的失敗率**
- 從 20% 降到 15%
- 統計上具有顯著性（p = 0.0384 < 0.05）
- 新稅法確實幫助小企業存活

## 🎓 詳細解釋各部分

### a. 假設設定的邏輯
```
問題：稅法是否有幫助？
    ↓
轉換：失敗率是否降低？
    ↓
統計語言：
  H₀: p = 0.20 (沒降低)
  Hₐ: p < 0.20 (有降低)
```

### b. 為什麼用 z 檢定？

**因為：**
- 這是**比例檢驗**，不是平均數檢驗
- 樣本數 n = 200 夠大
- 比例的抽樣分配接近常態分配
- 所以用 z 統計量（不是 t 統計量）

### c. 拒絕域的視覺化
```
        拒絕域          |    接受域
   ←---------------[-1.645]------------→
              ↑
             z=-1.77 在這裡
             (落在拒絕域內)
```

### d. p-value 的意義

**p-value = 0.0384 = 3.84%**

意思是：
> 「如果失敗率真的是 20%，我們只有 3.84% 的機會看到 15% 或更低的失敗率」

這個機率很小（< 5%），所以我們認為：
- 不太可能是巧合
- 更可能是稅法真的有效

---

## 💡 兩種判斷方法對照

### 方法 1：臨界值法（題目 c）
```
1. 算 z = -1.77
2. 查表找臨界值 = -1.645
3. 比較：-1.77 < -1.645
4. 結論：拒絕 H₀
```

### 方法 2：p-value 法（題目 d）
```
1. 算 z = -1.77
2. 查表找 p-value = 0.0384
3. 比較：0.0384 < 0.05
4. 結論：拒絕 H₀
```

**兩種方法結論永遠一致！** ✓
