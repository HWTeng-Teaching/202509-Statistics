# Exercise 25 - Potency of an Antibiotic

## 題目背景

**藥廠聲稱：** 某抗生素的平均效力是 80%

**實際測試：**
- 隨機抽樣 n = 100 顆膠囊
- 樣本平均效力 x̄ = 79.7%
- 樣本標準差 s = 0.8%

**問題：** 這些數據是否足以推翻藥廠的聲稱？（α = 0.05）

---

## 🎯 整體理解

### 情境分析

**藥廠說：** 平均效力是 80%
**實測結果：** 平均只有 79.7%

**問題：**
- 79.7% 比 80% 低了 0.3%
- 這個差異是真的（藥廠說謊）？
- 還是只是隨機誤差（藥廠沒說謊）？

**關鍵詞：「refute（推翻）」**
- 我們要看數據能否證明藥廠是錯的
- 也就是證明真實效力 < 80%

---

## 題目 a：虛無假設

### 🎯 這題在問什麼？

**「用統計語言表達『藥廠的聲稱』」**

---

### 答案

**H₀（虛無假設）：μ = 80%**

或更正式地寫：

**H₀: μ = 0.80**

### 📌 白話解釋

> 「假設藥廠說的是對的，抗生素的真實平均效力確實是 80%」

**這是我們要測試的『預設立場』**

---

## 題目 b：對立假設

### 🎯 這題在問什麼？

**「我們想證明什麼？」**

---

### 答案

**Hₐ（對立假設）：μ < 80%**

或：

**Hₐ: μ < 0.80**

### 📌 白話解釋

> 「我們懷疑真實效力低於 80%，藥廠的聲稱是誇大的」

**這是左尾檢驗**（因為要證明「小於」）

---

## 題目 c：進行統計檢驗

### 🎯 這題在問什麼？

**「用數據來判斷能否推翻藥廠的聲稱」**

---

## 解題步驟

### Step 1: 整理已知資訊

| 項目 | 數值 |
|------|------|
| 聲稱的效力 (μ₀) | 80% = 0.80 |
| 樣本數 (n) | 100 |
| 樣本平均 (x̄) | 79.7% = 0.797 |
| 樣本標準差 (s) | 0.8% = 0.008 |
| 顯著水準 (α) | 0.05 |

---

### Step 2: 計算檢定統計量 t

**公式：**

$$t = \frac{\bar{x} - \mu_0}{s / \sqrt{n}}$$

#### 1️⃣ 計算標準誤 (SE)

$$SE = \frac{s}{\sqrt{n}} = \frac{0.008}{\sqrt{100}} = \frac{0.008}{10} = 0.0008$$

#### 2️⃣ 計算 t 統計量

$$t = \frac{0.797 - 0.80}{0.0008} = \frac{-0.003}{0.0008} = -3.75$$

### 📌 檢定統計量

**t = -3.75**

---

### Step 3: 查表找臨界值

**查 t 分配表：**
- 自由度 df = n - 1 = 99
- 顯著水準 α = 0.05（左尾）
- 臨界值 **t₀.₀₅,₉₉ ≈ -1.660**

（df=99 很大，接近標準常態，所以用 -1.645 也可以）

---

### Step 4: 拒絕域

$$RR = \{t : t < -1.660\}$$

**白話：** 如果 t < -1.660（更負），就拒絕 H₀

---

### Step 5: 判斷

| 項目 | 數值 |
|------|------|
| 計算的 t | -3.75 |
| 臨界值 | -1.660 |
| 比較 | -3.75 < -1.660 ✅ |

**t = -3.75 遠遠落在拒絕域內！**

---

### Step 6: 計算 p-value（額外）

對於 t = -3.75，df = 99：

**p-value < 0.001**（極小）

這意味著：
> 「如果藥廠說的是真的，我們看到 79.7% 或更低的機率不到 0.1%」

---

## 📌 結論

### 統計決策

**∴ 拒絕 H₀**

### 白話結論

> **是的，數據提供了充分證據來推翻藥廠的聲稱。**
> 
> 在 α = 0.05 的顯著水準下，我們有足夠理由相信：抗生素的真實平均效力顯著低於 80%。

---

## 📊 完整結果總整理

| 項目 | 數值 |
|:-----|:------|
| 假設 | H₀: μ = 0.80 vs Hₐ: μ < 0.80 |
| 樣本數 (n) | 100 |
| 樣本平均 (x̄) | 79.7% = 0.797 |
| 樣本標準差 (s) | 0.8% = 0.008 |
| 標準誤 (SE) | 0.0008 |
| t 統計量 | -3.75 |
| 自由度 (df) | 99 |
| 臨界值 (α=0.05) | -1.660 |
| 拒絕域 | t < -1.660 |
| p-value | < 0.001 |
| 決策 | **拒絕 H₀** |

### 最終答案

✅ **藥廠的聲稱被推翻了**
- 真實效力顯著低於 80%
- 樣本顯示約 79.7%
- 統計上高度顯著 (t = -3.75, p < 0.001)

---

## 🎓 深入理解

### 為什麼差異看起來很小卻很顯著？

**表面上看：**
- 80% vs 79.7%，只差 0.3%
- 好像沒什麼大不了？

**但統計上看：**
- 標準差只有 0.8%
- 樣本數有 100 個
- 標準誤只有 0.08%
- 所以 0.3% 的差異其實是 **3.75 個標準誤**
- 這是非常大的差異！

---

### t = -3.75 有多極端？

視覺化：
```
         t 分配 (df=99)
              
   -4   -3.75  -2   -1.66  0    1    2
   |-----|-----|-----|-----|-----|-----|
         ↑           ↑
      我們的 t   臨界值 α=0.05
      
   拒絕域 ←----------
```

**t = -3.75 的意義：**
- 偏離假設值 3.75 個標準誤
- 在 t 分配下極端罕見
- 強烈證據證明藥廠誇大了

---

### 為什麼用左尾檢驗？

**關鍵字：「refute（推翻）」**
```
問題邏輯：
  藥廠說 80% → 我們懷疑實際更低
              ↓
           要證明 μ < 80%
              ↓
          左尾檢驗 ✓
```

**如果用雙尾檢驗：**
- 會檢驗「是否不等於 80%」
- 但題目明確要「推翻」（證明更低）
- 所以用左尾更合適

## 🤔 常見問題

### Q1: 為什麼用 t 分配而不是 z 分配？

**A:** 因為：
- ❌ 母體標準差 σ 未知
- ✅ 只有樣本標準差 s = 0.8%
- ✅ 雖然 n = 100（算大樣本），但標準做法還是用 t

*註：因為 n=100 很大，t 分配已經很接近 z 分配了*

### Q2: 如果用 α = 0.01 會怎樣？

**A:** 讓我們算算看：
- 臨界值變成 t₀.₀₁,₉₉ ≈ -2.364
- 我們的 t = -3.75 < -2.364
- **仍然拒絕 H₀**！

即使用更嚴格標準，結論不變！

### Q3: 79.7% 算好還是不好？

**A:** 這要看標準：
- 對比聲稱值 80% → 不達標 ❌
- 對於抗生素效力 → 79.7% 其實還不錯 ✓
- 但誠信問題 → 廣告不實 ❌

## ✅ 完整答案總結

### a. 虛無假設

**H₀: μ = 80% (or μ = 0.80)**

The null hypothesis states that the true mean potency of the antibiotic is 80%, as claimed by the manufacturer.

### b. 對立假設

**Hₐ: μ < 80% (or μ < 0.80)**

The alternative hypothesis states that the true mean potency is less than 80%. This is a left-tailed test.

### c. 統計檢驗與結論

**Test Statistic:**

$$t = \frac{79.7 - 80}{0.8/\sqrt{100}} = \frac{-0.3}{0.08} = -3.75$$

**Critical Value:** t₀.₀₅,₉₉ ≈ -1.660

**Decision:** Since t = -3.75 < -1.660, we reject H₀

**Conclusion:** 

Yes, the data present sufficient evidence to refute the manufacturer's claim at the α = 0.05 significance level. The sample data indicates that the true mean potency of the antibiotic is significantly less than the claimed 80%.
