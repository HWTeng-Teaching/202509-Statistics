# Exercise 30 - Bulimia Treatment Study

## 研究背景

**British Journal of Clinical Psychology** 的一篇文章研究：自尊心（self-esteem）是否能預測暴食症治療效果。

研究追蹤病患在三個時間點的自尊分數：
- **治療前（Pretreatment）**
- **治療後（Posttreatment）**
- **追蹤期（Follow-up）**

---

## 📊 數據

|  | Pretreatment | Posttreatment | Follow-up |
|:---|:---:|:---:|:---:|
| **樣本平均數 x̄** | 20.3 | 26.6 | 27.7 |
| **標準差 s** | 5.0 | 7.4 | 8.2 |
| **樣本數 n** | 21 | 21 | 20 |

---

## 題目 a：檢驗治療前平均分數是否 < 25

### 🎯 這題在問什麼？

**「治療前病患的自尊分數，是不是真的低於 25？」**

- 樣本平均是 20.3（看起來確實 < 25）
- 但這個差距是真的，還是只是隨機誤差？

---

### 解題步驟

#### 1️⃣ 設定假設

- **H₀（虛無假設）**: μ = 25（平均分數等於 25）
- **Hₐ（對立假設）**: μ < 25（平均分數小於 25）
- **α = 0.05**（通常預設值，題目沒給就用這個）

這是**左尾檢驗**（因為要看「是否小於」）

#### 2️⃣ 計算檢定統計量 t

**公式：**

$$t = \frac{\bar{x} - \mu_0}{s / \sqrt{n}}$$

**代入數字：**

$$t = \frac{20.3 - 25}{5.0 / \sqrt{21}} = \frac{-4.7}{5.0 / 4.583} = \frac{-4.7}{1.091} \approx -4.31$$

#### 3️⃣ 查表找臨界值

- 自由度 df = n - 1 = 20
- α = 0.05（左尾）
- 查 t 分配表：**t₀.₀₅,₂₀ = -1.725**

**門檻的意思：**
> 如果你的 t 值 < -1.725（更負），就代表差異夠大，可以說平均分數真的 < 25

#### 4️⃣ 比較並下結論

| 項目 | 數值 |
|------|------|
| 計算出的 t | -4.31 |
| 臨界值 | -1.725 |
| 比較結果 | -4.31 < -1.725 ✅ 超過門檻！ |

**拒絕域：** RR = {t < -1.725}

**判斷：** t = -4.31 落在拒絕域內

**∴ 拒絕 H₀**

#### 📌 白話結論

> **有足夠證據顯示：治療前病患的真實平均自尊分數確實低於 25。**
> 
> 樣本平均 20.3 跟假設值 25 的差距夠大，不太可能是隨機造成的。

---

## 題目 b：建立治療後平均分數的 95% 信賴區間

### 🎯 這題在問什麼？

**「治療後，病患的真實平均自尊分數大概在什麼範圍？」**

---

### 解題步驟

#### 1️⃣ 使用的數據

- x̄ = 26.6（治療後平均）
- s = 7.4（治療後標準差）
- n = 21（樣本數）

#### 2️⃣ 信賴區間公式

$$\left[\bar{x} - t_{\alpha/2} \times \frac{s}{\sqrt{n}}, \bar{x} + t_{\alpha/2} \times \frac{s}{\sqrt{n}}\right]$$

#### 3️⃣ 查表找臨界值

- 自由度 df = 20
- α/2 = 0.025（雙尾）
- 查表：**t₀.₀₂₅,₂₀ = 2.086**

#### 4️⃣ 計算標準誤

$$SE = \frac{s}{\sqrt{n}} = \frac{7.4}{\sqrt{21}} = \frac{7.4}{4.583} \approx 1.615$$

#### 5️⃣ 計算信賴區間

**誤差範圍（Margin of Error）：**

$$ME = t_{\alpha/2} \times SE = 2.086 \times 1.615 \approx 3.37$$

**信賴區間：**

$$[26.6 - 3.37, 26.6 + 3.37] = [23.23, 29.97]$$

#### 📌 白話結論

> **我們有 95% 的信心說：治療後病患的真實平均自尊分數介於 23.23 到 29.97 之間。**

---

## 題目 c：觀察三個時期平均數的差異

### 🎯 這題在問什麼？

**「不做統計檢定，光看數據，你覺得三個時期的平均分數有什麼不同？」**

---

### 📊 三個時期的數據比較

| 時期 | 平均數 x̄ | 標準差 s | 樣本數 n |
|:---|:---:|:---:|:---:|
| **治療前** | 20.3 | 5.0 | 21 |
| **治療後** | 26.6 | 7.4 | 21 |
| **追蹤期** | 27.7 | 8.2 | 20 |

### 📈 觀察到的趨勢

#### 1️⃣ 平均數變化
```
治療前 → 治療後：20.3 → 26.6（增加 6.3 分，+31%）
治療後 → 追蹤期：26.6 → 27.7（增加 1.1 分，+4%）
```

**趨勢：自尊分數持續上升** ✅

#### 2️⃣ 標準差變化
```
治療前：5.0
治療後：7.4（增加 48%）
追蹤期：8.2（增加 64%）
```

**趨勢：個體差異越來越大** 📊

### 🤔 可能的解釋

#### 平均數上升 = 治療有效

- 治療前自尊分數很低（20.3）
- 治療後大幅提升（26.6）
- 追蹤期維持並微幅上升（27.7）

**結論：治療確實改善了病患的自尊心**

#### 標準差增加 = 效果因人而異

**治療前（s=5.0）：** 大家都差不多低
- 病患們的自尊分數比較集中
- 範圍大約：20.3 ± 5 = [15.3, 25.3]

**治療後（s=7.4）：** 有人進步多，有人進步少
- 有些人自尊大幅提升
- 有些人進步較少
- 範圍大約：26.6 ± 7.4 = [19.2, 34.0]

**追蹤期（s=8.2）：** 差異更大
- 有些人持續進步
- 有些人可能退步
- 範圍大約：27.7 ± 8.2 = [19.5, 35.9]

### 📌 非正式結論（不用統計檢定）

> 1. **治療有效**：平均自尊分數從 20.3 提升到 27.7，增加約 36%
> 
> 2. **效果持久**：追蹤期分數維持在高水平，沒有明顯下降
> 
> 3. **個體差異大**：治療效果因人而異，有些人獲益多，有些人獲益少
> 
> 4. **需要進一步分析**：在 10.3 節會學到比較多組平均數的正式方法（可能是 ANOVA）

## 📊 完整結果總整理

### 題目 a：治療前平均 < 25？

| 項目 | 數值 |
|:-----|:------|
| 樣本平均 (x̄) | 20.3 |
| 假設值 (μ₀) | 25 |
| 標準差 (s) | 5.0 |
| 樣本數 (n) | 21 |
| t 統計量 | -4.31 |
| 臨界值 | t₀.₀₅,₂₀ = -1.725 |
| 判斷 | **拒絕 H₀** |

**結論：✅ 有充分證據顯示治療前平均自尊分數顯著低於 25**

### 題目 b：治療後平均的 95% 信賴區間

| 項目 | 數值 |
|:-----|:------|
| 樣本平均 (x̄) | 26.6 |
| 標準差 (s) | 7.4 |
| 樣本數 (n) | 21 |
| 標準誤 (SE) | 1.615 |
| t 臨界值 | t₀.₀₂₅,₂₀ = 2.086 |
| 誤差範圍 (ME) | 3.37 |
| **95% CI** | **[23.23, 29.97]** |

**結論：✅ 95% 信心水準下，治療後真實平均自尊分數介於 23.23 到 29.97**

### 題目 c：三個時期的差異

| 時期 | 平均數變化 | 標準差變化 | 觀察 |
|:---|:---:|:---:|:---|
| 治療前 → 治療後 | +6.3 (+31%) | +2.4 (+48%) | 顯著改善 |
| 治療後 → 追蹤期 | +1.1 (+4%) | +0.8 (+11%) | 持續微幅改善 |

**非正式結論：**
- ✅ 治療顯著提升自尊分數
- ✅ 效果在追蹤期持續存在
- ⚠️ 個體間差異隨時間增加（治療效果因人而異）

---

## 💡 重點名詞解釋

| 名詞 | 白話解釋 |
|------|---------|
| **左尾檢驗** | 檢查「是否小於某個值」 |
| **t 統計量** | 衡量「樣本平均與假設值的差距」有多少個標準誤 |
| **標準誤 (SE)** | 樣本平均的「不確定程度」 |
| **信賴區間** | 真實值的「可能範圍」 |
| **標準差增加** | 個體間的差異變大 |

---

## 🎓 這個研究告訴我們什麼？

1. **暴食症病患治療前自尊心偏低**（顯著 < 25）
2. **治療能有效提升自尊心**（從 20.3 → 26.6）
3. **治療效果能持續**（追蹤期維持在 27.7）
4. **但效果因人而異**（標準差從 5.0 → 8.2）

這支持了文章的論點：**自尊心確實是預測治療效果的重要指標！** 🎯
