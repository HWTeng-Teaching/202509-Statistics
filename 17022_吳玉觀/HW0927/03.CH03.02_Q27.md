## 🎯 問題分析

### a. 變數識別

#### 獨立變數（Independent Variable）
- **變數**: 樓層數 (Floors)
- **符號**: X
- **單位**: 層

#### 依變數（Dependent Variable）
- **變數**: 建築高度 (Height)
- **符號**: Y
- **單位**: 公尺 (meters)

#### 邏輯說明
樓層數決定建築物的高度，因此：
- **X → Y**: 樓層數（自變數）影響高度（因變數）
- 建築設計時先決定樓層數，進而影響總高度

### b. 相關係數分析

#### 計算結果

| 統計量 | 數值 | 說明 |
|--------|------|------|
| **Pearson 相關係數 (r)** | **0.9566** | 極強正相關 |
| **判定係數 (R²)** | **0.9150** | 91.50% 變異可解釋 |
| **p-value** | < 0.0001 | 高度顯著 |

#### 計算公式

相關係數公式：

$$r = \frac{\sum_{i=1}^{n}(x_i - \bar{x})(y_i - \bar{y})}{\sqrt{\sum_{i=1}^{n}(x_i - \bar{x})^2 \sum_{i=1}^{n}(y_i - \bar{y})^2}}$$

其中：
- $x_i$ = 樓層數
- $y_i$ = 高度
- $\bar{x}$ = 樓層數平均值 = 49.21 層
- $\bar{y}$ = 高度平均值 = 202.86 公尺
- $n$ = 樣本數 = 28

#### Google Sheets 操作步驟

```Google Sheets
1. 將數據輸入 Google Sheets：
   - A1: "Height", A2:A29 輸入高度數據
   - B1: "Floors", B2:B29 輸入樓層數據

2. 計算相關係數：
   儲存格 D2 輸入: =CORREL(B2:B29, A2:A29)
   或: =PEARSON(B2:B29, A2:A29)

3. 計算判定係數：
   儲存格 D3 輸入: =RSQ(B2:B29, A2:A29)
   或: =D2^2
```

#### 結果解釋

**相關強度分類**：
- |r| ≥ 0.9：極強相關 ✅ **（本案例）**
- 0.7 ≤ |r| < 0.9：強相關
- 0.4 ≤ |r| < 0.7：中度相關
- 0.2 ≤ |r| < 0.4：弱相關
- |r| < 0.2：極弱或無相關

**本案例解釋**：
1. **r = 0.9566** 表示樓層數與高度呈現**極強的正相關**
2. **正相關**：樓層數增加，建築高度隨之增加
3. **R² = 0.9150**：樓層數可以解釋 91.5% 的高度變異
4. 剩餘 8.5% 的變異可能來自：
   - 每層樓高度設計差異
   - 頂樓特殊結構（天線、裝飾塔等）
   - 地基深度差異

### d. 最小平方迴歸線

#### 迴歸方程式

$$\boxed{\text{Height} = -13.91 + 4.40 \times \text{Floors}}$$

**參數解釋**：

| 參數 | 符號 | 數值 | 單位 | 意義 |
|------|------|------|------|------|
| **截距** | $b_0$ | -13.91 | 公尺 | 理論上 0 樓層的高度（無實際意義） |
| **斜率** | $b_1$ | 4.40 | 公尺/樓層 | 每增加 1 層樓，高度增加 4.40 公尺 |

#### 計算公式

**斜率（Slope）**：

$$b_1 = \frac{\sum_{i=1}^{n}(x_i - \bar{x})(y_i - \bar{y})}{\sum_{i=1}^{n}(x_i - \bar{x})^2}$$

**截距（Intercept）**：

$$b_0 = \bar{y} - b_1 \bar{x}$$

#### Google Sheets 計算步驟

```Google Sheets
1. 計算斜率：
   儲存格 E2 輸入: =SLOPE(A2:A29, B2:B29)
   結果: 4.4045

2. 計算截距：
   儲存格 E3 輸入: =INTERCEPT(A2:A29, B2:B29)
   結果: -13.9065

3. 建立預測值欄位：
   儲存格 C2 輸入: =$E$3 + $E$2 * B2
   向下拖曳至 C29

4. 計算殘差：
   儲存格 D2 輸入: =A2 - C2
   向下拖曳至 D29

5. 迴歸統計（進階）：
   - 資料 → 資料分析 → 迴歸
   - Y 範圍：A1:A29
   - X 範圍：B1:B29
   - 勾選「標記」、「殘差」、「線性配適圖」
```

1. **極強相關性** ✅

### B. 統計學基礎概念

**相關係數 (r)** 的判斷標準：
- r = 1：完全正相關
- 0.7 ≤ r < 1：強正相關
- 0.3 ≤ r < 0.7：中度正相關
- 0 < r < 0.3：弱正相關
- r = 0：無相關
- -1 < r < 0：負相關（數值越小，負相關越強）

**判定係數 (R²)** 的意義：
- R² = 解釋變異 / 總變異
- 表示自變數可以解釋依變數變異的比例
- R² 越接近 1，模型配適度越好
