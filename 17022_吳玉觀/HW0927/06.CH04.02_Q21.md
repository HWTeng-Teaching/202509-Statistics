# 統計學題目解答：Candies（樹狀圖法）

## 題目 21：Candies

**情境描述：**
- 碗裡有 **5 顆糖果**：紅色 (R)、棕色 (Br)、黃色 (Y)、藍色 (Bl)、橘色 (O)
- **隨機抽取 2 顆**：一顆給自己吃，一顆給朋友
- **順序有關**：第 1 顆（自己）、第 2 顆（朋友）
- **無放回抽樣**

**求：P(你拿到橘色 AND 朋友沒拿到紅色)**

---

## 📊 步驟 1：建立樹狀圖

### 完整樹狀圖：

```
                    開始
                     |
        ┌────┬───┬───┼───┬────┐
        |    |   |   |   |    |
        R    Br  Y   Bl  O    (第1顆：你)
        |    |   |   |   |
    ┌─┬─┼─┬─ ┌─┼─┬─ ... ┌─┬─┬─┐ (第2顆：朋友)
    | | | |  | | | |     | | | |
   Br Y Bl O R Y Bl O   R Br Y Bl

說明：
- 第1層：5種選擇（你抽的糖果）
- 第2層：4種選擇（朋友從剩下4顆中抽）
- 總共：5 × 4 = 20 個簡單事件
```

---

### 重點展開：橘色分支

```
當你抽到 O (橘色)時：

        O (你)
        |
    ┌───┼───┬───┐
    |   |   |   |
    R   Br  Y   Bl  (朋友可能抽到的)
    ↓   ↓   ↓   ↓
   O-R O-Br O-Y O-Bl

符合條件的：O-Br, O-Y, O-Bl (朋友沒拿到紅色)
不符合的：O-R (朋友拿到紅色) ✗
```

---

## 📊 步驟 2：列出所有簡單事件

### 完整樣本空間 S（20個事件）：

| 第1顆(你) | 第2顆(朋友) | 簡單事件 |
|----------|-----------|---------|
| R | Br, Y, Bl, O | R-Br, R-Y, R-Bl, R-O |
| Br | R, Y, Bl, O | Br-R, Br-Y, Br-Bl, Br-O |
| Y | R, Br, Bl, O | Y-R, Y-Br, Y-Bl, Y-O |
| Bl | R, Br, Y, O | Bl-R, Bl-Br, Bl-Y, Bl-O |
| **O** | **R, Br, Y, Bl** | **O-R, O-Br, O-Y, O-Bl** ⭐ |

**總共：n(S) = 20 個等可能事件**

---

## 📊 步驟 3：確認符合條件的事件

### 條件分析：

**條件 A：你拿到橘色** → 第1顆 = O
```
可能事件：O-R, O-Br, O-Y, O-Bl
```

**條件 B：朋友沒拿到紅色** → 第2顆 ≠ R
```
排除：O-R
保留：O-Br, O-Y, O-Bl
```

### 符合條件的事件：

```
E = {O-Br, O-Y, O-Bl}
n(E) = 3
```

---

## 📊 步驟 4：計算機率

### 方法一：古典機率

```
P(E) = n(E) / n(S)
     = 3 / 20
     = 0.15
```

---

### 方法二：條件機率（分步驟）

#### 步驟 1：你抽到橘色
```
P(你抽到O) = 1/5
```

#### 步驟 2：在你抽到橘色後，朋友沒抽到紅色
```
剩下4顆：R, Br, Y, Bl
朋友沒抽到紅色 = 朋友抽到 Br, Y, 或 Bl
P(朋友不抽R | 你抽O) = 3/4
```

#### 步驟 3：兩事件同時發生
```
P(你抽O AND 朋友不抽R) = P(你抽O) × P(朋友不抽R | 你抽O)
                       = (1/5) × (3/4)
                       = 3/20
                       = 0.15
```

## 🎯 答案：

> **P(你拿到橘色 AND 朋友沒拿到紅色) = 3/20 = 0.15 = 15%**
> 
> **符合條件的事件：**
> 1. O-Br（你：橘色，朋友：棕色）
> 2. O-Y（你：橘色，朋友：黃色）
> 3. O-Bl（你：橘色，朋友：藍色）

```
P(O) = 1/5

P(Bl|O) = 1/4  → P(O,Bl) = 1/5 × 1/4 = 1/20

總機率 = 1/20 + 1/20 + 1/20 = 3/20 ✓
```

## 🔍 不同問法的機率

### 延伸問題：

#### Q1: 你拿到橘色的機率？
```
P(你拿O) = 4/20 = 1/5 = 0.2
包含：O-R, O-Br, O-Y, O-Bl
```

#### Q2: 朋友沒拿到紅色的機率？
```
朋友拿到R的情況：R-?, Br-R, Y-R, Bl-R, O-R (4種)
朋友沒拿到R：20 - 4 = 16種
P(朋友不拿R) = 16/20 = 4/5 = 0.8
```

#### Q3: 你拿到橘色或朋友沒拿到紅色？
```
P(A ∪ B) = P(A) + P(B) - P(A ∩ B)
         = 4/20 + 16/20 - 3/20
         = 17/20
         = 0.85
```

#### Q4: 兩人都沒拿到紅色？
```
符合：Br-Y, Br-Bl, Br-O, Y-Br, Y-Bl, Y-O, Bl-Br, Bl-Y, Bl-O, O-Br, O-Y, O-Bl
共12種
P = 12/20 = 3/5 = 0.6
```

## 🎯 關鍵概念總結

### 1️⃣ **無放回抽樣**
- 第1顆抽完後不放回
- 第2顆只能從剩下4顆中抽
- 總事件數 = 5 × 4 = 20

### 2️⃣ **順序重要**
- (你, 朋友) = (O, Br) ≠ (Br, O)
- 這是**排列問題**

### 3️⃣ **條件機率思維**
```
P(A AND B) = P(A) × P(B|A)
```

### 4️⃣ **樹狀圖優勢**
- 清楚顯示所有可能
- 容易識別符合條件的路徑
- 自然反映條件機率

## ⚠️ 常見錯誤

### ❌ 錯誤 1：忘記無放回
```
錯誤：總事件數 = 5 × 5 = 25
正確：總事件數 = 5 × 4 = 20
```

### ❌ 錯誤 2：計算錯誤的事件數
```
錯誤：只計算 O-Br, O-Y (漏了 O-Bl)
正確：O-Br, O-Y, O-Bl (共3個)
```

### ❌ 錯誤 3：條件理解錯誤
```
錯誤：朋友沒拿到紅色 = 只有你拿到紅色
正確：朋友沒拿到紅色 = 朋友拿 Br, Y, Bl, 或 O
```

### ❌ 錯誤 4：機率相加錯誤
```
錯誤：P = 1/5 + 3/4 (不能直接相加)
正確：P = 1/5 × 3/4 (相乘，因為是AND)
```
