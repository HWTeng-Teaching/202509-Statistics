# 統計學題目解答：Preschool or Not?（樹狀圖與列聯表）

## 題目 29：Preschool or Not?

**情境描述：**
- 老師從 25 名幼稚園學生中隨機選 1 位
- 記錄：性別 + 是否上過學前班 (preschool)

**數據表格：**

|  | **Male** | **Female** | **Total** |
|---|----------|-----------|-----------|
| **Preschool** | 8 | 9 | 17 |
| **No Preschool** | 6 | 2 | 8 |
| **Total** | 14 | 11 | 25 |

---

## 📊 問題 a：Construct a tree diagram & count simple events

建立樹狀圖，並計算有多少個簡單事件

### 方法一：性別 → 學前班經驗

```

簡單事件：

### 答案 a：

> 
> **樣本空間 S：**

> S = {(Male, Preschool), (Male, No Preschool),

> ```
> S = {M-P, M-NP, F-P, F-NP}

> 
> **n(S) = 4**

## 📊 問題 b：Assign probabilities to simple events

根據表格數據，指定各簡單事件的機率

### 計算每個簡單事件的機率：

```
P(事件) = 該事件的學生數 / 總學生數
```

---

### 詳細計算：

#### 事件 1：M-P (Male, Preschool)
```
P(M-P) = 8/25 = 0.32
```

#### 事件 2：M-NP (Male, No Preschool)
```
P(M-NP) = 6/25 = 0.24
```

#### 事件 3：F-P (Female, Preschool)
```
P(F-P) = 9/25 = 0.36
```

#### 事件 4：F-NP (Female, No Preschool)
```
P(F-NP) = 2/25 = 0.08
```

---

驗證總和：
0.32 + 0.24 + 0.36 + 0.08 = 1.00 ✓
```

## 📊 問題 c：P(Male) = ?

隨機選中的學生是男性的機率

### 方法一：從表格直接計算

```
男性總數 = 8 + 6 = 14
P(Male) = 14/25 = 0.56
```

---

### 方法二：使用簡單事件機率相加

```
P(Male) = P(M-P) + P(M-NP)
        = 8/25 + 6/25
        = 14/25
        = 0.56
```

---

## 🎯 延伸問題與機率計算

### Q1: P(Female) = ?
```
P(Female) = 11/25 = 0.44 = 44%
```

### Q2: P(Preschool) = ?
```
P(Preschool) = 17/25 = 0.68 = 68%
```

### Q3: P(No Preschool) = ?
```
P(No Preschool) = 8/25 = 0.32 = 32%
```

### Q4: P(Male AND Preschool) = ?
```
P(M-P) = 8/25 = 0.32 = 32%
```

### Q5: P(Male OR Preschool) = ?
```
P(M ∪ P) = P(M) + P(P) - P(M ∩ P)
         = 14/25 + 17/25 - 8/25
         = 23/25
         = 0.92 = 92%
```

### Q6: P(Female OR No Preschool) = ?
```
P(F ∪ NP) = P(F) + P(NP) - P(F ∩ NP)
          = 11/25 + 8/25 - 2/25
          = 17/25
          = 0.68 = 68%
```

## 🔍 獨立性檢驗（補充）

### 性別和學前班經驗是否獨立？

**如果獨立，應該滿足：**
```
P(M ∩ P) = P(M) × P(P)
```

**實際計算：**
```
P(M ∩ P) = 8/25 = 0.32
P(M) × P(P) = (14/25) × (17/25) = 238/625 = 0.3808

0.32 ≠ 0.3808
```

**結論：不獨立！**

**觀察：**
- 女性上學前班的比例更高（81.8% vs 57.1%）
- 這兩個變數有關聯

## 📚 關鍵公式

### 邊際機率（Marginal Probability）：
```
P(Male) = Σ P(Male, 任何學前班狀態)
P(Preschool) = Σ P(任何性別, Preschool)
```

### 聯合機率（Joint Probability）：
```
P(A AND B) = 從表格直接讀取
```

### 條件機率（Conditional Probability）：
```
P(A|B) = P(A AND B) / P(B)
```
