## 題目 27：Gender and Hair Color（結果表格法）

**情境描述：**
記錄一個人的：
1. **性別** (Gender)：Male (M) 或 Female (F)
2. **髮色** (Hair Color)：Blonde (Bl), Brown (Br), Black (Ba), Red (R), Other (O)

---

## 📊 方法：使用結果表格 (Table of Outcomes)

### 建立二維表格：

| | **Blonde (Bl)** | **Brown (Br)** | **Black (Ba)** | **Red (R)** | **Other (O)** |
|---------|-----------------|----------------|----------------|-------------|---------------|
| **Male (M)** | M-Bl | M-Br | M-Ba | M-R | M-O |
| **Female (F)** | F-Bl | F-Br | F-Ba | F-R | F-O |

---

### 完整樣本空間 S：

```
S = {M-Bl, M-Br, M-Ba, M-R, M-O,
     F-Bl, F-Br, F-Ba, F-R, F-O}
```

**總共：2 × 5 = 10 個簡單事件**

## 💡 延伸問題與機率計算

### 假設每個事件等可能：

```
每個簡單事件的機率 = 1/10 = 0.1
```

---

### 例題 1：隨機選一人，是男性的機率？

```
P(Male) = 5/10 = 1/2 = 0.5
```

**包含的事件：** M-Bl, M-Br, M-Ba, M-R, M-O

---

### 例題 2：隨機選一人，是金髮的機率？

```
P(Blonde) = 2/10 = 1/5 = 0.2
```

**包含的事件：** M-Bl, F-Bl

---

### 例題 3：隨機選一人，是金髮女性的機率？

```
P(Female AND Blonde) = 1/10 = 0.1
```

**包含的事件：** F-Bl

---

### 例題 4：隨機選一人，是男性或金髮的機率？

```
P(Male OR Blonde) = P(Male) + P(Blonde) - P(Male AND Blonde)
                  = 5/10 + 2/10 - 1/10
                  = 6/10 = 0.6
```

**包含的事件：** M-Bl, M-Br, M-Ba, M-R, M-O, F-Bl

## 🎯 重點整理

### 結果表格法特點：

✅ **優點：**
1. 視覺化清晰
2. 容易找出所有組合

✅ **適用情況：**
- 變數較少（通常 2-3 個）
- 每個變數的類別不多
- 需要清楚看到所有組合

✅ **本題關鍵：**
- 2 個分類變數：性別、髮色
- 性別：2 種
- 髮色：5 種
- 總共：2 × 5 = **10 個簡單事件**

## 🔢 計數原理驗證

### 乘法原理 (Multiplication Principle)：

```
如果事件 A 有 m 種結果，事件 B 有 n 種結果
則 A 和 B 一起發生的結果數 = m × n
```

**本題：**
```
性別選擇：2 種
髮色選擇：5 種
總結果數 = 2 × 5 = 10 ✓
```

## 💻 Python 程式生成（補充）

如果要用程式生成所有組合：

```python
genders = ['Male', 'Female']
hair_colors = ['Blonde', 'Brown', 'Black', 'Red', 'Other']

sample_space = []
for gender in genders:
    for hair in hair_colors:
        sample_space.append(f"{gender[0]}-{hair[:2]}")

print("Sample Space:", sample_space)
print("Total events:", len(sample_space))

# Output:
# Sample Space: ['M-Bl', 'M-Br', 'M-Ba', 'M-Re', 'M-Ot', 
#                'F-Bl', 'F-Br', 'F-Ba', 'F-Re', 'F-Ot']
# Total events: 10
```
