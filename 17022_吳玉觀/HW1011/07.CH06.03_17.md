# 統計學題目解答：Cell Phone Etiquette（二項分佈與常態近似）

## 題目 17：Cell Phone Etiquette

**情境描述：**
- 根據 USA Today 的調查
- **51%** 的美國人認為一般人講手機時「不太體貼他人」(Not very considerate)
- 隨機選取 **100** 位美國人
- 求：**至少 60 人**認為不體貼的近似機率

**參數：**
- n = 100（樣本數）
- p = 0.51（成功機率）
- 求：P(X ≥ 60)

---

## 📊 解題方法選擇

### 方法判斷：

這題可以用兩種方法：

1. **二項分佈（精確）**：適用但計算繁瑣
2. **常態近似（近似）**：更快且題目要求「approximate probability」

#### 檢查常態近似條件：

```
np = 100 × 0.51 = 51 ≥ 10 ✓
nq = n(1-p) = 100 × 0.49 = 49 ≥ 10 ✓
```

**兩個條件都滿足，可以使用常態近似！**

---

## 📊 方法一：使用常態近似（推薦）⭐

### 步驟 1：計算二項分佈的參數

**期望值：**
```
μ = np = 100 × 0.51 = 51
```

**標準差：**
```
σ = √[np(1-p)] 
  = √[100 × 0.51 × 0.49]
  = √24.99
  = 4.999 ≈ 5
```

---

### 步驟 2：連續性修正（Continuity Correction）

**重要！** 因為從離散（二項）轉換到連續（常態），需要修正：

```
P(X ≥ 60) ≈ P(X > 59.5)
```

**為什麼？**
- 二項分佈：X 只能是整數（59, 60, 61, ...）
- 常態分佈：X 是連續的
- X ≥ 60 在常態分佈下應該從 59.5 開始算

---

### 步驟 3：計算 Z 分數

```
Z = (X - μ) / σ
  = (59.5 - 51) / 5
  = 8.5 / 5
  = 1.7
```

---

### 步驟 4：查找機率

```
P(X ≥ 60) = P(Z > 1.7)
          = 1 - P(Z ≤ 1.7)
          = 1 - 0.9554
          = 0.0446
```

---

| 步驟 | 公式 | 結果 |
|------|------|------|
| μ | `=100*0.51` | 51 |

### 答案（方法一）：

> **P(X ≥ 60) ≈ 0.0446 或 4.46%**
> 
> 約有 **4.46%** 的機會，100 人中至少有 60 人認為手機使用者不體貼

## 🎯 重點整理

### 解題關鍵步驟：

1. ✅ **檢查常態近似條件**
   - np ≥ 10 ✓
   - nq ≥ 10 ✓

2. ✅ **計算參數**
   - μ = np = 51
   - σ = √(npq) = 5

3. ✅ **連續性修正**
   - P(X ≥ 60) → P(X > 59.5)

4. ✅ **標準化**
   - Z = (59.5 - 51) / 5 = 1.7

5. ✅ **查表或計算**
   - P(Z > 1.7) = 0.0446

---

### 常態近似的規則：

| 情況 | 修正方式 |
|------|---------|
| P(X ≥ a) | P(X > a - 0.5) |
| P(X > a) | P(X > a + 0.5) |
| P(X ≤ a) | P(X < a + 0.5) |
| P(X < a) | P(X < a - 0.5) |
| P(X = a) | P(a - 0.5 < X < a + 0.5) |

**本題：** P(X ≥ 60) → P(X > 59.5) ✓

## 🔍 結果解讀

### 實務意義：

1. **機率很低（4.46%）**
   - 在 100 人中，有 60 人或更多認為不體貼的機會不大

2. **為什麼？**
   - 因為期望值只有 51 人
   - 60 人比期望值高出 9 人
   - 這相當於超出 1.7 個標準差

3. **社會學意義：**
   - 如果真的觀察到 60+ 人，可能：
     - 樣本有偏差
     - 實際比例可能高於 51%
     - 純粹是隨機變異（但機率低）

## 📚 延伸問題

### 如果要問其他機率呢？

#### Q1: 恰好 51 人？
```
P(X = 51) ≈ P(50.5 < X < 51.5)

Z₁ = (50.5-51)/5 = -0.1
Z₂ = (51.5-51)/5 = 0.1

P(-0.1 < Z < 0.1) = P(Z<0.1) - P(Z<-0.1)
                  = 0.5398 - 0.4602
                  = 0.0796 ≈ 8%
```

#### Q2: 少於 45 人？
```
P(X < 45) ≈ P(X < 44.5)

Z = (44.5-51)/5 = -1.3

P(Z < -1.3) = 0.0968 ≈ 9.68%
```

#### Q3: 45 到 55 人之間？
```
P(45 ≤ X ≤ 55) ≈ P(44.5 < X < 55.5)

Z₁ = (44.5-51)/5 = -1.3
Z₂ = (55.5-51)/5 = 0.9

P(-1.3 < Z < 0.9) = P(Z<0.9) - P(Z<-1.3)
                   = 0.8159 - 0.0968
                   = 0.7191 ≈ 72%
```

## ⚠️ 常見錯誤提醒

### ❌ 錯誤 1：忘記連續性修正
```
錯誤：P(X ≥ 60) 直接用 Z = (60-51)/5 = 1.8
正確：應該用 Z = (59.5-51)/5 = 1.7
```

### ❌ 錯誤 2：標準差計算錯誤
```
錯誤：σ = √(np) = √51
正確：σ = √(npq) = √(51×0.49) = 5
```

### ❌ 錯誤 3：機率方向錯誤
```
錯誤：P(X ≥ 60) = P(Z ≤ 1.7)
正確：P(X ≥ 60) = P(Z > 1.7) = 1 - P(Z ≤ 1.7)
```
