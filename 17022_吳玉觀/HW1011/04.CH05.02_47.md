# 統計學題目解答：植物遺傳學（二項分佈）

## 題目 47：Plant Genetics

牡丹植物雜交實驗：
- 紅色花瓣 × 條紋花瓣
- 後代開紅花的機率 p = 0.75
- 從這次雜交中收集並發芽 10 顆種子
- X = 開紅花的植物數量

---

## 📋 問題 a：這是二項分佈嗎？

### 檢查二項分佈的四個條件：

✅ **1. 固定試驗次數 (n)**
- 有 10 顆種子，n = 10

✅ **2. 每次試驗只有兩種結果**
- 紅花 或 條紋花

✅ **3. 每次試驗成功機率相同 (p)**
- 每顆種子開紅花的機率都是 0.75

✅ **4. 各次試驗獨立**
- 每顆種子的結果互不影響

### 答案 a：

> **Yes, X 服從二項分佈**
> 
> **參數：n = 10, p = 0.75**

---

## 📊 問題 b：Find P(X ≥ 9)

求「至少9株開紅花」的機率

### 方法一：使用公式

P(X ≥ 9) = P(X = 9) + P(X = 10)

**二項機率公式：**

```
P(X = k) = C(n,k) × p^k × (1-p)^(n-k)
```

### 答案 b：

> **P(X ≥ 9) = 0.2440 或 24.40%**

## 🤔 問題 d：Unusual 判斷

**情境：** 10株植物中，只有1株紅花，其餘9株都是條紋花

**問題：** 這樣的結果unusual嗎？如果真的發生，可以得出什麼結論？

### 分析：

#### 1. 計算期望值和標準差

**期望值：**
```
μ = np = 10 × 0.75 = 7.5
```

**標準差：**
```
σ = √[np(1-p)] = √[10 × 0.75 × 0.25] = √1.875 = 1.369
```

#### 2. 使用 fx-991CW 計算標準差

```
按 AC
輸入: √(10×0.75×0.25)
按 =
結果: 1.369
```

#### 3. 判斷 X = 1 是否 unusual

**計算 Z 分數：**
```
Z = (X - μ) / σ = (1 - 7.5) / 1.369 = -6.5 / 1.369 = -4.75
```

**fx-991CW 操作：**
```
(1 - 7.5) ÷ 1.369 =
結果: -4.75
```

**判斷標準：**
- |Z| = 4.75 > 2 ✓✓✓
- P(X ≤ 1) = 0.000004 < 0.05 ✓✓✓

### 答案 d：

> **Yes, 這是非常 unusual 的結果！**
> 
> **理由：**
> 1. Z分數 = -4.75，遠超過unusual的標準（|Z| > 2）
> 2. 機率只有 0.0004%，幾乎不可能發生
> 3. 期望應該有 7-8 株紅花，實際只有 1 株
> 
> **可能的結論：**
> - 📌 **假設的機率 p = 0.75 可能是錯的**
> - 📌 種子可能受到污染或混雜
> - 📌 實驗條件可能有問題
> - 📌 遺傳模型可能不正確
> - 📌 這批種子可能不是來自該雜交
