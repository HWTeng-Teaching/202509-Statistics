## 1. 敘述統計

### 📊 中心趨勢 (Measures of Central Tendency)

| 公式 | 符號 | 何時使用 | 計算機按鍵 |
|------|------|---------|-----------|
| **平均數** | | | |
| 樣本平均 | $\bar{x} = \frac{\sum x_i}{n}$ | 數據無極端值 | `x̄` (統計模式) |
| 母體平均 | $\mu = \frac{\sum x_i}{N}$ | 全部數據 | |
| 加權平均 | $\bar{x} = \frac{\sum x_i \cdot f_i}{\sum f_i}$ | 有頻率或機率 | FREQ 欄位 |
| | | | |
| **中位數** | | | |
| 中位數 | 排序後中間值 | 有極端值/偏態 | `Med` (統計模式) |
| | | | |
| **眾數** | | | |
| 眾數 | 出現最多的值 | 類別資料 | 目視 |

---

### 📊 變異性 (Measures of Variability)

| 公式 | 符號 | 何時使用 | 計算機按鍵 |
|------|------|---------|-----------|
| **範圍** | | | |
| 範圍 | $R = Max - Min$ | 快速了解分散 | 手動計算 |
| | | | |
| **四分位數** | | | |
| Q1 | 第 25 百分位 | 盒鬚圖 | `Q₁` |
| Q3 | 第 75 百分位 | 盒鬚圖 | `Q₃` |
| IQR | $IQR = Q_3 - Q_1$ | 離群值檢測 | 手動計算 |
| | | | |
| **變異數與標準差** | | | |
| 樣本變異數 | $s^2 = \frac{\sum(x_i-\bar{x})^2}{n-1}$ | 樣本數據 | `s²` 或 `sx²` |
| 母體變異數 | $\sigma^2 = \frac{\sum(x_i-\mu)^2}{N}$ | 全部數據 | `σ²` |
| 樣本標準差 | $s = \sqrt{s^2}$ | 描述離散程度 | `sx` |
| 母體標準差 | $\sigma = \sqrt{\sigma^2}$ | 全部數據 | `σx` |
| 變異係數 | $CV = \frac{s}{\bar{x}}$ | 比較不同單位 | 手動計算 |

### 📊 離群值檢測

| 方法 | 公式 | 判斷準則 | 題目關鍵字 |
|------|------|---------|-----------|
| **IQR 法** | | | |
| 下界 | $Q_1 - 1.5 \times IQR$ | 小於下界 → 離群值 | "outlier", "unusual" |
| 上界 | $Q_3 + 1.5 \times IQR$ | 大於上界 → 離群值 | |
| | | | |
| **Z 分數法** | | | |
| Z 分數 | $Z = \frac{x - \mu}{\sigma}$ | \|Z\| > 2 → unusual | "unusual", "rare" |
| | | | \|Z\| > 3 → very unusual | |

## 2. 機率基礎

### 📊 基本機率

| 公式 | 符號 | 何時使用 | 關鍵字 |
|------|------|---------|--------|
| **古典機率** | | | |
| 基本機率 | $P(A) = \frac{n(A)}{n(S)}$ | 等可能事件 | "randomly", "equally likely" |
| | | | |
| **機率規則** | | | |
| 補集 | $P(A^c) = 1 - P(A)$ | "不發生" | "not", "does not" |
| 聯集 (OR) | $P(A \cup B) = P(A) + P(B) - P(A \cap B)$ | "A或B" | "or", "at least one" |
| 交集 (AND) | $P(A \cap B) = P(A) \times P(B\|A)$ | "A且B" | "and", "both" |
| 互斥 | $P(A \cup B) = P(A) + P(B)$ | 不能同時發生 | "mutually exclusive" |
| 獨立 | $P(A \cap B) = P(A) \times P(B)$ | 互不影響 | "independent", "with replacement" |
| | | | |
| **條件機率** | | | |
| 條件機率 | $P(A\|B) = \frac{P(A \cap B)}{P(B)}$ | "已知B發生" | "given", "if", "knowing that" |

---

### 📊 計數原理

| 公式 | 符號 | 何時使用 | 計算機 |
|------|------|---------|--------|
| **排列** | | | |
| 排列 | $P(n,r) = \frac{n!}{(n-r)!}$ | 順序重要 | `nPr` |
| | | 無放回抽樣 | SHIFT + ÷ |
| | | | |
| **組合** | | | |
| 組合 | $C(n,r) = \frac{n!}{r!(n-r)!}$ | 順序不重要 | `nCr` |
| | | 選取問題 | SHIFT + × |
| | | | |
| **乘法原理** | | | |
| 乘法原理 | $n_1 \times n_2 \times ... \times n_k$ | 多階段選擇 | 直接相乘 |
| | | 樹狀圖 | |

## 3. 離散機率分佈

### 📊 離散隨機變數

| 公式 | 符號 | 何時使用 | 關鍵字 |
|------|------|---------|--------|
| **期望值** | | | |
| 期望值 | $E(X) = \mu = \sum x \cdot p(x)$ | 計算平均 | "expected", "mean", "average" |
| | | | |
| **變異數** | | | |
| 變異數 | $Var(X) = E(X^2) - [E(X)]^2$ | 計算分散 | "variance", "variability" |
| | $= \sum x^2 \cdot p(x) - \mu^2$ | | |
| 標準差 | $\sigma = \sqrt{Var(X)}$ | 離散程度 | "standard deviation" |

---

### 📊 二項分佈 (Binomial Distribution)

| 公式 | 符號 | 條件 | 計算機 |
|------|------|------|--------|
| **識別條件** | | | |
| ✓ | 固定試驗次數 n | 有明確次數 | MENU→7→3 |
| ✓ | 只有兩種結果 | 成功/失敗 | |
| ✓ | 每次機率相同 p | 不變的 p | |
| ✓ | 試驗獨立 | 有放回或母體大 | |
| | | | |
| **公式** | | | |
| 機率 | $P(X=k) = C(n,k) \cdot p^k \cdot (1-p)^{n-k}$ | 恰好 k 次成功 | Bpd |
| 累積 | $P(X \leq k) = \sum_{i=0}^{k} P(X=i)$ | 最多 k 次 | Bcd |
| | | | |
| **參數** | | | |
| 期望值 | $\mu = np$ | 平均成功次數 | 直接算 |
| 標準差 | $\sigma = \sqrt{np(1-p)}$ | 離散程度 | √ |
| 變異數 | $\sigma^2 = np(1-p)$ | | |

**題目關鍵字：**
- "n trials", "n times"
- "success/failure"
- "probability of success is p"
- "how many", "number of"

## 4. 常態分佈

### 📊 常態分佈 (Normal Distribution)

| 公式 | 符號 | 何時使用 | 計算機 |
|------|------|---------|--------|
| **標準化** | | | |
| Z 分數 | $Z = \frac{X - \mu}{\sigma}$ | 標準化數值 | MENU→7→1→2 |
| 反向 | $X = \mu + Z\sigma$ | 從 Z 算回 X | |
| | | | |
| **機率** | | | |
| 左尾 | $P(X \leq a)$ | 小於等於 | Lower=-∞, Upper=a |
| 右尾 | $P(X \geq a)$ | 大於等於 | Lower=a, Upper=∞ |
| 區間 | $P(a \leq X \leq b)$ | 之間 | Lower=a, Upper=b |
| | | | |
| **百分位數** | | | |
| 第 p 百分位 | $P(X \leq x_p) = p$ | 找臨界值 | MENU→7→1→3 (InvN) |
| Q1 | 第 25 百分位 | Area=0.25 | |
| Q3 | 第 75 百分位 | Area=0.75 | |

**題目關鍵字：**
- "normally distributed"
- "mean μ and standard deviation σ"
- "what percent", "probability that"
- "find the value", "what score"

---

### 📊 常態近似二項 (Normal Approximation)

| 步驟 | 公式 | 條件檢查 | 注意事項 |
|------|------|---------|---------|
| **1. 檢查條件** | | | |
| | $np \geq 10$ | 必須滿足 | 題目說 "approximate" |
| | $n(1-p) \geq 10$ | 必須滿足 | |
| | | | |
| **2. 計算參數** | | | |
| 期望值 | $\mu = np$ | | |
| 標準差 | $\sigma = \sqrt{np(1-p)}$ | | |
| | | | |
| **3. 連續性修正** ⚠️ | | | |
| $P(X \geq a)$ | → $P(X > a-0.5)$ | 至少 a | **最重要！** |
| $P(X \leq a)$ | → $P(X < a+0.5)$ | 最多 a | 不要忘記 |
| $P(X = a)$ | → $P(a-0.5 < X < a+0.5)$ | 恰好 a | |
| $P(X > a)$ | → $P(X > a+0.5)$ | 超過 a | |
| | | | |
| **4. 標準化** | | | |
| | $Z = \frac{X^* - \mu}{\sigma}$ | X* 是修正後的值 | |

## 9. 常見錯誤提醒

### ⚠️ 前10大致命錯誤

1. **忘記連續性修正**
   - ❌ P(X≥60) 直接用 Z=(60-μ)/σ
   - ✅ P(X≥60) 用 Z=(59.5-μ)/σ

2. **標準差公式錯誤**
   - ❌ σ = √(np)
   - ✅ σ = √[np(1-p)]

3. **樣本vs母體**
   - ❌ 樣本用 N 當分母
   - ✅ 樣本用 n-1 當分母

4. **機率方向**
   - ❌ P(X≥a) = P(Z≤z)
   - ✅ P(X≥a) = 1 - P(Z<z)

5. **條件機率混淆**
   - ❌ P(A|B) = P(A) × P(B)
   - ✅ P(A|B) = P(A∩B) / P(B)

6. **獨立性假設錯誤**
   - ❌ 無放回當有放回
   - ✅ 檢查是否真的獨立

7. **Z分數符號**
   - ❌ 只看數值不看正負
   - ✅ 負值表示低於平均

8. **IQR離群值**
   - ❌ 用標準差判斷
   - ✅ 用 Q1-1.5IQR 和 Q3+1.5IQR

9. **計算機模式**
   - ❌ 用錯分佈（Bpd當Bcd）
   - ✅ 確認是密度還是累積

10. **單位轉換**
    - ❌ 1.88m 忘記轉成 188cm
    - ✅ 注意單位一致性
