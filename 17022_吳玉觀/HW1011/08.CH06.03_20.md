# 統計學題目解答：Genetic Defects（二項分佈與常態近似）

## 題目 20：Genetic Defects

**情境描述：**
- 某種遺傳缺陷的發生率：**1/1000** 兒童
- 醫療診所檢查了 **50,000** 名兒童
- 觀察到 **x = 60** 名兒童有此缺陷

**參數：**
- n = 50,000
- p = 1/1000 = 0.001
- 觀察值：x = 60

---

## 📊 問題 a：P(X ≥ 60) = ?

如果這 50,000 名兒童是隨機樣本，觀察到 60 或更多有缺陷的機率是多少？

### 步驟 1：檢查常態近似條件

```
np = 50,000 × 0.001 = 50 ≥ 10 ✓
nq = 50,000 × 0.999 = 49,950 ≥ 10 ✓
```

**兩個條件都滿足，可以使用常態近似！**

---

### 步驟 2：計算二項分佈的參數

**期望值：**
```
μ = np = 50,000 × 0.001 = 50
```

**標準差：**
```
σ = √[np(1-p)]
  = √[50,000 × 0.001 × 0.999]
  = √[49.95]
  = 7.068
```

---

---

### 步驟 3：連續性修正

```
P(X ≥ 60) ≈ P(X > 59.5)
```

**為什麼用 59.5？**
- 從離散轉連續，需要連續性修正
- X ≥ 60 包含 60, 61, 62, ...
- 在常態分佈中應從 59.5 開始算

---

### 步驟 4：計算 Z 分數

```
Z = (X* - μ) / σ
  = (59.5 - 50) / 7.068
  = 9.5 / 7.068
  = 1.344
```

**使用 fx-991CW：**
```
輸入: (59.5 - 50) ÷ 7.068
按 =
結果: 1.344
```

---

### 步驟 5：計算機率

```
P(X ≥ 60) = P(Z > 1.344)
          = 1 - P(Z ≤ 1.344)
          = 1 - 0.9106
          = 0.0894
```

### 答案 a：

> **P(X ≥ 60) ≈ 0.0894 或 8.94%**
> 
> 如果這是隨機樣本，觀察到 60 或更多有缺陷兒童的機率約為 **8.94%**

## 🤔 問題 b：Is x = 60 a rare event?

觀察到 60 名有遺傳缺陷的兒童是否為罕見事件？

### 判斷標準：

#### 1️⃣ **機率判斷標準**

統計學中「罕見事件」的常用標準：
```
P < 0.05 (5%) → 罕見事件
P < 0.01 (1%) → 非常罕見
```

**本題結果：**
```
P(X ≥ 60) = 0.0894 = 8.94%
```

#### 2️⃣ **Z 分數判斷標準**

```
|Z| > 2 → unusual (罕見)
|Z| > 3 → very unusual (非常罕見)
```

**本題結果：**
```
Z = 1.344
|Z| = 1.344 < 2
```

#### 3️⃣ **標準差判斷**

```
X = 60
μ = 50
σ = 7.068

X = μ + 1.344σ
```

**距離平均值約 1.34 個標準差**

---

### 答案 b：

> **No, x = 60 不算是罕見事件（rare event）**
> 
> **理由：**
> 
> 1. **機率判斷（主要理由）：**
>    - P(X ≥ 60) = 8.94% > 5%
>    - 不符合罕見事件的傳統標準（< 5%）
>    - 約每 11 次就會發生 1 次，不算罕見
> 
> 2. **Z 分數判斷：**
>    - Z = 1.344 < 2
>    - 不符合 unusual 的標準（|Z| > 2）
>    - 在「正常範圍」內
> 
> 3. **標準差判斷：**
>    - 60 = μ + 1.34σ
>    - 距離平均值只有 1.34 個標準差
>    - 在 μ ± 2σ 範圍內（正常範圍）
> 
> **BUT 注意：**
> - 雖然不算「罕見」，但也不是「常見」
> - 8.94% 的機率意味著這是相對**不太可能但仍可能發生**的事件
> - 如果用更寬鬆的標準（如 10%），可以說是「不尋常」

## ⚠️ 常見錯誤提醒

### ❌ 錯誤 1：混淆 P(X = 60) 和 P(X ≥ 60)
```
錯誤：只計算 P(X = 60)
正確：題目問的是 P(X ≥ 60)
```

### ❌ 錯誤 2：忘記連續性修正
```
錯誤：Z = (60-50)/7.068 = 1.415
正確：Z = (59.5-50)/7.068 = 1.344
```

### ❌ 錯誤 3：標準差計算錯誤
```
錯誤：σ = √(np) = √50
正確：σ = √(npq) = √(50×0.999) = 7.068
```

### ❌ 錯誤 4：罕見事件判斷標準不明確
```
錯誤：只看絕對數字（60 vs 50）
正確：要看機率和 Z 分數
```

## 🎓 統計學原理總結

### 何時使用常態近似？

✅ **條件：**
1. np ≥ 10
2. nq ≥ 10
3. n 夠大（通常 > 30）

✅ **優點：**
- 計算快速
- 結果準確（當條件滿足時）

✅ **注意事項：**
- 必須使用連續性修正
- p 接近 0 或 1 時要小心
