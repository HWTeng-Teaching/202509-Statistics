# 統計學題目解答：Gestation Times（常態分佈應用）

## 題目 59：Gestation Times

**情境描述：**
根據《Biology Data Book》報告：
- 人類嬰兒的妊娠期（gestation time）平均為 **278 天**
- 標準差為 **12 天**
- 假設妊娠期呈常態分佈

**參數：**
- μ = 278 天
- σ = 12 天
- X ~ N(278, 12²)

---

## 📊 問題 a：Find the upper and lower quartiles

求妊娠期的上四分位數（Q₃）和下四分位數（Q₁）

### 四分位數定義：

```
Q₁ (下四分位數，第25百分位)：P(X ≤ Q₁) = 0.25
Q₂ (中位數，第50百分位)：P(X ≤ Q₂) = 0.50
Q₃ (上四分位數，第75百分位)：P(X ≤ Q₃) = 0.75
```

---

### 方法一：使用 Z 分數查表

#### 步驟 1：找對應的 Z 值

**對於 Q₁（第 25 百分位）：**
```
P(Z ≤ z) = 0.25
查標準常態表：z₁ = -0.6745 ≈ -0.675
```

**對於 Q₃（第 75 百分位）：**
```
P(Z ≤ z) = 0.75
查標準常態表：z₃ = 0.6745 ≈ 0.675
```

#### 步驟 2：轉換回原始分數

**公式：**
```
X = μ + zσ
```

**計算 Q₁：**
```
Q₁ = 278 + (-0.675)(12)
   = 278 - 8.1
   = 269.9 天
```

**計算 Q₃：**
```
Q₃ = 278 + (0.675)(12)
   = 278 + 8.1
   = 286.1 天
```

---

### 📱 Casio fx-991CW 操作

#### 方法：使用反常態分佈（Inverse Normal）

**計算 Q₁（下四分位數）：**

```
步驟1: 按 MENU
步驟2: 選擇 7 (分佈)
步驟3: 選擇 1 (常態分佈)
步驟4: 選擇 3 (反常態累積分佈 InvN)

參數設定：
• Area: 0.25      ← 第25百分位
• σ: 12
• μ: 278

按 =
結果: 269.91 天
```

**計算 Q₃（上四分位數）：**

```
重複上述步驟，但：
• Area: 0.75      ← 第75百分位
• σ: 12
• μ: 278

按 =
結果: 286.09 天
```

---

### 📊 Google Sheets 計算

#### 計算 Q₁：
```excel
=NORM.INV(0.25, 278, 12)
```
結果：**269.91 天**

#### 計算 Q₃：
```excel
=NORM.INV(0.75, 278, 12)
```
結果：**286.09 天**

#### 驗證中位數（Q₂）：
```excel
=NORM.INV(0.5, 278, 12)
```
結果：**278 天**（等於平均數，符合常態分佈特性！）

---

### 答案 a：

> **妊娠期的四分位數：**
> 
> - **Q₁（下四分位數）= 269.9 天 ≈ 270 天**
> - **Q₃（上四分位數）= 286.1 天 ≈ 286 天**
> 
> **解讀：**
> - 25% 的嬰兒在 **270 天或更短**時間出生
> - 75% 的嬰兒在 **286 天或更短**時間出生
> - 中間 50% 的嬰兒妊娠期在 **270 到 286 天**之間（IQR = 16.2 天）

## 📊 問題 b：Unusual to deliver after only 6 months?

只有 6 個月（180 天）的妊娠期就分娩，這樣unusual嗎？

### 分析步驟：

#### 步驟 1：計算 Z 分數

```
Z = (X - μ) / σ
  = (180 - 278) / 12
  = -98 / 12
  = -8.167
```

**使用 fx-991CW：**
```
輸入: (180 - 278) ÷ 12
按 =
結果: -8.167
```

---

#### 步驟 2：計算機率 P(X ≤ 180)

**使用 fx-991CW：**

```
MENU → 7 → 1 → 2 (Normal CD)

參數設定：
• σ: 12
• μ: 278
• Lower: -10000  (或用 -5000)
• Upper: 180

按 =
結果: 非常接近 0（計算機可能顯示 0 或極小值）
```

**使用標準常態分佈：**

```
MENU → 7 → 1 → 2

參數設定：
• σ: 1
• μ: 0
• Lower: -10
• Upper: -8.167

按 =
結果: ≈ 0.0000000000015（幾乎是 0）
```

---

### 📊 Google Sheets 計算

```excel
=NORM.DIST(180, 278, 12, TRUE)
```
結果：**約 1.5 × 10⁻¹³**（0.00000000000015）

**用科學記號表示：**
```excel
=TEXT(NORM.DIST(180, 278, 12, TRUE), "0.00E+00")
```
結果：**1.50E-13**

---

### 判斷標準：

#### 1️⃣ **Z 分數判斷：**
```
|Z| = 8.167 >>> 3
```
- |Z| > 2：unusual
- |Z| > 3：very unusual
- |Z| > 8：**極度罕見！**

#### 2️⃣ **機率判斷：**
```
P(X ≤ 180) ≈ 0.0000000000015
           = 0.00000000015%
```
- 這相當於**每 6.7 千億次**才會發生一次！

#### 3️⃣ **標準差判斷：**
```
180 天 = μ - 8.167σ
       = 278 - 8.167(12)
       = 278 - 98
```
- 距離平均值超過 **8 個標準差**

### 答案 b：

> **Yes, 這是極度 unusual 的情況！**
> 
> **理由：**
> 
> 1. **Z 分數 = -8.17**
>    - 遠遠超過 unusual 的標準（|Z| > 2）
>    - 甚至超過 very unusual 的標準（|Z| > 3）
> 
> 2. **機率極小：P(X ≤ 180) ≈ 1.5 × 10⁻¹³**
>    - 相當於 0.00000000015%
>    - 約每 **6,700 億次**才發生一次
> 
> 3. **醫學意義：**
>    - 180 天約為 **6 個月**或 **26 週**
>    - 這是**極度早產**（extremely premature）
>    - 正常足月妊娠為 **37-42 週**（259-294 天）
>    - 6 個月的嬰兒存活需要高度醫療介入
> 
> 4. **實務判斷：**
>    - 如果真的發生，可能是：
>      - 計算錯誤（受孕日期記錯）
>      - 醫療緊急情況
>      - 非常特殊的個案
> 
> **結論：在統計學上，這幾乎是不可能發生的事件。**

## 📚 相關公式整理

### 四分位數公式（常態分佈）：

```
Q₁ = μ + (-0.6745)σ = μ - 0.6745σ
Q₂ = μ
Q₃ = μ + (0.6745)σ
```

### Z 分數轉換：

```
Z = (X - μ) / σ
X = μ + Zσ
```
