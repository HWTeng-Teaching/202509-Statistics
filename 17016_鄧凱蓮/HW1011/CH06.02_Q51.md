## Ans:

川普身高 1.88 m = 188 cm

x_trump = 188.0    
$\mu$ = 176.5         
$\sigma$ = 8.9       

# 1. 計算 Z-分數 (Z-score)
# Z = (x - mu) / sigma
Z = (x_trump - mu) / sigma
Z_numerator = 188.0 - 176.5
Z_numerator = 11.5
Z_score = 11.5 / 8.9
Z_score ≈ 1.2921

# 2. 判斷是否不尋常 (Unusual)

# 統計學上，Z-分數的絕對值 |Z| ≥ 2 通常被視為不尋常。
# 臨界值 1: |Z| ≥ 2

if abs(Z_score) >= 2:
    unusual_status = "屬於不尋常 (Unusual)"
else:
    unusual_status = "不屬於不尋常 (Not Unusual)"

# 3. 結論
# Z-score ≈ 1.2921

print(f"川普身高的 Z-分數: {Z_score:.3f}")
print(f"判斷結果: Z-分數 (|1.29|) 小於 2。")
print(f"結論: {unusual_status}")

# 額外機率分析 (P(X > 188))
# 查表 P(Z < 1.29) ≈ 0.9015
# P(X ≥ 188) = 1 - P(Z < 1.29)
P_taller = 1 - 0.9015
P_taller = 0.0985  # 9.85% 的男性比他高。

# 由於 0.0985 > 0.05 (常用的單尾不尋常臨界值)，因此從機率角度看，也不算不尋常。
