#### b. Find the least-squares line describing these data. Do the data indicate that there is a linear relationship between the number of miles of roadways and the year? Test using a t statistic with $\alpha=.05$  

<img width="398" height="407" alt="image" src="https://github.com/user-attachments/assets/f5eaf989-cd8e-4b08-bbe6-ba4285010e3b" />

<img width="440" height="60" alt="image" src="https://github.com/user-attachments/assets/2d273f68-ea1c-406e-8a4e-d7b9c73ed8fc" />

$b=S_{xy}/S_{xx}=7.85/340=0.02309$

$a=\bar{y}-b\bar{x}=1.04-0.02309*7.5)=0.8681$

$\hat{y}=0.8681+0.02309x$

t檢定

1. $H_0:\beta=0$
   $H_1:\beta\neq0$ 
   
2. $\alpha = 0.05$ 

3. $t_{STAT}=\frac{b}{\sqrt{\frac{MSE}{S_{XX}}}} \sim t_{(n-2)}$  

4. $t*=\frac{0.02309}{0.00104}=22.2349$  

5. 查表 $t_{0.05/2,14}=2.145$
  
   RR={ t：t* > 2.145 }  
    
6. Since t* = 22.2349 > 2.145, reject H₀ , $\Rightarrow$ 數據顯示道路里程數與年份之間存在顯著的線性關係。
