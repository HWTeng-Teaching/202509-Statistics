3. $F_{STAT}=\frac{MST}{MSE} \sim F_{(k-1),(n-k)}$  

4. &nbsp; $F^*=6.46$  

5.(1) 查表 $F_{0.05, 2, 11}$，臨界值為 3.98
  
    RR={ F：F* > 3.98 }  
    
    Since F* = 6.46 > 3.98, reject H₀.

  (2) $F_{0.025}(2,11)=5.26 < F^* = 6.46 < F_{0.01}(2,11)=7.21$

      0.01 < p-value < 0.025.

      因為 p-value < 0.05, reject H₀.
            
6.結論: α = 0.05 的顯著水準下，有充分證據顯示這三種處理的平均數不全相等。
