### Ans:

#### μ = 1110    σ = 80   n = 400  

#### a. P(1100 < X̄ < 1110)

SE = $\dfrac{\sigma}{\sqrt{n}} = \dfrac{80}{\sqrt{400}} = \dfrac{80}{20}=4$

Z1 = (1100 - 1110) / 4 = -2.5  
Z2 = (1110 - 1110) / 4 = 0  

P(1100 < X̄ < 1110) = P(-2.5 < Z < 0)  
= P(Z < 0) - P(Z < -2.5)  
= 0.5000 - 0.0062  
= **0.4938**
