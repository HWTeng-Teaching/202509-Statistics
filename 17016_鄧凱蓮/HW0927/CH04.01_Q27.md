- 性別有2種可能：男性、女性。
- 頭髮顏色有5種可能：blonde, brown, black, red, other
- 可能的組合數量為： 2 x 5 = 10 

**結論**：總共有10種性別與頭髮顏色的組合。

| Gender | Hair Color |
|--------|------------|
| Male   | Blonde     |
| Male   | Brown      |
| Male   | Black      |
| Male   | Red        |
| Male   | Other      |
| Female | Blonde     |
| Female | Brown      |
| Female | Black      |
| Female | Red        |
| Female | Other      |
