由於總體標準差 ($\sigma$) 未知，且樣本大小 $n=21 < 30$ (小樣本)，使用T檢定  

(a) 假設檢定：治療前的平均自尊是否 < 25？

1. 設定假設

H₀：μ = 25（治療前的真實平均自尊 = 25）

H₁：μ < 25（治療前的真實平均自尊 小於 25）這是 左尾 t 檢定

2. 計算檢定統計量 t

$t = \frac{\bar{x} - \mu_0}{s / \sqrt{n}} =  \frac{25-20.3}{5 / \sqrt{21}} = -4.31 $

xˉ=20.3,μ0​=25,s=5.0,n=21

3. 自由度 df

df=n−1=20

先假設 $\alpha = 0.05$ 的顯著水準
查T表得知 $t_{0.05, 20} \approx \mathbf{-1.725} $(左尾有負號)  
t=-4.31 < -1.725 落在拒絕域，拒絕H0  
結論：在 5% 顯著水準下，有足夠證據認為治療前平均自我評價分數小於25

(b) 建構 95% 信賴區間：治療後的平均自尊 μ

資料：
x̄ = 26.6

s = 7.4

n = 21

df = 20

1. t_{0.025, 20}

自由度20，雙尾，各邊2.5%，查表 t0.025,20​=2.086

2. 標準誤
   
SE=7.4/開根號21=1.614

3. 信賴區間計算

Xˉ±t⋅SE=26.6±2.086(1.614)=26.6±3.37

4. 95% CI

(23.23, 29.97)

治療後的真實平均自尊介於約 23.2 到 30.0 之間。   

(c) 無正式檢定時，三組平均數的差異可得結論？

題目給三組平均：

Pretreatment = 20.3

Posttreatment = 26.6

Follow-up = 27.7

結論:

治療有效：治療後的平均自尊明顯高於治療前。

改善維持：在追蹤期 Follow-up，自尊甚至持續略微增加。

三組間呈現遞增趨勢 → Pretreatment < Posttreatment < Follow-up
