(b) Plot the data using a scatterplot. How would you describe the relationship between temperature and number of chirps?
```python
import matplotlib.pyplot as plt

# 資料
chirps = [20, 16, 19, 18, 18, 16, 14, 17, 15, 16]
temperature = [31, 23, 33, 29, 28, 24, 21, 28, 21, 28]

# 繪製散佈圖
plt.scatter(temperature, chirps, color='blue', marker='o')

# 標題與座標軸
plt.title("Chirps per Second vs Temperature")
plt.xlabel("Temperature (°C)")
plt.ylabel("Chirps per Second")

# 顯示圖形
plt.show()
