#### (b)  Find the correlation coefficient, r. What does this tell you about the strength and direction of the relationship between height and number of floors?
#### Ans:
#### 資料設定
- x：Floors（樓層數）
- y：Height（高度，m）
- 筆數 n = 28
#### 步驟 1：計算平均數
$\bar{x} = \frac{\sum x_i}{n} = \frac{1378}{28} = 49.2143$   

$\bar{y} = \frac{\sum y_i}{n} = \frac{5680}{28} = 202.8571$ 

（中間和必要原始和）  
$\displaystyle
\sum x_i = 1378, \quad
\sum y_i = 5680, \quad
\sum x_i^2 = 70250, \quad
\sum y_i^2 = 1203804, \quad
\sum x_i y_i = 290252
$
#### 步驟 2：計算平方和與交乘和（以「原始和」公式）
$\displaystyle
Den_x = n\sum x_i^2 - (\sum x_i)^2 = 28*(70250) - 1378^2 = 68116,$ <br>

$\displaystyle
Den_y = n\sum y_i^2 - (\sum y_i)^2 = 28*(1203804) - 5680^2 = 1{,}444{,}112,$ <br>

$\displaystyle
Num = n\sum x_i y_i - \sum x_i\sum y_i = 28*(290252) - 1378(5680) = 300{,}016.
$

#### 步驟 3：皮爾森相關係數
$\displaystyle
r = \frac{Num}{\sqrt{Den_x \times Den_y}} =
\frac{300{,}016}{\sqrt{68{,}116 \times 1{,}444{,}112}} =
0.9566 \approx 0.957
$   

**解釋：** 強烈且明顯的正相關（樓層越多，高度越高）。

#### (d)Find the least-squares line, and use it to predict the height of a building in Los Angeles that has 48 floors.
#### Ans:
- 筆數 n=28   
$\displaystyle \sum x = 1378,\quad \sum y = 5680,\quad \sum x^2 = 70250,\quad \sum y^2 = 1203804,\quad \sum xy = 290252$ <br>

$\displaystyle Den_x = 68116,\quad Den_y = 1{,}444{,}112,\quad Num = 300{,}016$ <br>   

#### 斜率 \(b\)
$\displaystyle
b = \frac{S_{xy}}{S_{xx}} = \frac{Num}{Den_x}
= \frac{300{,}016}{68{,}116} = 4.4044865\ \text{(m/樓)}
$

#### 截距 \(a\)
$\displaystyle
a = \bar{y} - b\bar{x}
= 202.8571 - 4.4044865 \times 49.2143
= -13.9065124
$

#### 迴歸方程式
$\displaystyle
\hat{y} = a + bx
= -13.9065 + 4.4045x \quad (\text{單位：公尺})
$

#### 預測（48 樓）
$\displaystyle
\hat{y}(x = 48)
= -13.9065 + 4.4045 \times 48
= 197.51\ \text{m}
$

**✅ 結論：**  
最小平方迴歸線為  
$\displaystyle \hat{y} = -13.9065 + 4.4045x$  
若樓層數為 48 層，預測高度約 **197.5 公尺**。
