CH07.05_31

<img width="656" height="870" alt="7 05 31" src="https://github.com/user-attachments/assets/22745f9c-5f6f-4488-af4d-d2264f3868e6" />

a小題：

因為這題隨機抽樣n=100，表示，按照中央極限定理，樣本比例 p^會近似常態分布。所以說，平均數（期望值）：E(p^)=p=0.47E( p^ )=p=0.47

標準差 = 開根號 ((變異數σ²＝pq)/n) = 開根號 ((0.47*(1-0.47))/100) = 0.0499

b小題：

轉換Z值查表查詢機率：(0.45-0.47)/0.0499= -0.4，查Z表 -0.4的機率，

而-0.4查表後，其機率為0.3446 (34.46%)

c小題：

轉換Z值查表查詢機率：(0.42-0.47)/0.0499= -1.0，查Z表 -1.0的機率為0.1587

轉換Z值查表查詢機率：(045-0.47)/0.0499= -0.4，查Z表-0.4的機率為0.3466

0.3466-0.1587 = 0.1879,落在這個範圍的機率為 18.79%

d小題：

轉換Z值查表查詢機率：(0.3-0.47)/0.0499= -3.4，查Z表 -3.4 的機率為 0.003

機率太低，表示這個"假設"不成立
