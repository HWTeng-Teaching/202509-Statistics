情境描述：

某種遺傳缺陷的發生率：1/1000 兒童
醫療診所檢查了 50,000 名兒童
觀察到 x = 60 名兒童有此缺陷
參數：

n = 50,000
p = 1/1000 = 0.001
觀察值：x = 60
📊 問題 a：P(X ≥ 60) = ?
如果這 50,000 名兒童是隨機樣本，觀察到 60 或更多有缺陷的機率是多少？

步驟 1：檢查常態近似條件
np = 50,000 × 0.001 = 50 ≥ 10 ✓
nq = 50,000 × 0.999 = 49,950 ≥ 10 ✓
兩個條件都滿足，可以使用常態近似！

步驟 2：計算二項分佈的參數
期望值：

μ = np = 50,000 × 0.001 = 50
標準差：

σ = √[np(1-p)]
  = √[50,000 × 0.001 × 0.999]
  = √[49.95]
  = 7.068

步驟 3：連續性修正
P(X ≥ 60) ≈ P(X > 59.5)
為什麼用 59.5？

從離散轉連續，需要連續性修正
X ≥ 60 包含 60, 61, 62, ...
在常態分佈中應從 59.5 開始算
步驟 4：計算 Z 分數
Z = (X* - μ) / σ
  = (59.5 - 50) / 7.068
  = 9.5 / 7.068
  = 1.344

步驟 5：計算機率
P(X ≥ 60) = P(Z > 1.344)
          = 1 - P(Z ≤ 1.344)
          = 1 - 0.9106
          = 0.0894
