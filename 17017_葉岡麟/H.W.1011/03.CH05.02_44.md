情境描述：

50% 的年輕人偏好 McDonald's 勝過 Burger King
隨機選取 10 位年輕人並記錄他們的偏好
X = 偏好 McDonald's 的人數
參數：

n = 10
p = 0.5
X ~ Binomial(10, 0.5)

求「超過 6 人偏好 McDonald's」的機率

解題思路：
P(X > 6) = P(X = 7) + P(X = 8) + P(X = 9) + P(X = 10)

📊 問題 c：P(4 ≤ Y ≤ 6) = ?
注意：這題問的是偏好 Burger King 的人數！

設 Y = 偏好 Burger King 的人數

重要觀念：
如果 X 人偏好 McDonald's，則 (10 - X) 人偏好 Burger King

Y = 10 - X
4 ≤ Y ≤ 6 等價於：

4 ≤ (10 - X) ≤ 6
-6 ≤ -X ≤ -4
4 ≤ X ≤ 6
所以：

P(4 ≤ Y ≤ 6) = P(4 ≤ X ≤ 6)
答案 c：
P(4 ≤ Y ≤ 6) = 0.6562 或 65.62%

結果與問題 b 相同！（因為 p = 0.5，分佈對稱）

重要觀念：
1️⃣ 對稱性
當 p = 0.5 時，二項分佈完全對稱：

P(X = k) = P(X = n-k)
2️⃣ 互補性
偏好 McDonald's 和 Burger King 是互補事件：

如果 X 人選 McDonald's
則 (10-X) 人選 Burger King
3️⃣ 累積機率的應用
P(a ≤ X ≤ b) = P(X ≤ b) - P(X ≤ a-1)
P(X > a) = 1 - P(X ≤ a)
P(X < a) = P(X ≤ a-1)
🎯 計算技巧總結
Casio fx-991CW 快速技巧：
求 P(X > a)：

1 - P(X ≤ a) 
使用 Bcd 計算 P(X ≤ a)，再用 1 減去
求 P(a ≤ X ≤ b)：

P(X ≤ b) - P(X ≤ a-1)
分別用 Bcd 計算後相減
求 P(X = a)：

直接用 Bpd 計算單點機率
🔗 延伸思考
如果樣本數增加到 100 人會怎樣？

📚 相關公式整理
二項分佈公式：
機率質量函數：

P(X = k) = C(n,k) × p^k × (1-p)^(n-k)
期望值：

E(X) = μ = np
變異數：

Var(X) = σ² = np(1-p)
標準差：

SD(X) = σ = √[np(1-p)]
