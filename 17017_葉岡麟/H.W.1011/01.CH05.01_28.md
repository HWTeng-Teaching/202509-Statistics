統計學題目解答：Which Key Fits?（機率分佈）
題目 28：Which Key Fits?
情境描述：
•	鑰匙圈上有 4 把外觀相同的鑰匙
•	只有 1 把能開辦公室門
•	隨機選一把試試，不行就從剩下的再選一把
•	每個不同的選擇順序代表一個等可能的簡單事件
________________________________________
📋 問題 a：List the simple events in S
列出樣本空間 S 中的所有簡單事件，並指定機率
分析：
設正確的鑰匙為 C (Correct)，錯誤的鑰匙為 W (Wrong)
可能的情況：
1.	第 1 次就選對：C
2.	第 2 次選對：W₁C（第1次錯，第2次對）
3.	第 3 次選對：W₁W₂C（前2次錯，第3次對）
4.	第 4 次選對：W₁W₂W₃C（前3次錯，第4次對）
________________________________________
計算每個事件的機率：
事件 1：第 1 次就成功
P(第1次成功) = 1/4
事件 2：第 2 次成功
P(第2次成功) = P(第1次錯) × P(第2次對|第1次錯)
              = (3/4) × (1/3)
              = 1/4
事件 3：第 3 次成功
P(第3次成功) = P(前2次錯) × P(第3次對|前2次錯)
              = (3/4) × (2/3) × (1/2)
              = 6/24 = 1/4
事件 4：第 4 次成功
P(第4次成功) = P(前3次錯) × P(第4次對|前3次錯)
              = (3/4) × (2/3) × (1/2) × (1/1)
              = 6/24 = 1/4

計算期望值 E(X)：
E(X) = Σ [x × p(x)]
     = 1(1/4) + 2(1/4) + 3(1/4) + 4(1/4)
     = (1 + 2 + 3 + 4)/4
     = 10/4
     = 2.5

計算變異數 Var(X)：
E(X²) = 1²(1/4) + 2²(1/4) + 3²(1/4) + 4²(1/4)
      = (1 + 4 + 9 + 16)/4
      = 30/4
      = 7.5

Var(X) = E(X²) - [E(X)]²
       = 7.5 - (2.5)²
       = 7.5 - 6.25
       = 1.25

💡 重點整理
分佈特性：
統計量	符號	數值	意義
期望值	E(X)	2.5	平均需試 2.5 把鑰匙
變異數	Var(X)	1.25	變異程度
標準差	σ	1.118	離散程度
機率	p(x)	0.25	每個結果等可能
________________________________________
分佈類型：
離散均勻分佈 (Discrete Uniform Distribution)
特徵：
•	所有可能結果的機率相等
•	p(x) = 1/n，其中 n 是可能結果數
•	本題：n = 4，所以 p(x) = 1/4
公式：
E(X) = (a + b)/2 = (1 + 4)/2 = 2.5
Var(X) = (n² - 1)/12 = (16 - 1)/12 = 1.25
________________________________________
🎯 實務意義
情境解讀：
1.	平均情況：
o	預期需要試 2.5 把鑰匙
o	實際上可能是 1, 2, 3, 或 4 把
2.	最好情況：
o	第 1 次就成功（機率 25%）
3.	最壞情況：
o	需要試全部 4 把（機率 25%）
4.	機率相等的原因：
o	鑰匙外觀相同
o	隨機選擇
o	不重複使用（無放回抽樣）

🔍 延伸思考
如果有 5 把鑰匙呢？
p(x) = 1/5 = 0.20，其中 x = 1, 2, 3, 4, 5
E(X) = (1+2+3+4+5)/5 = 3
Var(X) = (25-1)/12 = 2
如果有 n 把鑰匙？
p(x) = 1/n
E(X) = (n+1)/2
Var(X) = (n²-1)/12
