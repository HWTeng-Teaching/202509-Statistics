To find (a) or (b):<br>
(a) RR={F: $F*>F_{(k-1),(n-k),\alpha}$ }={F: F*> $F_{1,6,.05}$ }=5.99<br>
(b) $p$-value: P( $F_{(k-1),(n-k)>F*}$ )=.05 > p-value > .005<br>
$H_0$ falls into the RR, so we reject $H_0$.<br>
$b= \frac{8}{4}=2$<br>
SE= $\sqrt{\frac{\sigma^2}{S_{xx}}}$, where $\sigma^2$ is estimated with $s^2$=MSE.<br> 
Therefore, SE= $\sqrt{\frac{MSE}{S_{xx}}} = \sqrt{\frac{.667}{S_{4}}} = .4084$<br>

t*= $\frac{2}{\sqrt{.667/4}}=4.899$<br>
df=n-2=6<br>

(a) RR{ $t: t<-t_{\alpha /2}$ } or { $t: t>t_{\alpha /2}$ }<br>
=> RR{ $t: t<-2.447$ } or { $t: t>2.447$ }<br>
(b) $p$-value: .025 > p-value<br>
