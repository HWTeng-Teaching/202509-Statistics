# Answer:<br>
Population: X ~ $N(1110, 80^2)$<br>
n=400<br>
$z=\frac{\overline{X}-\mu}{\sigma/\sqrt{n}}$<br>
## a. Find $P(1100 \leq \overline{X} \leq 1110)$<br>
### $z=\frac{1110-1110}{80\sqrt{400}}=0$<br>
### $P(z=0)=.5000$<br>

### $z=\frac{1100-1110}{80\sqrt{400}}=-2.5$<br>
$P(z=-2.5)=.0062$<br>
### $P(-2.5 \leq z \leq 0)=.5-.0062=.4938$<br>


## b. Find $P(1120 < \overline{X})$<br>
### $z=\frac{1120-1110}{80\sqrt{400}}=2.5$<br>
$P(z=2.5)=.9938$<br>
### $P(2.5<z)=1-.9938=.0062$<br>
