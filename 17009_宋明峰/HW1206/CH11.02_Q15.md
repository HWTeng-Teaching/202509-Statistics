一位營造商想比較「每 1000 板尺（board meters）」的標準等級或更高等級結構用木材的價格。他在自己打算開工的四個州裡，各隨機選取五家供應商。各家的報價如下表所示。
| State | 價格（每 1000 board meters） |
| ----- | ----------------------- |
| 1     | 261, 255, 258, 267, 270 |
| 2     | 236, 240, 225, 233, 240 |
| 3     | 250, 245, 255, 248, 260 |
| 4     | 265, 270, 258, 275, 275 |
a. 這裡使用的是哪一種實驗設計？
b. 為這組資料建立變異數分析（ANOVA）表。
c. 在顯著水準 α = 0.05 下，資料是否足以支持：「四個州之間，每 1000 board meters 的平均木材價格有所差異」這個說法？

a. 實驗設計類型

單因子（factor：State，四個水準）

每州各自隨機抽樣 5 家供應商

👉 這是「完全隨機設計的單因子 ANOVA」（completely randomized one-way ANOVA design）。
