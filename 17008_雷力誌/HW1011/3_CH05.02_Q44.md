假設當被要求表達偏好時，所有年輕人中有 50% 偏好 McDonald's 而非 Burger King。現隨機選取 10 位年輕人並記錄他們的偏好

---

試驗次數（n）：10 位年輕人

成功機率（p）：偏好 McDonald's 的機率 = 0.5

隨機變數 X：10 人中偏好 McDonald's 的人數

分佈：X ~ B(10, 0.5)

二項分佈公式：

$P(X = k) = C(n, k) \times p^k \times (1-p)^{n-k}$

其中：

$( C(n, k) = \frac{n!}{k!(n-k)!} ) 為組合數（從 n 個物品中選 k 個的方法數）$

( n = 10 )（樣本數）

( p = 0.5 )（成功機率）

( k ) 為偏好 McDonald's 的人數

---

a. 超過 6 人偏好 McDonald's 的機率是多少？

( P(X > 6) = P(X = 7) + P(X = 8) + P(X = 9) + P(X = 10) )

P(X = 7)：

$P(X = 7) = C(10, 7) \times (0.5)^7 \times (0.5)^3 = 120 \times (0.5)^{10} = 0.117187$

P(X = 8)：

$P(X = 8) = C(10, 8) \times (0.5)^8 \times (0.5)^2 = 45 \times (0.5)^{10} = 0.043945$

P(X = 9)：

$P(X = 9) = C(10, 9) \times (0.5)^9 \times (0.5)^1 = 10 \times (0.5)^{10} = 0.009766$

P(X = 10)：

$P(X = 10) = C(10, 10) \times (0.5)^{10} \times (0.5)^0 = 1 \times (0.5)^{10} = 0.000977$

總和：

$P(X > 6) = 0.117187 + 0.043945 + 0.009766 + 0.000977 = 0.171875$

超過 6 人偏好 McDonald's 的機率為 0.1719 或 17.19%
