## 📝 第 15 題 (Exercise 15)

**題目已知條件：**
* 樣本數 $n = 49$
* 母體平均值 $\mu = 53$
* 母體標準差 $\sigma = 21$

### 解答：
1. **分佈形狀 (Shape)：**
   根據中央極限定理 (CLT)，由於 $n = 49 \ge 30$，樣本平均數 $\bar{x}$ 的抽樣分佈為 **近似正態分佈 (Approximately Normal)**。
2. **期望值 (Mean)：**
   $$\mu_{\bar{x}} = \mu = 53$$
3. **標準誤差 (Standard Error)：**
   $$SE = \sigma_{\bar{x}} = \frac{\sigma}{\sqrt{n}} = \frac{21}{\sqrt{49}} = \frac{21}{7} = 3$$

## 📝 第 23 題 (Exercise 23) - 電池壽命

**題目已知條件：**
* 母體平均值 $\mu = 1110$ 天
* 母體標準差 $\sigma = 80$ 天
* 樣本數 $n = 400$

### 準備計算：抽樣分佈參數
* **分佈：** 由於 $n = 400$ 遠大於 30，根據中央極限定理，$\bar{x}$ 服從正態分佈。
* **標準誤差 (SE)：**
  $$SE = \frac{\sigma}{\sqrt{n}} = \frac{80}{\sqrt{400}} = \frac{80}{20} = 4$$

### (a) 平均值介於 1100 與 1110 之間
1. 計算 $z$ 分數：
   * $z_1 = \frac{1100 - 1110}{4} = -2.5$
   * $z_2 = \frac{1110 - 1110}{4} = 0$
2. 查找概率：
   $$P(1100 < \bar{x} < 1110) = P(-2.5 < Z < 0)$$
   $$= \Phi(0) - \Phi(-2.5) = 0.5 - 0.0062 = 0.4938$$
**答案：0.4938**

### (b) 平均值大於 1120
1. 計算 $z$ 分數：
   * $z = \frac{1120 - 1110}{4} = 2.5$
2. 查找概率：
   $$P(\bar{x} > 1120) = P(Z > 2.5)$$
   $$= 1 - \Phi(2.5) = 1 - 0.9938 = 0.0062$$
**答案：0.0062**

### (c) 平均值小於 900
1. 計算 $z$ 分數：
   * $z = \frac{900 - 1110}{4} = \frac{-210}{4} = -52.5$
2. 查找概率：
   由於 $z = -52.5$ 極小，在標準正態分佈中其概率趨近於 0。
**答案：$\approx 0$**
