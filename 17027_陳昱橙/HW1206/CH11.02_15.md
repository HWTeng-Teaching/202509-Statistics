## a. 實驗設計類型 (Type of Experimental Design)

**答案：完全隨機設計 (Completely Randomized Design, CRD)**

**原因：**
1.  **單一因子**：實驗中僅有一個自變數（因子），即「州」(State)。
2.  **隨機抽樣**：題目指出建商在每個州「隨機選擇」(randomly selects) 5 個供應商。
3.  **獨立性**：樣本是隨機選取且獨立分配到各個處理組（州）中的。

## b. 建構變異數分析表 (ANOVA Table)

### 1. 計算平方和 (Sum of Squares)

首先計算**校正項 (Correction Factor, CF)**：
$$CF = \frac{(\sum x)^2}{N} = \frac{(5086)^2}{20} = \frac{25,867,396}{20} = 1,293,369.8$$

**(1) 總平方和 (SST, Total Sum of Squares):**
將所有 20 個原始數據平方相加 ($\sum x^2 = 1,297,302$)，再減去 CF。
$$SST = \sum x^2 - CF = 1,297,302 - 1,293,369.8 = \mathbf{3,932.2}$$

**(2) 組間平方和 (SSTr, Treatment Sum of Squares):**
利用各組總和 ($T_i$) 計算。
$$SSTr = \sum \frac{T_i^2}{n_i} - CF$$
$$SSTr = \left( \frac{1311^2}{5} + \frac{1174^2}{5} + \frac{1258^2}{5} + \frac{1343^2}{5} \right) - 1,293,369.8$$
$$SSTr = 1,296,642 - 1,293,369.8 = \mathbf{3,272.2}$$

**(3) 誤差平方和 (SSE, Error Sum of Squares):**
$$SSE = SST - SSTr = 3,932.2 - 3,272.2 = \mathbf{660.0}$$

### 2. 計算均方 (Mean Square) 與 F 值

* **均方 (MS)**:
    * $MSTr = SSTr / (k-1) = 3272.2 / 3 = 1090.73$
    * $MSE = SSE / (N-k) = 660.0 / 16 = 41.25$
* **F 統計量**:
    * $F = MSTr / MSE = 1090.73 / 41.25 = \mathbf{26.44}$

### 3. 最終 ANOVA 表格

| Source of Variation (變異來源) | df (自由度) | SS (平方和) | MS (均方) | F Value |
| :--- | :---: | :---: | :---: | :---: |
| **Treatments (州)** | $4-1=3$ | 3,272.2 | 1,090.73 | **26.44** |
| **Error (誤差)** | $20-4=16$ | 660.0 | 41.25 | |
| **Total (總和)** | $20-1=19$ | 3,932.2 | | |

## c. 假設檢定 (Hypothesis Test)

**題目**：是否有足夠證據顯示四個州的平均木材價格不同？($\alpha = .05$)

### 1. 設立假設
* **$H_0$ (虛無假設)**: $\mu_1 = \mu_2 = \mu_3 = \mu_4$ (四個州的平均價格皆相同)
* **$H_1$ (對立假設)**: 至少有一組平均值與其他不同

### 2. 決策規則 (Decision Rule)
* **F 統計量**: $F = 26.44$
* **臨界值 (Critical Value)**: 查表 $F(0.05, 3, 16) = 3.24$
* **規則**: 若 $F > 3.24$，則拒絕 $H_0$。

### 3. 結論 (Conclusion)
因為計算出的 **$F = 26.44$** 遠大於臨界值 **$3.24$**，我們**拒絕虛無假設 ($H_0$)**。

**解釋：**
在 5% 的顯著水準下，有**充分的證據 (sufficient evidence)** 顯示，這四個州的框架木材平均價格（per 1000 board meters）存在顯著差異。
