# 統計學作業解答：Reducing Hostility (單因子 ANOVA)

## 題目摘要
比較三種減少大學生敵意的方法 (Method A, B, C) 是否有顯著差異。
- **Method A**: 73, 83, 76, 68, 80 ($n=5$)
- **Method B**: 54, 74, 71 ($n=3$)
- **Method C**: 79, 95, 87 ($n=3$)

---

## 步驟 1：基本統計量 (Basic Statistics)

我們先計算各組的總和 ($T_i$) 與總樣本的修正因子 ($CF$)，以確保後續計算精確。

| 組別 | 數據 ($x_{ij}$) | 樣本數 ($n_i$) | 總和 ($T_i$) | 平均 ($\bar{x}_i$) |
| :---: | :--- | :---: | :---: | :---: |
| **A** | 73, 83, 76, 68, 80 | 5 | 380 | 76.00 |
| **B** | 54, 74, 71 | 3 | 199 | 66.33 |
| **C** | 79, 95, 87 | 3 | 261 | 87.00 |
| **總計** | | **$N=11$** | **$G=840$** | |

### 關鍵參數計算
1. **原始數據平方和 ($\sum x^2$)**:
   $$73^2 + ... + 87^2 = \mathbf{65286}$$
2. **修正因子 (Correction Factor, CF)**:
   $$CF = \frac{G^2}{N} = \frac{840^2}{11} \approx \mathbf{64145.4545}$$

---

## 步驟 2：變異數平方和 (Sum of Squares)

這裡使用**計算公式** (Computational Formula) 來避免小數點四捨五入的誤差。

### 1. 總變異 (SST)
$$SST = \sum x^2 - CF$$
$$SST = 65286 - 64145.4545 = \mathbf{1140.5455}$$

### 2. 處理間變異 (SSTR)
公式：
$$
SSTR = \sum \frac{T_i^2}{n_i} - CF
$$

- Method A: $380^2 / 5 = 28880$
- Method B: $199^2 / 3 \approx 13200.3333$
- Method C: $261^2 / 3 = 22707$

$$SSTR = (28880 + 13200.3333 + 22707) - 64145.4545$$
$$SSTR = 64787.3333 - 64145.4545 = \mathbf{641.8788}$$

### 3. 誤差變異 (SSE)
$$SSE = SST - SSTR$$
$$SSE = 1140.5455 - 641.8788 = \mathbf{498.6667}$$

---

## 步驟 3：變異數分析表 (ANOVA Table)

| 變異來源 (Source) | 自由度 (df) | 平方和 (SS) | 平均平方 (MS) | F 檢定值 |
| :--- | :---: | :---: | :---: | :---: |
| **處理間 (Treatments)** | $3-1=2$ | $641.88$ | $320.94$ | **5.15** |
| **誤差 (Error)** | $11-3=8$ | $498.67$ | $62.33$ | |
| **總計 (Total)** | $11-1=10$ | $1140.55$ | | |

* **計算細節**:
  * $MSTR = 641.88 / 2 = 320.94$
  * $MSE = 498.67 / 8 = 62.33$
  * $F = 320.94 / 62.33 \approx 5.149 \Rightarrow \mathbf{5.15}$

---

## 步驟 4：檢定結論 (Hypothesis Test)

### (a) 虛無與對立假設
- $H_0: \mu_A = \mu_B = \mu_C$ (三種方法的平均效果相同)
- $H_a$: 至少有一種方法的平均效果不同

### (b) 臨界值與決策
- **顯著水準**: $\alpha = 0.05$
- **自由度**: $df_1 = 2, df_2 = 8$
- **臨界值**: 查表得 $F_{0.05, 2, 8} = \mathbf{4.46}$
- **判斷**:
  $$F_{\text{calc}} (5.15) > F_{\text{crit}} (4.46)$$
  檢定統計量落入拒絕域。

### (c) 結論
**拒絕虛無假設 ($H_0$)**。
有充分的統計證據顯示，這三種減少敵意的方法對學生的平均效果存在**顯著差異**。
