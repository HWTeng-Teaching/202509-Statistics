# 統計學解題：Reducing Hostility (單因子 ANOVA)

## 題目資訊
心理學家想比較三種減少大學生敵意的方法（Method A, B, C）。
- **Method A**: 73, 83, 76, 68, 80
- **Method B**: 54, 74, 71
- **Method C**: 79, 95, 87

---

## 步驟 1：基本統計量計算 (Basic Statistics)

首先整理各組的樣本數 ($n$)、總和 ($T_i$)、平均數 ($\bar{x}_i$) 與平方和 ($\sum x^2$)。

| 組別 (Method) | 原始數據 | $n_i$ | 總和 ($T_i$) | 平均數 ($\bar{x}_i$) | 平方和 ($\sum x_{ij}^2$) |
| :---: | :--- | :---: | :---: | :---: | :---: |
| **A** | 73, 83, 76, 68, 80 | 5 | 380 | 76.00 | $73^2+...+80^2 = 29018$ |
| **B** | 54, 74, 71 | 3 | 199 | 66.33 | $54^2+...+71^2 = 13433$ |
| **C** | 79, 95, 87 | 3 | 261 | 87.00 | $79^2+...+87^2 = 22835$ |
| **總計 (Total)** | | **11** | **840** | **76.36** | **65286** |

* **總樣本數**: $N = 11$
* **總和**: $G = \sum T_i = 840$
* **修正因子 (Correction Factor, CF)**:
  $$CF = \frac{G^2}{N} = \frac{840^2}{11} = \frac{705600}{11} \approx 64145.4545$$

---

## 步驟 2：計算變異平方和 (Sum of Squares)

### 1. 總變異 (Total Sum of Squares, SST)
$$SST = \sum x_{ij}^2 - CF$$
$$SST = 65286 - 64145.4545 = \mathbf{1140.5455}$$

### 2. 處理間變異 (Sum of Squares for Treatments, SSTR)
公式：$SSTR = \sum \frac{T_i^2}{n_i} - CF$

* Method A: $\frac{380^2}{5} = 28880$
* Method B: $\frac{199^2}{3} \approx 13200.3333$
* Method C: $\frac{261^2}{3} = 22707$

$$SSTR = (28880 + 13200.3333 + 22707) - 64145.4545$$
$$SSTR = 64787.3333 - 64145.4545 = \mathbf{641.8788}$$

### 3. 誤差變異 (Sum of Squares for Error, SSE)
利用加法性質計算：
$$SSE = SST - SSTR$$
$$SSE = 1140.5455 - 641.8788 = \mathbf{498.6667}$$

*(驗證：也可以直接加總各組內的變異平方和，結果會相同)*

---

## 步驟 3：變異數分析表 (ANOVA Table)

計算自由度 ($df$)、平均平方 ($MS$) 與 $F$ 統計量。

* $df_{Treatment} = k - 1 = 3 - 1 = 2$
* $df_{Error} = N - k = 11 - 3 = 8$
* $MSTR = \frac{SSTR}{df_{Tr}} = \frac{641.8788}{2} \approx 320.94$
* $MSE = \frac{SSE}{df_{E}} = \frac{498.6667}{8} \approx 62.33$
* $F = \frac{MSTR}{MSE} = \frac{320.94}{62.33} \approx 5.15$

| 變異來源 (Source) | 自由度 (df) | 平方和 (SS) | 平均平方 (MS) | F 檢定統計量 |
| :--- | :---: | :---: | :---: | :---: |
| **處理間 (Treatments)** | 2 | 641.88 | 320.94 | **5.15** |
| **誤差 (Error)** | 8 | 498.67 | 62.33 | |
| **總計 (Total)** | 10 | 1140.55 | | |

---

## 步驟 4：假設檢定與結論

### (a) 執行變異數分析
如上表所示，我們計算出檢定統計量 **$F = 5.15$**。

### (b) 是否有足夠證據顯示三種方法的平均分數有差異？

1.  **設立假設**:
    * 虛無假設 $H_0: \mu_A = \mu_B = \mu_C$ (三種方法效果相同)
    * 對立假設 $H_a$: 至少有一種方法的平均分數不同

2.  **決定拒絕域 (Rejection Region)**:
    * 顯著水準：設 $\alpha = 0.05$ (一般標準)
    * 自由度：$df_1 = 2, df_2 = 8$
    * 查表 (F-distribution Table)：$F_{0.05, 2, 8} = \mathbf{4.46}$
    * 拒絕法則：若 $F_{calc} > 4.46$ 則拒絕 $H_0$

3.  **檢定結果**:
    * 計算值 $F = 5.15$
    * 臨界值 $F_{crit} = 4.46$
    * **$5.15 > 4.46$**，落入拒絕域。

4.  **結論**:
    **拒絕虛無假設 ($H_0$)**。
    有足夠的證據顯示，經過這三種不同方法處理後，學生的平均敵意分數存在**顯著差異**。
