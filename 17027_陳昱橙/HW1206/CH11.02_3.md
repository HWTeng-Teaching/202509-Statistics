### (A) ANOVA 表格

| 變異來源 (Source) | SS (平方和) | df (自由度) | MS (平均平方) | F 統計量 |
| :--- | :--- | :--- | :--- | :--- |
| **處理間 (Treatments)** | $\text{SSTR} = 17.2$ | $k-1 = 2$ | $\text{MSTR} = 8.6$ | $8.32$ |
| **誤差 (Error)** | $\text{SSE} = 12.4$ | $N-k = 12$ | $\text{MSE} \approx 1.033$ | |
| **總計 (Total)** | $\text{SST} = 29.6$ | $N-1 = 14$ | | |

* **計算詳情**:
    * $\text{SST} = \sum x^2 - N\bar{\bar{x}}^2 = 131 - 15(2.6)^2 = 29.6$
    * $\text{SSTR} = 5(2.8-2.6)^2 + 5(3.8-2.6)^2 + 5(1.2-2.6)^2 = 17.2$
    * $\text{MSTR} = \frac{17.2}{2} = 8.6$
    * $\text{MSE} = \frac{12.4}{12} \approx 1.033$
    * $F = \frac{8.6}{1.033} \approx 8.32$

### (B) 正式檢定 ($\alpha = 0.05$)

1.  **假設**: $H_0: \mu_1 = \mu_2 = \mu_3$
2.  **檢定統計量**: $F = 8.32$
3.  **拒絕域**: 
    - 臨界值 $F_{0.05, 2, 12} \approx 3.89$
    - 拒絕域為 $F > 3.89$
4.  **p-值範圍**: $p\text{-value} < 0.01$ (因為 $F_{\text{test}} > F_{0.01, 2, 12} \approx 6.93$)
5.  **結論**: 由於 $F_{\text{test}} (8.32) > F_{\text{critical}} (3.89)$，我們 **拒絕 $H_0$**。這三個處理的平均數存在顯著差異。
