## 1. ANOVA 表格與檢定

### 參數
- 處理組 ($k$): 6
- 總樣本 ($N$): 30
- $\text{SST} = 21.4, \text{SSE} = 16.2$

### (A) ANOVA 表
| 來源 | SS | df | MS | F |
| :--- | :--- | :--- | :--- | :--- |
| **處理間** | $\text{SSTR} = 5.2$ | 5 | $\text{MSTR} = 1.04$ | $1.54$ |
| **誤差** | $16.2$ | 24 | $\text{MSE} = 0.675$ | |
| **總計** | $21.4$ | 29 | | |

### (B) 正式檢定 ($\alpha = 0.05$)
1.  **假設**: $H_0: \mu_1 = \dots = \mu_6$
2.  **檢定統計量**: $F = 1.54$
3.  **拒絕域**: $F_{0.05, 5, 24} \approx 2.62$。拒絕 $H_0$ 當 $F > 2.62$。
4.  **p-值**: $p\text{-value} > 0.05$
5.  **結論**: $F_{\text{test}} < F_{\text{critical}}$，**不拒絕 $H_0$**。
