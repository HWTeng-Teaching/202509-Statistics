### 1. 基礎統計量 (Basic Statistics)
首先計算各組平均數 ($\bar{x}_j$) 與總平均數 ($\bar{\bar{x}}$)。
- **Treatment 1**: $\{3, 2, 4, 3, 2\}$, Sum=14, $\bar{x}_1 = 2.8$
- **Treatment 2**: $\{4, 3, 5, 2, 5\}$, Sum=19, $\bar{x}_2 = 3.8$
- **Treatment 3**: $\{2, 0, 2, 1, 1\}$, Sum=6,  $\bar{x}_3 = 1.2$
- **總平均 (Grand Mean)**: $\bar{\bar{x}} = \frac{14+19+6}{15} = \frac{39}{15} = 2.6$

---

### 2. 平方和計算 (Sum of Squares Calculation)



**A. 處理間平方和 (SSTR)**
公式: $\sum n_j (\bar{x}_j - \bar{\bar{x}})^2$

$$
\begin{aligned} 
\text{SSTR} &= 5(2.8 - 2.6)^2 + 5(3.8 - 2.6)^2 + 5(1.2 - 2.6)^2 \\ 
&= 5(0.04) + 5(1.44) + 5(1.96) \\ 
&= 0.2 + 7.2 + 9.8 \\ 
&= \mathbf{17.2} 
\end{aligned}
$$

**B. 誤差平方和 (SSE)**
公式: $\sum \sum (x_{ij} - \bar{x}_j)^2$
- Group 1: $(0.2)^2 + (-0.8)^2 + (1.2)^2 + (0.2)^2 + (-0.8)^2 = 2.8$
- Group 2: $(0.2)^2 + (-0.8)^2 + (1.2)^2 + (-1.8)^2 + (1.2)^2 = 6.8$
- Group 3: $(0.8)^2 + (-1.2)^2 + (0.8)^2 + (-0.2)^2 + (-0.2)^2 = 2.8$

\text{SSE} = 2.8 + 6.8 + 2.8 = \mathbf{12.4}


**C. 總平方和 (SST)**

SST= SSTR + SSE = 17.2 + 12.4 = 29.6


---

### 3. ANOVA 表格與 F 值 (ANOVA Table)

| Source | df | SS | MS (Mean Square) | F |
| :--- | :--- | :--- | :--- | :--- |
| **Treatments** | $3-1=2$ | $17.2$ | $17.2 / 2 = \mathbf{8.6}$ | $\mathbf{8.32}$ |
| **Error** | $15-3=12$ | $12.4$ | $12.4 / 12 \approx \mathbf{1.033}$ | |
| **Total** | $14$ | $29.6$ | | |

* **F 值計算細節**:
  $$F = \frac{\text{MSTR}}{\text{MSE}} = \frac{8.6}{1.0333...} \approx 8.322 \Rightarrow \mathbf{8.32}$$

---

### 4. 檢定結論 (Conclusion)
- **假設**: $H_0: \mu_1 = \mu_2 = \mu_3$
- **臨界值**: $F_{0.05, 2, 12} \approx 3.89$
- **決策**: 由於 $8.32 > 3.89$，落入拒絕域。
- **結論**: **拒絕 $H_0$**，有充分證據顯示三組平均數存在顯著差異。
