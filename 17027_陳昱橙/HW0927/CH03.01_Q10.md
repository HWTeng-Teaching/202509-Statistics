# 第10題：手機問題詳解

這題是關於比較八年級男女生擁有手機比例的統計問題。

### 原始數據

| | 有手機 (Cell Phone) | 沒有手機 (No Cell Phone) | 總計 |
| :-- | :---: | :---: | :---: |
| **男生 (Boys)** | 52 | 48 | 100 |
| **女生 (Girls)**| 55 | 45 | 100 |

### 百分比分析

為了方便比較，我們先將數據轉換為百分比。

-   **擁有手機的男生比例**: `52 / (52 + 48) = 52%`
-   **擁有手機的女生比例**: `55 / (55 + 45) = 55%`

### a. 堆疊長條圖 (Stacked bar chart)

堆疊長條圖會將每個群體（男生和女生）的數據堆疊在一個長條中。

-   **圖表結構**:
    1.  X軸會是類別：`男生` 和 `女生`。
    2.  Y軸會是人數或百分比。
    3.  會有兩個長條，一個代表男生，一個代表女生。
    4.  每個長條都會由兩個顏色區塊堆疊而成：
        -   一個區塊代表「有手機」的人數 (男=52, 女=55)。
        -   另一個區塊代表「沒有手機」的人數 (男=48, 女=45)。
-   **視覺效果**:
    因為男生和女生的總人數恰好都是100，所以兩個長條的總高度會一樣。透過這個圖，可以很清楚地看到在各個性別中，有手機和沒有手機的人數分佈。

### b. 並列長條圖 (Side-by-side bar chart)

並列長條圖會將不同類別的數據並排陳列，方便直接比較。

-   **圖表結構**:
    1.  X軸會是類別：`男生` 和 `女生`。
    2.  Y軸是人數或百分比。
    3.  在 `男生` 這個類別下，會有兩個並排的長條：一個是「有手機」(高度52)，另一個是「沒有手機」(高度48)。
    4.  在 `女生` 這個類別下，也會有兩個對應的並排長條：「有手機」(高度55)和「沒有手機」(高度45)。
-   **視覺效果**:
    這種圖表非常適合用來直接比較男生和女生在「有手機」這個項目上的差異，以及在「沒有手機」項目上的差異。

### c. 關於男女生之間的相似處與差異

**結論**: **男女生擁有手機的比例非常相似，差異極小。**

-   **相似處 (Similarities)**:
    -   在男生和女生這兩個群體中，擁有手機的人數都略高於沒有手機的人數，比例都接近一半一半。

-   **差異處 (Differences)**:
    -   女生擁有手機的比例 (`55%`) 略高於男生 (`52%`)。
    -   這個差異非常微小，只有3個百分點。從統計學的角度來看，如果沒有更進一步的檢定，我們通常會認為這個差異不顯著 (not significant)。

總體來說，根據這份數據，八年級男女生是否擁有手機的情況沒有太大不同。
