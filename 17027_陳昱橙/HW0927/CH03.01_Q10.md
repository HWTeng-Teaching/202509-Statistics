## 1. 問題與數據分析

題目提供了一組關於八年級男女生是否擁有手機的調查數據。

#### 原始數據

| | 有手機 (Cell Phone) | 沒有手機 (No Cell Phone) | 總計 |
| :-- | :---: | :---: | :---: |
| **男生 (Boys)** | 52 | 48 | 100 |
| **女生 (Girls)**| 55 | 45 | 100 |

#### 數據分析

為了方便比較，我們先將數據轉換為百分比：

-   **擁有手機的男生比例**: `52 / 100 = 52%`
-   **擁有手機的女生比例**: `55 / 100 = 55%`

從數據上看，女生擁有手機的比例 (`55%`) 略高於男生 (`52%`)，但差距非常小。

## 2. 圖表視覺化 (a & b)

我們可以使用 Python 的 `matplotlib` 和 `pandas` 函式庫來繪製題目要求的兩種圖表。

#### Python 程式碼

```python
import pandas as pd
import matplotlib.pyplot as plt

# 建立資料
data = {
    'Cell Phone': {'Boys': 52, 'Girls': 55},
    'No Cell Phone': {'Boys': 48, 'Girls': 45}
}
df = pd.DataFrame(data)

# 繪製堆疊長條圖 (Stacked Bar Chart)
df.plot(kind='bar', stacked=True, figsize=(8, 6), rot=0)
plt.title('Stacked Bar Chart of Cell Phone Ownership')
plt.xlabel('Group')
plt.ylabel('Number of Students')
plt.legend(title='Status')
for c in plt.gca().containers:
    plt.gca().bar_label(c, label_type='center')
plt.tight_layout()
plt.savefig('stacked_bar_chart.png')
plt.close()

# 繪製並列長條圖 (Side-by-Side Bar Chart)
df.plot(kind='bar', stacked=False, figsize=(8, 6), rot=0)
plt.title('Side-by-Side Bar Chart of Cell Phone Ownership')
plt.xlabel('Group')
plt.ylabel('Number of Students')
plt.legend(title='Status')
for c in plt.gca().containers:
    plt.gca().bar_label(c, label_type='edge')
plt.ylim(0, 60)
plt.tight_layout()
plt.savefig('side_by_side_bar_chart.png')
plt.close()
```

## 3. 相似處與差異解釋 (c)

**最終結論：男女生擁有手機的比例非常相似，沒有顯著差異。**

-   **相似處 (Similarities)**:
    -   兩個群體（男生和女生）擁有手機的比例都剛好超過一半，分佈情況非常接近。
    -   從堆疊長條圖中可以看出，兩個長條內部的顏色區塊分佈幾乎一樣。

-   **差異處 (Differences)**:
    -   女生擁有手機的比例 (`55%`) 略高於男生 (`52%`)，但兩者僅相差 **3個百分點**。
    -   在並列長條圖中，代表「有手機」的兩根長條高度非常接近，直觀地顯示了這個微小的差異。

總體而言，根據這份數據，我們可以得到的解釋是：**在這個八年級的樣本中，性別與是否擁有手機之間沒有明顯的關聯。**
