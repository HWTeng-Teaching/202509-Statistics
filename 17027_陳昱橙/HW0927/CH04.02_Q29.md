# 問題29：幼稚園就學調查之機率分析

本文件將分析一份針對 25 名幼稚園學生的性別與是否上過幼稚園的調查數據，並回答相關的機率問題。

---

### 數據整理與總計

首先，我們將題目提供的數據整理成一個包含總計的表格，方便後續計算。

| | 男性 (Male) | 女性 (Female) | **總計 (Total)** |
| :--- | :---: | :---: | :---: |
| **上過幼稚園 (Preschool)** | 8 | 9 | 17 |
| **沒上過幼稚園 (No Preschool)**| 6 | 2 | 8 |
| **總計 (Total)** | **14** | **11** | **25** |

---

### a. 樹狀圖與獨立事件 (Tree Diagram and Simple Events)

這個實驗由兩個階段組成：記錄性別，然後記錄就學經驗。

#### **樹狀圖結構**

```
                   ┌── 上過幼稚園 (P)  ->  (結果 1: 男性, 上過)
            ┌── 男性 (M) ───┤
            │                  └── 沒上過幼稚園 (NP) ->  (結果 2: 男性, 沒上過)
(起始點) ──┤
            │                  ┌── 上過幼稚園 (P)  ->  (結果 3: 女性, 上過)
            └── 女性 (F) ───┤
                               └── 沒上過幼稚園 (NP) ->  (結果 4: 女性, 沒上過)
```

#### **獨立事件數量**
從樹狀圖的最終分枝可以看出，這個實驗共有 **4 個**可能的獨立結果 (simple events)：
1.  男性且上過幼稚園 (Male, Preschool)
2.  男性且沒上過幼稚園 (Male, No Preschool)
3.  女性且上過幼稚園 (Female, Preschool)
4.  女性且沒上過幼稚園 (Female, No Preschool)

---

### b. 為獨立事件分配機率 (Assigning Probabilities to Simple Events)

根據數據總表，我們可以計算出每個獨立事件發生的機率（總人數為 25）。

-   **P(男性 且 上過幼稚園)** = `8 / 25` = 0.32
-   **P(男性 且 沒上過幼稚園)** = `6 / 25` = 0.24
-   **P(女性 且 上過幼稚園)** = `9 / 25` = 0.36
-   **P(女性 且 沒上過幼稚園)** = `2 / 25` = 0.08

*(驗證：0.32 + 0.24 + 0.36 + 0.08 = 1.0)*

---

### c. 選中男性的機率 (Probability of Selecting a Male)

要計算隨機選中的學生是男性的機率，我們需要用男性的總數除以全體總數。

```math
P(\text{男性}) = \frac{\text{男性總人數}}{\text{全體總人數}}
```

根據表格，男性總人數為 14 人。
```math
P(\text{男性}) = \frac{14}{25} = 0.56
```
**結論：選中男性的機率是 14/25 (或 56%)。**

---

### d. 選中「女性且未上過幼稚園」的機率 (Probability of Selecting a Female and No Preschool)

這個問題要求的是一個獨立事件的機率，我們可以直接從數據表格中找到對應的人數。

```math
P(\text{女性 且 沒上過幼稚園}) = \frac{\text{符合條件的人數}}{\text{全體總人數}}
```
根據表格，女性且沒上過幼稚園的人數為 2 人。
```math
P(\text{女性 且 沒上過幼稚園}) = \frac{2}{25} = 0.08
```
**結論：選中女性且沒上過幼稚園的學生的機率是 2/25 (或 8%)。**
