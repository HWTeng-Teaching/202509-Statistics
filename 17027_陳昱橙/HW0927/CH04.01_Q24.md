# 問題24：社群媒體帳號調查分析 (GitHub 格式)

這份文件使用樹狀圖的概念，來找出一個學生針對四個社群平台 (Facebook, Twitter, Instagram, Snapchat) 回答「有帳號 (Yes)」或「沒有帳號 (No)」時，所有可能的結果組合。

---

### 1. 樹狀圖的結構解析

這個實驗可以看作是一個有四個連續階段的過程，每個階段都有兩種可能的結果 (Yes/No)。樹狀圖的結構會如下展開：

-   **第一層 (Facebook)**: 從一個起始點開始，分出兩個樹枝：Y (有) 和 N (沒有)。
-   **第二層 (Twitter)**: 從上一層的每個樹枝 (Y 和 N) 再各自延伸出兩個新的樹枝 (Y 和 N)。至此，總共已經有 `2 x 2 = 4` 條路徑。
-   **第三層 (Instagram)**: 從現有的 4 條路徑末端，再各自延伸出兩個新的樹枝 (Y 和 N)，形成 `4 x 2 = 8` 條路徑。
-   **第四層 (Snapchat)**: 同樣地，從 8 條路徑末端再各自延伸出兩個樹枝，最終得到 `8 x 2 = 16` 條路徑。

#### 樹狀圖結構示意 (前三層)

為了方便理解，以下用文字示意圖畫出前三層的結構：

```
                   ┌── Y (IG) --> (8條路徑的起點)
            ┌── Y (Twitter) ┤
            │      └── N (IG) --> (...)
(起始點) ──┤
            │      ┌── Y (IG) --> (...)
            └── N (Twitter) ┤
                   └── N (IG) --> (...)
```
每一條從「起始點」到最末端樹枝的路徑，都代表一個獨立的結果 (simple event)。

---

### 2. 所有可能的結果 (樣本空間)

根據乘法原理，總共的結果數量為：
```math
2 \times 2 \times 2 \times 2 = 2^4 = 16
```
這 16 個獨立結果（或稱簡單事件）就是這個實驗的樣本空間 (Sample Space)。我們可以用一個表格來清晰地列出所有組合（Y 代表 Yes, N 代表 No）：

### 3. 結論

總結來說，這個實驗共有 **16 個**可能的獨立結果 (simple events)。樹狀圖是一個有效的思考工具，可以幫助我們系統性地找出並視覺化所有這些結果，確保沒有任何遺漏。上面表格所列出的 16 種組合，就是完整的樣本空間。
