### 翻譯

請填寫練習題 4-5 中所示，簡單線性迴歸分析的變異數分析表（ANOVA table）中的缺失數值。

<img width="489" height="167" alt="image" src="https://github.com/user-attachments/assets/dbd9f1d4-0713-49a2-957f-95f8f0436ad8" />

基本觀念在簡單線性迴歸（只有一個自變數 $x$）中：

1. 自由度 ($df$) 關係：

Regression (迴歸) $df = 1$ (因為只有一個自變數)。

Total (總和) $df = n - 1$。

Error (誤差) $df = \text{Total } df - \text{Regression } df$。

2. 平方和 ($SS$) 關係：

$\text{Total } SS = \text{Regression } SS + \text{Error } SS$。

所以，

$\text{Error } SS = \text{Total } SS - \text{Regression } SS$。

3. 均方 ($MS$) 計算：

$\text{Regression } MS = \text{Regression } SS / \text{Regression } df$。

$\text{Error } MS = \text{Error } SS / \text{Error } df$。

a. 計算步驟填寫 Regression $df$：

◆ 因為是簡單線性迴歸，故 $df = 1$。

b. 計算 Error $df$：

◆ 已知 Total $df = 19$，Regression $df = 1$。

◆ Error $df = 19 - 1 = 18$。

c. 計算 Error $SS$：

◆已知 Total $SS = 12.5$，Regression $SS = 4.3$。

◆ Error $SS = 12.5 - 4.3 = 8.2$。

d. 計算 Regression $MS$：$MS = 4.3 / 1 = 4.3$。

e. 計算 Error $MS$：

$MS = 8.2 / 18 \approx 0.456$ (四捨五入至小數點後三位)。
