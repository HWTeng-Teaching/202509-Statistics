## 題目翻譯

# 題目 15. The Cost of Lumber (木材的成本)

一位建築商想要比較「標準」或「更高等級」框架木材每 1000 板公尺（board meters）的價格。他在計畫開始施工的四個州（State）中，每個州隨機選擇了五家供應商。價格數據如下表所示（單位：美元）。

| 州 1 | 州 2 | 州 3 | 州 4 |
| :---: | :---: | :---: | :---: |
| \$261 | \$236 | \$250 | \$265 |
| 255 | 240 | 245 | 270 |
| 258 | 225 | 255 | 258 |
| 267 | 233 | 248 | 275 |
| 270 | 240 | 260 | 275 |

**問題：**
* **a.** 請問使用了哪種實驗設計？
* **b.** 為此數據建構變異數分析（ANOVA）表。
* **c.** 這些數據是否提供足夠的證據顯示這四個州的框架木材每 1000 板公尺的平均價格有所不同？使用 $\alpha = .05$ 進行檢定。

---

## 解答

### a. 實驗設計類型

**答案：完全隨機設計 (Completely Randomized Design, CRD)**

**原因：**
在這個實驗中，我們只有一個感興趣的因子（Factor），即「州」（State），並且該因子有 4 個水準（Levels）。樣本是從每個總體中獨立且隨機抽取的，沒有進行區集（Blocking）。

### b. 建構變異數分析 (ANOVA) 表

#### 1. 計算各組平均值與總平均

首先計算每個州（組）的樣本數 ($n$)、總和 ($\sum x$) 和平均值 ($\bar{x}$)：

* **State 1:** $261, 255, 258, 267, 270$
    * $\bar{x}_1 = 262.2$
* **State 2:** $236, 240, 225, 233, 240$
    * $\bar{x}_2 = 234.8$
* **State 3:** $250, 245, 255, 248, 260$
    * $\bar{x}_3 = 251.6$
* **State 4:** $265, 270, 258, 275, 275$
    * $\bar{x}_4 = 268.6$

* **總體數據：**
    * 總樣本數 $N = 20$
    * 組數 $k = 4$
    * 總平均 $\bar{\bar{x}} = \frac{262.2 + 234.8 + 251.6 + 268.6}{4} = 254.3$

#### 2. 計算平方和 (Sum of Squares)

* **組間平方和 (Sum of Squares Between, SSTR):**

   衡量各組平均值與總平均值的差異。

    $$SSTR = \sum n_i (\bar{x}_i - \bar{\bar{x}})^2$$

    $$SSTR = 5(262.2 - 254.3)^2 + 5(234.8 - 254.3)^2 + 5(251.6 - 254.3)^2 + 5(268.6 - 254.3)^2$$

    $$SSTR = 5(62.41) + 5(380.25) + 5(7.29) + 5(204.49)$$

    $$SSTR = 312.05 + 1901.25 + 36.45 + 1022.45 = \mathbf{3272.2}$$

* **組內平方和 (Sum of Squares Error, SSE):**
    衡量組內數據與該組平均值的差異（變異）。可以透過計算每組的變異數或偏差平方和求得。

   $$SSE = \sum (x_{ij} - \bar{x}_j)^2$$

    * State 1 SSE: $(261-262.2)^2 + ... = 154.8$
    * State 2 SSE: $(236-234.8)^2 + ... = 154.8$
    * State 3 SSE: $(250-251.6)^2 + ... = 141.2$
    * State 4 SSE: $(265-268.6)^2 + ... = 209.2$
    $$SSE = 154.8 + 154.8 + 141.2 + 209.2 = \mathbf{660.0}$$

* **總平方和 (Total Sum of Squares, SST):**

   $$SST = SSTR + SSE = 3272.2 + 660.0 = 3932.2$$

#### 3. 計算自由度 (Degrees of Freedom) 與均方 (Mean Square)

* **$df_{Treatment} (Between)$** = $k - 1 = 4 - 1 = 3$
* **$df_{Error} (Within)$** = $N - k = 20 - 4 = 16$
* **$df_{Total}$** = $N - 1 = 19$

* **均方處理 (MSTR):** $SSTR / df_{Tr} = 3272.2 / 3 = 1090.73$

* **均方誤差 (MSE):** $SSE / df_{E} = 660.0 / 16 = 41.25$

#### 4. 計算 F 檢定統計量

$$F = \frac{MSTR}{MSE} = \frac{1090.73}{41.25} = \mathbf{26.44}$$

#### **ANOVA Table**

| Source of Variation | d.f. | Sum of Squares (SS) | Mean Squares (MS) | F Statistic |
| :--- | :---: | :---: | :---: | :---: |
| **Treatments (States)** | 3 | 3272.2 | 1090.73 | **26.44** |
| **Error** | 16 | 660.0 | 41.25 | |
| **Total** | 19 | 3932.2 | | |

---

### c. 假設檢定

**步驟 1：建立假設**
* $H_0: \mu_1 = \mu_2 = \mu_3 = \mu_4$ (四個州的平均木材價格相同)
* $H_1:$ 至少有一組平均值與其他不同

**步驟 2：決定顯著水準**
* $\alpha = 0.05$

**步驟 3：找出臨界值 (Critical Value)**
* 查 F 分配表：$F_{\alpha, df_1, df_2} = F_{0.05, 3, 16}$
* 臨界值 $\approx 3.24$

**步驟 4：進行決策**
* 我們計算出的 $F$ 值為 **26.44**。
* 因為 $F = 26.44 > 3.24$ (臨界值)，且 $P\text{-value} \approx 0.00000025 < 0.05$。
* **結論：拒絕虛無假設 ($H_0$)**。

**解釋：**
有足夠的證據顯示，這四個州的框架木材每 1000 板公尺的平均價格**存在顯著差異**。
