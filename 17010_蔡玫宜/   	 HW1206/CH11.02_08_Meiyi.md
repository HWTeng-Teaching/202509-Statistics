## 題目翻譯

# 題目 8：降低敵意 (Reducing Hostility)

一位心理學家想要比較三種降低大學生敵意程度的方法。根據某項心理測驗 (HLT)，有 11 名學生被判定具有「高度敵意」。這些學生被隨機分成三組——其中 5 名接受「方法 A」治療，3 名接受「方法 B」治療，另外 3 名接受「方法 C」治療。

所有治療持續整個學期，結束後再次進行 HLT 測驗。結果顯示在表格中。

| 方法 (Method) | HLT 測驗分數 (Scores) |
| :---: | :--- |
| **A** | 73, 83, 76, 68, 80 |
| **B** | 54, 74, 71 |
| **C** | 79, 95, 87 |

**問題：**
1. **a.** 對此實驗進行變異數分析 (ANOVA)。
2. **b.** 數據是否提供足夠的證據顯示三種方法的治療後平均學生成績存在差異？

---

## 解題過程 (Solution)

### 1. 建立假設 (Hypothesis)

* **虛無假設 ($H_0$):** $\mu_A = \mu_B = \mu_C$ (三種方法的平均分數沒有差異)
* **對立假設 ($H_1$):** 至少有一組平均分數與其他組不同。

### 2. 數據整理與計算 (Calculations)

首先計算各組的總和 ($T$)、平均值 ($\bar{x}$) 與樣本數 ($n$)。

* **Group A:** $73, 83, 76, 68, 80$
    * $n_1 = 5$
    * $T_1 = (73+83+76+68+80) = 380$
    * $\bar{x}_1 = (380/ 5) =76$
    * $\sum X_1^2 = 73^2 + 83^2 +76^2 +68^2 + 80^2 = 29,018$

* **Group B:** $54, 74, 71$
    * $n_2 = 3$
    * $T_2 = (54+74+71) = 199$
    * $\bar{x}_2 = ( 199/ 3) = 66.33$
    * $\sum X_2^2 = 54^2 + 74^2 + 71^2 = 13,433$

* **Group C:** $79, 95, 87$
    * $n_3 = 3$
    * $T_3 = (79+95+87) =261$
    * $\bar{x}_3 = (261 / 3) = 87$
    * $\sum X_3^2 = 79^2 + 95^2 + 87^2 = 22,835$

**整體統計量 (Grand Statistics):**
* 總樣本數 ($N$) = $5 + 3 + 3 = 11$
* 總和 ($G$) = $380 + 199 + 261 = 840$
* 總平方和 ($\sum X^2_{total}$) = $29,018 + 13,433 + 22,835 = 65,286$
* 校正因子 ($CF$) = $\frac{G^2}{N} = \frac{840^2}{11} = 64,145.45$

### 3. 計算平方和 (Sum of Squares, SS)

* **總平方和 (SST, Total):**
  
    $$SST = \sum X^2_{total} - CF = 65,286 - 64,145.45 = 1,140.55$$

* **組間平方和 (SSTR, Treatment/Between):**

  $$SSTR = \sum \frac{T_i^2}{n_i} - CF$$
  
    $$SSTR = (\frac{380^2}{5} + \frac{199^2}{3} + \frac{261^2}{3}) - 64,145.45$$
  
    $$SSTR = (28,880 + 13,200.33 + 22,707) - 64,145.45$$
  
    $$SSTR = 64,787.33 - 64,145.45 = 641.88$$

* **組內/誤差平方和 (SSE, Error/Within):**
    $$SSE = SST - SSTR = 1,140.55 - 641.88 = 498.67$$

### 4. 變異數分析表 (ANOVA Table)

| 變異來源 (Source) | 自由度 (df) | 平方和 (SS) | 均方 (MS) | F 值 (F) |
| :--- | :---: | :---: | :---: | :---: |
| **處理 (Treatment)** | $k-1 = 2$ | $641.88$ | $320.94$ | **5.15** |
| **誤差 (Error)** | $N-k = 8$ | $498.67$ | $62.33$ | |
| **總和 (Total)** | $N-1 = 10$ | $1,140.55$ | | |

*註：$k$ 為組數 (3)。*

* $MSTr = 641.88 / 2 = 320.94$
* $MSE = 498.67 / 8 = 62.33$
* $F = MSTr / MSE = 320.94 / 62.33 = 5.15$

### 5. 結論 (Conclusion)

**問題 b 解答：**

我們需要比較計算出的 F 值與臨界 F 值 (Critical F-value)。
假設顯著水準 $\alpha = 0.05$。

* **自由度：** $df_1 = 2$, $df_2 = 8$
* **查表 (F-Distribution Table)：** $F(0.05, 2, 8) = 4.46$

**判定：**
因為計算出的 $F = 5.15$ 大於臨界值 $4.46$。

$$5.15 > 4.46 \Rightarrow \text{Reject } H_0$$

**結果：**
我們**拒絕虛無假設**。
這意味著有足夠的證據顯示，這三種方法在降低學生敵意程度的平均分數上，**存在顯著差異**。
