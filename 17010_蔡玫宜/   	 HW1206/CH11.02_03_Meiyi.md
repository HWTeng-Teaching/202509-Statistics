利用練習 1-4 提供的資訊，為這些單因子分類資料建立一個 ANOVA 表。針對 $H_0: \mu_1 = \mu_2 = \dots = \mu_k$ 進行正式檢定，包含 $\alpha = .05$ 的拒絕域。界定檢定的 p 值範圍並說明您的結論。

處理 1 (Treatment 1): 3, 2, 4, 3, 2

處理 2 (Treatment 2): 4, 3, 5, 2, 5

處理 3 (Treatment 3): 2, 0, 2, 1

# 第 3 題 ANOVA 解題步驟

## 1. 建立假設 (Hypotheses)
* **虛無假設 ($H_0$):** $\mu_1 = \mu_2 = \mu_3$ (所有處理組的平均數皆相等)
* **對立假設 ($H_a$):** 至少有兩組平均數不相等

## 2. 數據整理與計算
首先計算各組的總和 ($T_i$)、樣本數 ($n_i$) 與總平均。

* **Treatment 1:** $3, 2, 4, 3, 2$
    * $n_1 = 5$
    * $T_1 = (3+2+4+3+2) = 14$
    * $\bar{x}_1 = (14/5 )=2.8$
    * $\sum x^2 = 9+4+16+9+4 = 42$

* **Treatment 2:** $4, 3, 5, 2, 5$
    * $n_2 = 5$
    * $T_2 =(4+3+5+2+5)= 19$
    * $\bar{x}_2 =(19/5)= 3.8$
    * $\sum x^2 = 16+9+25+4+25 = 79$

* **Treatment 3:** $2, 0, 2, 1$
    * $n_3 = 4$
    * $T_3 =(2+0+2+1)= 5$
    * $\bar{x}_3 = 5/4 = 1.25$
    * $\sum x^2 = 4+0+4+1 = 9$

**總和統計量：**
* 總樣本數 ($N$) = $5 + 5 + 4 = 14$
* 總和 ($G$) = $14 + 19 + 5 = 38$
* 原始數據平方和 ($\sum y^2$) = $42 + 79 + 9 = 130$

## 3. 計算平方和 (Sum of Squares)

**A. 修正因子 (Correction Factor, CF):**
$$CF = \frac{G^2}{N} = \frac{38^2}{14} = \frac{1444}{14} \approx 103.143$$

**B. 總平方和 (Total SS, SSTotal):**
$$SS_{Total} = \sum y^2 - CF = 130 - 103.143 = 26.857$$

**C. 處理平方和 (Treatment SS, SST):**
$$SST = \sum \frac{T_i^2}{n_i} - CF$$
$$SST = (\frac{14^2}{5} + \frac{19^2}{5} + \frac{5^2}{4}) - 103.143$$
$$SST = (39.2 + 72.2 + 6.25) - 103.143$$
$$SST = 117.65 - 103.143 = 14.507$$

**D. 誤差平方和 (Error SS, SSE):**
$$SSE = SS_{Total} - SST = 26.857 - 14.507 = 12.350$$

## 4. 建立 ANOVA 表

| 變異來源 (Source) | 自由度 (df) | 平方和 (SS) | 均方 (MS) | F 值 |
| :--- | :---: | :---: | :---: | :---: |
| **處理 (Treatments)** | $k-1 = 2$ | 14.507 | $14.507 / 2 = 7.254$ | **6.46** |
| **誤差 (Error)** | $N-k = 11$ | 12.350 | $12.350 / 11 = 1.123$ | |
| **總和 (Total)** | $N-1 = 13$ | 26.857 | | |

* $F_{statistic} = \frac{MST}{MSE} = \frac{7.254}{1.123} \approx 6.46$

## 5. 檢定結論

* **拒絕域 (Rejection Region):**
    在 $\alpha = 0.05$ 下，自由度為 $(df_1=2, df_2=11)$。
    查 F 分配表，臨界值 $F_{0.05, 2, 11} \approx 3.98$。
    拒絕域為：$F > 3.98$。

* **P 值範圍 (Bound the p-value):**
    根據 F 分配表 (自由度 2, 11)：
    * $F_{0.05} = 3.98$
    * $F_{0.01} = 7.21$
    
    我們的計算值 $F = 6.46$ 介於 3.98 與 7.21 之間。
    因此，**$0.01 < \text{p-value} < 0.05$**。

* **結論 (Conclusion):**
    因為 $F = 6.46 > 3.98$ (且 p 值小於 0.05)，我們**拒絕虛無假設 ($H_0$)**。
    
    **統計證據顯示，這三種處理 (Treatment) 的平均數之間存在顯著差異。**
