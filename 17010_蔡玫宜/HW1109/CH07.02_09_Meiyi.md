## 翻譯
一個母體由 

N=4 個數值組成：10,15,21,22，其母體平均數為 𝜇 = 17

從此母體中隨機抽取樣本大小 

n=2，有兩種抽樣方式：

不放回抽樣；

有放回抽樣。

利用以上資訊回答第 7～9 題。

9. 分別求出第 7 題與第 8 題中各個 $\bar{x}$ 抽樣分配的平均數  𝐸(𝑥ˉ)。

它們與母體平均數 μ=17 相比如何？

--------

## 題目 9 解答

母體：\(\{10, 15, 21, 22\}\)，母體平均數 \(\mu = 17\)。  
樣本大小：\(n = 2\)。

---

### (一) 不放回抽樣時 $\bar{x}$ 的平均數

不放回抽樣，所有 **不重複的樣本組合** (大小 2) 為：

(10, 15) → x̄ = (10 + 15) / 2 = 12.5

(10, 21) → x̄ = (10 + 21) / 2 = 15.5

(10, 22) → x̄ = (10 + 22) / 2 = 16

(15, 21) → x̄ = (15 + 21) / 2 = 18

(15, 22) → x̄ = (15 + 22) / 2 = 18.5

(21, 22) → x̄ = (21 + 22) / 2 = 21.5

共有 6 種樣本，每一種機率皆為 \(1/6\)，  
因此 $\bar{x}$的平均數為：

$E(\bar{x})
= \frac{1}{6}(12.5+15.5+16+18+18.5+21.5)
= \frac{102}{6}
= 17.$

---

### (二) 有放回抽樣時 $\bar{x}$ 的平均數

有放回抽樣時，兩次抽樣獨立且同分配，  
設第一次抽得 \(X_1\)，第二次抽得 \(X_2\)，則樣本平均為：

$\bar{x} = \frac{X_1 + X_2}{2}.$

已知每次抽樣都來自同一母體，其期望值為：

$E(X_1) = E(X_2) = \mu = 17.$

利用期望值的線性性質：

E(x̄)
= E[ (X₁ + X₂) / 2 ]
= (1/2) × [ E(X₁) + E(X₂) ]
= (1/2) × (17 + 17)
= 17

所以，有放回抽樣時 $\bar{x}\$ 平均數也是 \(17\)。

---

### (三) 與母體平均數的比較

- 不放回抽樣：E($\bar{x})$= 17
- 有放回抽樣：E($\bar{x})$ = 17
- 母體平均數： μ = 17

因此，在這兩種抽樣方式下，樣本平均數 $\bar{x}$ 的期望值都 **等於母體平均數 μ **，  
也就是說， $\bar{x}$ 是母體平均數 $\mu\$ 的**不偏估計量 (unbiased estimator)**。
