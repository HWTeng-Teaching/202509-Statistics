# Exercise 8 — Sampling With Replacement  

Population = {10, 15, 21, 22}, sample size n = 2

## 1. Number of Possible Samples

Because sampling is **with replacement**, each draw has 4 possible values.

Total samples = 4 × 4 = **16**

## 2. List of All Possible Samples (Ordered Pairs)
(10,10), (10,15), (10,21), (10,22)  
(15,10), (15,15), (15,21), (15,22)  
(21,10), (21,15), (21,21), (21,22)  
(22,10), (22,15), (22,21), (22,22)

## 3. Sampling Distribution of the Sample Mean 𝑥̄

Compute each sample mean:

| Sample (x₁, x₂) |  x̄  |
|-----------------|------|
| (10,10) | 10 |
| (10,15) | 12.5 |
| (10,21) | 15.5 |
| (10,22) | 16 |
| (15,10) | 12.5 |
| (15,15) | 15 |
| (15,21) | 18 |
| (15,22) | 18.5 |
| (21,10) | 15.5 |
| (21,15) | 18 |
| (21,21) | 21 |
| (21,22) | 21.5 |
| (22,10) | 16 |
| (22,15) | 18.5 |
| (22,21) | 21.5 |
| (22,22) | 22 |

## 4. Probability Distribution Table of 𝑥̄

Since all 16 samples are equally likely:

$P(\bar{x}) = \frac{\text{frequency}}{16}$

|  x̄  | Frequency | Probability |
