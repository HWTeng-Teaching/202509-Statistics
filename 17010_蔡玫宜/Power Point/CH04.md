## 4.1 Events and Sample Space (事件與樣本空間)

### 基本概念
- **Experiment (實驗)**：一次觀察或測量的過程  
  例：擲骰子、紀錄年齡、詢問意見
- **Simple Event (基本事件)**：單次實驗的結果  
  例：擲骰子 → {E1=1, E2=2, …, E6=6}
- **Sample Space (樣本空間)**：所有可能結果的集合  
  S = {E1, E2, E3, E4, E5, E6}
- **Empty Set (空集合)**：無事件發生，記為 ϕ
- **Event (事件)**：一個或多個基本事件的集合

  A：出現奇數 → {1,3,5}  
  B：大於2 → {3,4,5,6}
- **Mutually Exclusive (互斥事件)**：兩事件不能同時發生  
  A ∩ B = ϕ

## 4.2 Calculating Probabilities Using Simple Events
以基本事件計算機率

### 概念與定義
- 機率定義：

P(E) = f / n

或

P(E) = lim (n→∞) f / n

- 機率公理：
1. 0 ≤ P(E) ≤ 1  
2. 所有基本事件機率總和 = 1  
3. P(A) = Σ P(Ei)
- 若事件等可能：

P(A) = nA / N


### 範例
- 擲兩次公平硬幣：S = {HH, HT, TH, TT}  
P(至少一正面) = 3/4  
- 抽兩顆 M&M（紅、藍、綠）：P(至少一紅) = 2/3

## 4.3 Useful Counting Rules (計數法則)

1. **m×n Rule**  
 兩階段實驗：總可能結果 = m × n

2. **Permutations (排列)**  

P(n, r) = n! / (n - r)!

順序重要  
例：{1,2,3,4} 選3個 → 24種

3. **Combinations (組合)**  

C(n, r) = n! / [(n - r)! r!]

順序不重要  
例：5人選3人 → 10種  
例：6顆糖果（4紅2綠），P(1紅) = 8/15

## 4.4 Rules for Calculating Probabilities (機率運算法則)

1. **Additive Rule (加法法則)**  

P(A ∪ B) = P(A) + P(B) - P(A ∩ B)

若互斥：P(A ∩ B) = 0

2. **Multiplicative Rule (乘法法則)**  

P(A ∩ B) = P(A) P(B|A)

若獨立：P(A ∩ B) = P(A) P(B)

3. **Conditional Probabilit若 P(A|B) = P(A) → A、B 獨立  
否則相依

P(A|B) = P(A ∩ B) / P(B)

若 P(A|B) = P(A) → A、B 獨立  

否則相依

4. **Complement Rule (補集法則)**  

P(A^C) = 1 - P(A)  


### 範例
49% 為女性，其中 8% 為高風險：  
P(高風險女性) = 0.49 × 0.08 = 0.0392

## 4.5 Bayes’ Rule (貝氏定理)

1. **Law of Total Probability (全機率定理)**  

P(A) = Σ P(Si) P(A | Si)

2. **Bayes’ Rule (貝氏定理)**

P(Si | A) = [P(Si) P(A | Si)] / Σ P(Sj) P(A | Sj)

### 範例

已知：

- P(F) = 0.49, P(M) = 0.51
  
- P(H|F) = 0.08, P(H|M) = 0.12
  
求 P(M|H)：

P(M|H) = [0.51 × 0.12] / [0.49 × 0.08 + 0.51 × 0.12] = 0.61
