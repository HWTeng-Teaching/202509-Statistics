# 📘 第五章：常用的離散機率分配（Several Useful Discrete Distributions）

## 5.1 離散型隨機變數與機率分配

### 🔹 重要觀念
- **隨機變數 (Random Variable, RV)**：其數值由實驗結果決定。  
- **離散型隨機變數 (Discrete RV)**：只能取有限或可數無限多個值。  
- **機率分配 (Probability Distribution)**：列出每個可能的 x 值及對應的機率 p(x)。

### 🧮 機率分配性質

$\sum p(x) = 1, \quad 0 \leq p(x) \leq 1$

### 🧠 平均值與變異數

$\mu = E[X] = \sum x p(x)$

$\sigma^2 = E(X - \mu)^2 = \sum (x - \mu)^2 p(x)$

$\sigma = \sqrt{\sigma^2}$

### 🪙 範例：擲三次公平硬幣  
\( x = \) 出現正面的次數  

| x | p(x) |
|:-:|:-:|
| 0 | 1/8 |
| 1 | 3/8 |
| 2 | 3/8 |
| 3 | 1/8 |

$\mu = 1.5,\quad \sigma = 0.688$

## 5.2 二項分配（Binomial Distribution）

### 🔹 定義
二項試驗需滿足以下條件：
1. 有 \( n \) 次相同且獨立的試驗。  
2. 每次結果為「成功 (S)」或「失敗 (F)」。  
3. 成功機率 \( p \) 於每次試驗中固定。  
4. 失敗機率 \( q = 1 - p \)。  
5. \( X \)：代表成功次數。  

$X \sim Binomial(n, p)$

### 🔹 機率公式

$P(X = k) = \binom{n}{k} p^k (1 - p)^{n - k}$

### 🔹 平均與標準差

$\mu = np, \quad \sigma^2 = np(1 - p), \quad \sigma = \sqrt{np(1 - p)}$

### 🧮 範例：射擊命中率
射手命中率 0.8，射擊 5 次：  

$P(X = 3) = \binom{5}{3}(0.8)^3(0.2)^2 = 0.2048$

$P(X > 3) = 1 - P(X \le 3) = 0.737$

## 5.3 普瓦松分配（Poisson Distribution）

### 🔹 定義
用於描述在固定時間或空間內**事件發生的次數**，且事件為稀有、獨立發生。  

$P(X = k) = \frac{e^{-\mu}\mu^k}{k!}, \quad k = 0, 1, 2, \dots$

### 🔹 平均與變異數

$E[X] = \mu, \quad Var[X] = \mu, \quad \sigma = \sqrt{\mu}$

### 🧮 範例：交通事故
平均每週 2 起交通事故：  

$P(X = 1) = e^{-2}\frac{2^1}{1!} = 0.2707$

$P(X \ge 8) = 1 - P(X \le 7) = 0.001$

---

## 5.4 超幾何分配（Hypergeometric Distribution）

### 🔹 定義
從有限母體中**不放回抽樣**，計算樣本中成功次數的機率。  

$P(X = k) = \frac{\binom{M}{k}\binom{N - M}{n - k}}{\binom{N}{n}}$

參數說明：
- \( N \)：母體大小  
- \( M \)：母體中成功的個數  
- \( n \)：抽樣大小  
- \( k \)：樣本中成功個數  

### 🔹 平均與變異數

$\mu = n \frac{M}{N}$

$\sigma^2 = n\frac{M}{N}\left(1 - \frac{M}{N}\right)\frac{N - n}{N - 1}$

### 🧮 範例：電池良率
共 8 顆電池，其中 2 顆不良，隨機選 4 顆：  

$P(\text{4 顆皆良品}) = \frac{\binom{6}{4}\binom{2}{0}}{\binom{8}{4}} = \frac{15}{70} = 0.214$

$\mu = 3,\quad \sigma^2 = 0.4286$

## 🧩 三種離散分配比較

| 分配名稱 | 機率公式 | 平均 (μ) | 變異數 (σ²) | 適用情境 |
|:-----------|:-----------|:-----------|:-----------|:-----------|
| **二項分配 (Binomial)** | $\ P(X=k)=\binom{n}{k}p^k(1-p)^{n-k} $ | \( np \) | np(1-p) | 有放回抽樣或獨立試驗 |
| **普瓦松分配 (Poisson)** | $\( P(X=k)=\frac{e^{-\mu}\mu^k}{k!} $) | $\mu\$ | \( $\mu\$ ) | 稀有事件、時間/空間發生次數 |
| **超幾何分配 (Hypergeometric)** | $P(X=k)=\frac{\binom{M}{k}\binom{N-M}{n-k}}{\binom{N}{n}}$ | $(n\frac{M}{N}$) | $( n\frac{M}{N}\left(1-\frac{M}{N}\right)\frac{N-n}{N-1}$) | 不放回抽樣（有限母體） |

---

## 🏁 重點總結
- **離散型隨機變數** 用於描述可數的結果。  
- 三大離散分配：  
  - **二項分配**：獨立、固定次數的成功次數。  
  - **普瓦松分配**：單位時間/空間內稀有事件的次數。  
  - **超幾何分配**：有限母體中不放回抽樣的成功次數。  
- 平均與變異數可分別表示中心趨勢與離散程度。
