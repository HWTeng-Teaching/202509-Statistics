# Chapter 9：Large-Sample Tests of Hypotheses

#️⃣ 考試作答最重要的思路（直接背這段即可）

看到考題 → 馬上判斷要用什麼檢定？請照以下判斷流程。

🔍 Step 1 — 看題目是哪一類型

| 類型               | 題目關鍵字                               | 應用公式                                          |
| ---------------- | ----------------------------------- | --------------------------------------------- |
| **一母體平均數 $\mu$** | average, mean, yield, price, weight | $Z = \frac{\bar X - \mu_0}{S / \sqrt{n}}$     |
| **一母體比例 $p$**    | proportion, %, rate, success, heads | $Z = \frac{\hat p - p_0}{\sqrt{p_0 q_0 / n}}$ |
| （本章跳過）兩母體平均數     | difference of means                 | —                                             |
| （本章跳過）兩母體比例      | difference of proportions           | —                                             |

🔍 Step 2 — 判斷 H₀ 與 Hₐ 方向（非常重要！）

| 題目表述     | 使用的假設                                                       |
| -------- | ----------------------------------------------------------- |
| “是否改變了？” | $H_0: \theta = \theta_0$ vs $H_a: \theta \neq \theta_0$（雙尾） |
| “是否變大？”  | $H_0: \theta = \theta_0$ vs $H_a: \theta > \theta_0$（右尾）    |
| “是否變小？”  | $H_0: \theta = \theta_0$ vs $H_a: \theta < \theta_0$（左尾）    |

🔍 Step 4 — 使用兩種方法擇一
(A) 臨界值法（critical value approach）

* 找到 $z_\alpha$ 或 $z_{\alpha/2}$

* 判斷 $Z^*$ 是否落在拒絕區（rejection region）

(B) p-value 方法（考試最常用）

* 求 p 值

* 若 $p < \alpha$ → 拒絕 $H_0$

🔍 Step 5 — 結論

* 拒絕 $H_0$：結果 具統計顯著

* 不拒絕 $H_0$：結果 不具統計顯著 / 證據不足
