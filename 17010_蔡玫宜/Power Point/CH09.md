# Chapter 9：Large-Sample Tests of Hypotheses

#️⃣ 考試作答最重要的思路（直接背這段即可）

看到考題 → 馬上判斷要用什麼檢定？請照以下判斷流程。

🔍 Step 1 — 看題目是哪一類型

| 類型               | 題目關鍵字                               | 應用公式                                          |
| ---------------- | ----------------------------------- | --------------------------------------------- |
| **一母體平均數 $\mu$** | average, mean, yield, price, weight | $Z = \frac{\bar X - \mu_0}{S / \sqrt{n}}$     |
| **一母體比例 $p$**    | proportion, %, rate, success, heads | $Z = \frac{\hat p - p_0}{\sqrt{p_0 q_0 / n}}$ |
| （本章跳過）兩母體平均數     | difference of means                 | —                                             |
| （本章跳過）兩母體比例      | difference of proportions           | —                                             |

🔍 Step 2 — 判斷 H₀ 與 Hₐ 方向（非常重要！）

| 題目表述     | 使用的假設                                                       |
| -------- | ----------------------------------------------------------- |
| “是否改變了？” | $H_0: \theta = \theta_0$ vs $H_a: \theta \neq \theta_0$（雙尾） |
| “是否變大？”  | $H_0: \theta = \theta_0$ vs $H_a: \theta > \theta_0$（右尾）    |
| “是否變小？”  | $H_0: \theta = \theta_0$ vs $H_a: \theta < \theta_0$（左尾）    |

🔍 Step 4 — 使用兩種方法擇一

(A) 臨界值法（critical value approach）

* 找到 $z_\alpha$ 或 $z_{\alpha/2}$

* 判斷 $Z^*$ 是否落在拒絕區（rejection region）

(B) p-value 方法（考試最常用）

* 求 p 值

* 若 $p < \alpha$ → 拒絕 $H_0$

🔍 Step 5 — 結論

* 拒絕 $H_0$：結果 具統計顯著

* 不拒絕 $H_0$：結果 不具統計顯著 / 證據不足

## 2. Hypothesis Testing（假設檢定）

### 🔹 重要要素（Key Ingredients）
1. **模型設定（Model specification）**：找到適合你情境的分配 ℱ(θ)  
2. **估計量（Estimator）**  
3. **標準化得到統計量（Statistic）並找出抽樣分配**  
4. 兩大統計方法  
   - 信賴區間（Ch.8）
   - 假設檢定（Ch.9+）

---

## 3. Null & Alternative Hypothesis

### Null Hypothesis（虛無假設）  
- 記作：H₀  
- 通常是與 Ha 相反的立場  
- 例：H₀: θ = θ₀

### Alternative Hypothesis（對立假設）  
- 記作：Hₐ 或 H₁  
- 例：H₁: θ ≠ θ₀（雙尾）

---

## 4. 檢定的兩個動作
1. **Reject H₀（拒絕 H₀）**
2. **Do not reject H₀（不拒絕 H₀）**

---

## 5. Type I & Type II Errors（第一類與第二類錯誤）

| 判斷 | H₀ 為真 | H₀ 為假 |
|------|---------|---------|
| Reject H₀ | Type I error | 正確決策 |
| Do not reject H₀ | 正確決策 | Type II error |

- **Type I error**：拒絕一個其實為真的 H₀  
  - 機率 = α  
- **Type II error**：未拒絕一個其實為假的 H₀  
  - 機率 = β  
- **Power**：1 – β（拒絕錯誤 H₀ 的機率）

---

## 6. 假設檢定 SOP（流程）
1. 設定 H₀ 與 Hₐ  
2. 選擇顯著水準 α  
3. 找出檢定統計量與其抽樣分配  
4. 計算實際統計量  
5. 找出：
   - (a) **拒絕域（Rejection region）** 或  
   - (b) **p-value**  
6. 結論  

---

## 7. 檢定方法

### (A) Rejection Region Approach（臨界值法）
- 若 test statistic 落入 RR → 拒絕 H₀  
- 否則不拒絕

### (B) p-value Approach
- p-value = 假設 H₀ 真時，觀察到「此統計量或更極端」的機率  
- 若 p < α → 拒絕 H₀  
- 若 p ≥ α → 不拒絕 H₀  

---

## 8. Sliding Scale（研究常用判斷）
- p < .01 → 高度顯著  
- .01 < p < .05 → 顯著  
- .05 < p < .10 → 接近顯著  
- p > .10 → 不顯著  

---

## 9. One Population Mean（母體平均數檢定）

### 三種形式
1. **Right-sided test：右尾**
   - H₀: μ = μ₀ vs Hₐ: μ > μ₀  
2. **Left-sided test：左尾**
   - H₀: μ = μ₀ vs Hₐ: μ < μ₀  
3. **Two-sided test：雙尾**
   - H₀: μ = μ₀ vs Hₐ: μ ≠ μ₀  

---

## 10. Key Ingredients for mean test

### CLT 與統計量
- 因為 n 大，可使用：
$Z = \frac{\bar{X} - \mu_0}{S / \sqrt{n}} \sim N(0,1)$

---

## 11. Example（母體平均數例題）

### 題目  
化工廠多年平均產量 μ = 880 噸。  
抽樣 50 天 → x̄ = 871, s = 21  
檢定平均是否改變（雙尾），α = .01  

### Test statistic  
$Z = \frac{871 - 880}{21/\sqrt{50}} = -3.03$

### RR Approach  
- RR = { z < -2.575 or z > 2.575 }  
- -3.03 落入 RR → **拒絕 H₀**

### p-value Approach  
\[
p = 2P(Z < -3.03) = 0.0024 < 0.01
\]
→ **拒絕 H₀，平均已改變**

---

## 12. Example（房價）

### 題目  
64 戶房屋樣本，x̄ = 252,000, s = 15,000  
檢定平均房價是否 > 250,000，α = .01

### 統計量  
$Z = \frac{252000-250000}{15000/\sqrt{64}} = 1.07$

### RR  
RR = { z > 2.33 }  
1.07 不落入 RR → **不拒絕 H₀**

### 結論  
證據不足以支持平均房價 > 250,000

---

## 13. One Population Proportion（母體比例）

### 統計量  
$z = \frac{\hat{p} - p_0}{\sqrt{p_0 q_0 / n}}$

---

## 14. Example — 健身活動比例
- 全美成年人固定運動比例：20%  
- 40 歲以上樣本 100 人 → 15 人運動  
- 檢定是否 **下降**（左尾，p < .2），α = .05

### Test statistic  
$z = \frac{0.15-0.2}{\sqrt{0.2\cdot0.8/100}} = -1.25$

### RR  
RR = { z < -1.645 }  
-1.25 不落入 RR → **不拒絕 H₀**

結論：證據不足支持 40 歲後比例下降。

---

## 15. Example — 擲硬幣 100 次出現 10 次正面  
- H₀: p = 0.5  
- H₁: p ≠ 0.5  
- p-value = 3.06 × 10⁻¹⁷  
→ **拒絕 H₀**  
→ p 很可能不等於 0.5
