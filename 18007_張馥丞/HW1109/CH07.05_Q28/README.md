28.O 若從 NHL 球員中隨機抽取一個樣本，樣本大小為 n = 50，請問樣本中出生在美國Canada! 國家冰球聯盟（NHL）約有 70% 的球員出生在美國以外地區。

以外的球員比例超過 80% 的機率是多少？

關於「樣本比例的抽樣分配」與「常態近似」的機率計算

1.定義參數

   母體比例：p=0.70
   
   樣本大小：n=50
   
   樣本比例：p^
   
   要算的機率：P(p^>0.80)

2.樣本比例的標準差（標準誤）

3.樣本比例轉換為 Z 分數

Z=(0.80−0.70)/0.0648 ≈1.543


4.查標準常態分配表

查 Z=1.54 的右尾機率：P(Z>1.54) ≈ 1 − 0.9382 = 0.0618

在樣本大小為 50 的情況下，樣本中出生在美國以外的球員比例超過 80% 的機率約為 0.0618，也就是 6.18%。
