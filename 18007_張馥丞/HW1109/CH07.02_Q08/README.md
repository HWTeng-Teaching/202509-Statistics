用母體 {10,15,21,22} (N=4)、樣本數 n=2 做「有放回抽樣」的完整列舉與計算。重點結果如下：

有放回、且順序有別的所有可能樣本數： 4^2 = 16 個（有序樣本）。

每一個有序樣本發生機率相等： 1/16=0.0625。
