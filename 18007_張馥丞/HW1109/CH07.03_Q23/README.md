某型汽車電池的壽命平均為 1110 天，標準差為 80 天。

若隨機抽取 400 個電池，求下列有關「樣本平均壽命」的機率：


a.樣本平均介於 1100 與 1110 之間。

b.樣本平均 大於 1120。

c.樣本平均 小於 900。

已知資訊

母體平均：μ=1110

母體標準差：σ=80

樣本大小：n=400

樣本平均的標準誤 (Standard Error, SE)

<img width="86" height="61" alt="image" src="https://github.com/user-attachments/assets/f52fa55c-5a88-4de2-8dfb-57e76df19bb8" />


SE=80/20=4

樣本平均 X bar 的抽樣分配為近似常態：X bar ∼N(1110,4)


(a) 1100 ≤ X bar ≤ 1110

轉成 Z：

左端：Z=(1100-1110)/4=-2.5

右端：Z=(1110-1110)/4=0

所以要求：P(−2.5≤Z≤0)

查標準常態表：P(Z<0)=0.5000

              P(Z<−2.5) ≈ 0.0062
              
因此：P=0.5000−0.0062=0.4938

答案：0.4938（約 49.4%）


(b) X bar >1120

Z=(1120-1110)/4=2.5

P(Z>2.5)=1−P(Z<2.5)

P(Z<2.5)=0.9938


P=1−0.9938=0.0062
答案：0.0062（約 0.62%）

(c) X bar <900

Z=(900-1110)/4=-210/4=-52.5

這是一個極端的 Z 值。

(Z<−52.5) ≈ 0

答案：0（機率幾乎為零）
