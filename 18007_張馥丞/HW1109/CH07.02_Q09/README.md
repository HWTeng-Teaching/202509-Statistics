E(x bar)=(12.5+15.5+16+18+18.5+21.5)/6=17

無放回時： E(x bar)=17

第 8 題（有放回）之 x bar 的抽樣平均

有放回時共有 16 種有序樣本，每個機率 = 1/16

在有放回抽樣時，樣本平均的期望值永遠等於母體平均數 μ

每一個樣本平均為x bar=(x1 + x2)/2

因為兩次抽取獨立，且 E(x1)=E(x2)=μ=17，所以：

E(x bar)=(E(x1)+E(x2))/2=(17+17)/2=17

有放回時：E(x bar)=17
