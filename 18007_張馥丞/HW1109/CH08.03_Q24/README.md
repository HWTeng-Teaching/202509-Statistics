題目背景： 一位小兒科醫師從她的資料庫中隨機選取了 50 位六個月大的男嬰，記錄了以下資料：

平均體重：8.0 公斤，標準差：0.30 公斤

平均身長：67.3 公分，標準差：0.64 公分

樣本數：n=50

a.計算 95% 信賴區間（體重）

公式：<img width="109" height="53" alt="image" src="https://github.com/user-attachments/assets/7e993fb2-2b08-4af3-83fd-266c8618f47b" />

其中 Z=1.96（對應 95% 信心水準）

代入數值：CI=8.0±1.96⋅0.30/√50=8.0±1.96⋅0.0424 ≈ 8.0 ± 0.083

結果：{95% 信賴區間為 } (7.917, 8.083)

b. 計算 99% 信賴區間（身長）

公式：<img width="109" height="53" alt="image" src="https://github.com/user-attachments/assets/e3142d3d-79b1-44dd-bd5e-8c5a9bbbf801" />

其中 Z=2.576Z = 2.576（對應 99% 信心水準）

代入數值：CI=67.3 ± 2.576⋅0.64/√50=67.3 ± 2.576⋅0.0905 ≈ 67.3 ± 0.233

結果：{99% 信賴區間為 } (67.067, 67.533)

c. 推論條件說明

若要將這些結果推論至「所有六個月大的男嬰」，我們必須假設：

醫師的資料庫是代表性樣本，即這 50 位男嬰是從整體族群中隨機抽樣的。

沒有系統性偏誤，例如只抽取特定地區、特定健康狀況或特定族群的嬰兒。
