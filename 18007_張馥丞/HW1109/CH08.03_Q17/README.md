信賴區間 Confidence Interval for p

根據一次二項實驗的隨機樣本，共進行了500次試驗，其中有27次成功。

請建立對二項比例 p 的 95% 信賴區間，並解釋你所建構的區間。

計算步驟：

這是典型的二項比例信賴區間問題。使用正態近似法（當樣本數夠大時適用）：

樣本成功率：p^=27/500=0.054

標準誤差（SE）：<img width="259" height="62" alt="image" src="https://github.com/user-attachments/assets/b2b7852a-7433-4feb-9131-cc5c17c295bc" />

使用 95% 信賴區間的 Z 值（約 1.96）：CI=p^±Z⋅SE=0.054±1.96⋅0.0101

結果：CI ≈ (0.034, 0.074)

解釋： 我們有 95% 的信心認為真實的成功比例 p 落在 0.034 到 0.074 之間。
