15.從一個母體中抽取樣本，其樣本大小為 n=49，母體平均數為 μ=53

母體標準差為 σ=21。描述樣本平均數的抽樣分配的大致形狀，並求其平均數與標準誤。


1.抽樣分配的形狀（Shape）

因為樣本大小n=49≥30, 根據中央極限定理（CLT），樣本平均數 x bar的抽樣分配會：近似呈常態分配（approximately normal）

無論母體本身是否常態，只要樣本量夠大（n ≥ 30），x bar 的抽樣分配就會接近常態。


2.抽樣平均

樣本平均數 x bar 的抽樣分配平均等於母體平均數：μx bar =μ=53
