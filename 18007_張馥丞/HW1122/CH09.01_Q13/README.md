Facebook 朋友數

據報導，Facebook 使用者的平均朋友數為 155。假設隨機抽取 50 位使用者，

調查得知樣本平均數為 x bar=149，樣本標準差為 s=29.7。使用此資訊回答問題 13–15。


13.若我們想質疑官方宣稱的平均數 155，應如何表達虛無假設 H0與對立假設 Ha？


要「質疑」155，表示我們認為真實平均可能不是 155，因此為雙尾檢定（two-tailed test）：雙尾檢定是一種假設檢定方法，用來判斷樣本平均數是否「顯著地不同於」某個特定值（母體平均數），不論是高於或低於該值。我們關心的是「有差異」，而不是「大於」或「小於」某個值。

虛無假設 H0： Facebook 使用者的平均朋友數為 155

對立假設 Ha： Facebook 使用者的平均朋友數不等於 155
