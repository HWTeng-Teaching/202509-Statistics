抗生素效力：製造商宣稱某抗生素的平均效力為 80%。隨機抽取 n=100粒膠囊，樣本平均 x bar =79.7%，樣本標準差 s=0.8。是否有足夠證據反駁製造商的宣稱？顯著水準 α=0.05

a.虛無假設 H0   H0 : μ=80%

b.對立假設 Ha   因為要「反駁宣稱」，採雙尾檢定：Ha : μ≠80%

c. 統計檢定與結論（逐步計算）

1.標準誤（standard error）：SE=0.8/√ 100 = 0.8/10 = 0.8

2.z 統計量：z = (x bar - μ0)/SE = (79.7-80)/0.08 = -0.3/0.08 = -3.75

雙尾顯著水準 α=0.05 的臨界值：zα/2​=±1.96

比較：−3.75<−1.96，因此落在拒絕域內 → 拒絕 H0

3.p 值（雙尾）：在雙尾 Z 檢定中，p 值公式為p=2⋅Φ(−∣z∣)

當 z=−3.75 時：p=2⋅Φ(−3.75)

尾部對稱性：利用公式 Φ(−z)=1−Φ(z)，可將左尾機率轉換為右尾：

Φ(−3.75)=1−Φ(3.75)

查表（標準常態分配表）：

從 Z 表可得：

Φ(3.7)≈0.99989

Φ(3.8)≈0.99993  於 z=3.75 時：Φ(3.75)≈0.9999116

因此：Φ(−3.75)≈1−0.9999116=8.84×10−5

單尾機率 P(Z<−3.75) ≈ 0.0000884173

p ≈ 2Φ(−3.75) ≈ 0.00018

因此雙尾 p 值約 2 × 0.0000884173 ≈ 0.0001768

p=2⋅Φ(−3.75)≈2⋅(8.84×10−5)=1.768×10−4≈0.00018

4.判斷：p-value ≈ 0.00018 ≪ α=0.05 因此 拒絕 H0

  在顯著水準 0.05 下，樣本提供非常強的證據反駁製造商宣稱的平均效力 80%。從樣本平均（79.7%）和 z 值（−3.75）來看，實際平均效力顯著低於 80%。
