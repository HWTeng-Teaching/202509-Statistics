9.新稅法 新的稅制被認為有助於小型企業的生存。目前已知有 20% 的小型企業在第一年內倒閉。現在針對 200 家新開的小型企業進行一年追蹤，結果有 30 家倒閉。


a. 如何表達虛無假設 H0 與對立假設 Ha？

若我們要檢定「新稅法有助於小型企業生存」的主張，應如何表達 H0 與 Ha？

H0：新稅法沒有幫助 → 倒閉率仍為 20% → p=0.20

Ha：新稅法有幫助 → 倒閉率下降 → p<0.20

這是一個左尾檢定（左側檢定）。


b. 根據樣本比例 p^，計算檢定統計量的值

樣本大小 n=200

倒閉數 x=30

樣本比例 p^=30/200=0.15

母體比例 p0=0.20

標準誤差 SE=√p0(1-p0)/n = √(0.2*0.8)/200 =√0.0008 ≈ 0.02828

檢定統計量（z 分數）：z = (p^-p0)/SE = (0.15-0.2)/0.02828 ≈ -1.767


c. 在顯著水準 α=0.05 下的拒絕域是什麼？能否得出新稅法有效的結論？

這是左尾檢定，臨界值為 z=−1.645

我們的檢定統計量 z=−1.767

因為 −1.767<−1.645，落在拒絕域內 → 拒絕 H0

結論：有統計證據支持新稅法有助於小型企業生存。


d. 計算 p 值。這會改變你在 c 部分的結論嗎？

z=−1.767

查標準常態分布表或使用計算機：p-value≈  P(Z<−1.767)  ≈  0.0387

p=0.0387<0.05  仍然拒絕 H0，結論不變。

結論：p 值支持我們在 c 部分的判斷，新稅法可能有效。
