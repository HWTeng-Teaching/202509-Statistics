USA Today 隨機抽樣 500 位女性，問她們考慮節食的原因，其中有 68% 選「改善我的健康 (Improve my health)」。問題：我們能否斷定超過 60% 的女性考慮節食是為了「改善健康」？

a)虛無與對立假設

要檢驗「是否超過 60%」，採單尾（右尾）檢定：

H0​: p=0.60

Ha​: p>0.60

b) 計算檢定統計量與 p 值，並找出以 α=0.01 的拒絕域

樣本比例：p^=0.68（500 人中 68%）

標準誤（使用 H0下的 p0=0.6）：

SE = √p0(1-p0)/n = √(0.6*0.4)/500 ≈ 0.021909

z 值：z = (p^-p0)/SE = (0.68-0.6)/0.021909 ≈ 3.65

單尾 p 值：P(Z>3.65) ≈ 0.00013

拒絕域（α=0.01，右尾）為 z > z0.01 ≈ 2.33

因為 z ≈ 3.65>2.33，且 p 值  ≈ 0.00013 ≪ 0.01 ，落在拒絕域內。

c) 結論

在顯著水準 α=0.01下，有非常強的統計證據拒絕 H0。

也就是說，可以合理地得出結論：超過 60% 的女性考慮節食是為了改善健康（結果在統計上高度顯著）。
