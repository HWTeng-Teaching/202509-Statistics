為使統計量 (x bar −μ)/(s/n) 服從 t 分配，需要滿足哪兩個假設？

這個統計量是用來進行 單一樣本平均數的推論，當母體標準差未知時，我們使用樣本標準差 s 來估計。要使這個統計量服從 t 分配，必須滿足以下兩個假設：

假設一：樣本來自常態分配的母體

如果母體是常態分配，則即使樣本數很小，t 分配仍然適用。

若母體不是常態分配，則樣本數必須夠大（通常 n ≥ 30）才能近似使用 t 分配。

假設二：樣本是隨機抽樣且獨立

每個樣本值必須是獨立的，且來自相同的母體。

若樣本間有依賴性（例如時間序列），則 t 分配不適用。
