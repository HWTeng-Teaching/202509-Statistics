一篇文章指出自尊是預測哪些人會從暴食症（bulimia）治療中受益的重要因子。

表格給出治療前（Pretreatment）、治療後（Posttreatment）與追蹤（Follow-up）

三個時點自尊分數的樣本平均、樣本標準差與樣本數：

Pretreatment：x bar =20.3,  s=5.0,  n=21

Posttreatment：x bar =26.6,  s=7.4,  n=21

Follow-up：x bar =27.7,  s=8.2,  n=20

(a)用假設檢定判斷是否有足夠證據可以斷定真實的 pretreatment 平均小於 25。

(b)建立 posttreatment 真實平均的 95% 信賴區間。

(c)在第 10.3 節會介紹兩母體平均差的小樣本方法；在沒有正式檢定下，你會如何就三個樣本平均的差異作出結論？


(a)假設檢定（Pretreatment）

零假設：H0:μ=25

對立假設（單尾，左尾）：Ha:μ<25

樣本數 n=21，自由度 df=20

樣本平均 x bar=20.3、樣本標準差 s=5.0

計算 t 統計量：

SE = 5/√ 21 = 5/4.5826 ≈ 1.0911

t = (x bar -25)/SE = (20.3-25)/1.0911 = -4.7/1.0911 ≈ -4.31

對於 df=20 而言，t ≈ − 4.31的左尾機率非常小（顯著性遠小於 0.01）。

結論：在常用顯著水準（例如 0.05 或 0.01）下，我們拒絕 H0，有充分證據支持 Pretreatment 的母體平均 小於 25。
（可簡潔表示：p-value < 0.001，所以顯著。）


(b) 95% 信賴區間（Posttreatment）

已知：x post=26.6,  s post=7.4,  n=21,  df=20

計算標準誤與 t 臨界值：SE post = 7.4/√ 21 ≈ 7.4/4.58267.4 ≈ 1.615

對於 df=20，雙尾 95% 臨界值 t0.975,20 ≈ 2.086

邊際誤差：ME = t 0.975,20 × SE post ≈ 2.086 × 1.615 ≈ 3.37 

因此 95% 信賴區間：26.6 ± 3.37 ⇒ (26.6−3.37,26.6+3.37) ≈ (23.23,29.97).

解釋：我們有 95% 信心真實的 Posttreatment 自尊分數平均落在約 23.23 到 29.97 之間。


(c) 非正式結論（比較三個平均）

從數值上看：

Pretreatment = 20.3（較低）

Posttreatment = 26.6（顯著增加）

Follow-up = 27.7（再略增加，且維持在比 Pretreatment 高的水準）

在沒有正式配對或成對樣本檢定前，這些平均值顯示治療後自尊有明顯提升，且在追蹤時仍維持或稍增。

要作出嚴謹結論應使用適當的小樣本方法（例如對同一組受試者的成對 t 檢定或重複測量 ANOVA），因為資料

可能是重複測量（同一組人在三個時點），此時應採用配對/重複測量的方法來控制個體間變異。若樣本為相互獨

立個體，則需用獨立樣本方法比較。
