15.求出 z > 1.43 或 z < −1.43 的機率。可得出什麼結論？

標準常態分布查表：P(Z>1.43)=0.0764; P(Z<−1.43)=0.0764

因為對稱：P(∣Z∣>1.43)=2×0.0764=0.1528; 答案：約 0.1528（15.28%）

結論：因為 p 值約 0.1528，大於常用顯著水準 0.05，因此 沒有足夠證據拒絕平均數為 155 的說法。

換句話說，樣本平均 149 與 155 的差距在統計上並不特別顯著。
