一個碗裡有五顆糖果──紅 (red)、棕 (brown)、黃 (yellow)、藍 (blue)、橘 (orange)。

隨機抽出兩顆糖果，一顆給自己吃，一顆給朋友。

問：「你拿到橘色糖果而你的朋友沒有拿到紅色糖果」的機率是多少？

步驟 1：列出樣本空間

碗中共有 5 顆不同的糖果：

R（紅）、Br（棕）、Y（黃）、B（藍）、O（橘）。

抽出兩顆，且順序有分（因為一顆是你拿，一顆是朋友拿）。

→ 總共有5×4=20個等可能的結果

例如：(R, Br): 你拿紅、朋友拿棕
      (O, Y): 你拿橘、朋友拿黃
      ⋯⋯等共 20 種。
      
步驟 2：找出符合條件的事件

條件是：你拿到橘色糖果 (O) 朋友 沒有 拿紅色糖果 (not R)

步驟 3：列出符合條件的可能組合

你拿橘色糖果 → 你的那一顆固定是 O。

朋友可從剩下的 4 顆中選，但不能拿紅色 (R)。

剩下可選的：Br、Y、B → 共 3 種。

符合條件的結果：(O, Br)、(O, Y)、(O, B)
→ 共 3 個符合條件的事件。

步驟 4：計算機率

樣本空間中共有 20 個等可能事件。
符合條件的有 3 個。因此：

P(你拿橘色且朋友不拿紅色)=3/20​（也可寫成 0.15 或 15%）
