a.
哪個是自變數？哪個是應變數？

=> 自變數（Independent Variable）：溫度（Temperature）→ 由研究者控制或觀察的條件

=> 應變數（Dependent Variable）：每秒鳴叫次數（Chirps per second）→ 隨溫度變化而改變的結果


b. 畫出散佈圖並描述關係

在繪製函數圖時，自變數溫度通常位於X 軸（橫軸），應變數蟋蟀鳴叫則位於Y 軸（縱軸）。這表示隨著X 的變化，Y 的值會跟著改變。溫度越高，蟋蟀鳴叫越頻繁
判斷Sxy=Sum(Xi-x bar)(Yi-y bar)/n-1=6.96>0 這代表：溫度上升時，鳴叫次數也上升，所以這是線性正相關
