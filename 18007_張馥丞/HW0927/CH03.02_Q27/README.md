a. 哪個是自變數？哪個是應變數？

=> 自變數（Independent Variable）：樓層數（Floors）→ 由研究者控制或觀察的條件

=> 應變數（Dependent Variable）：高度（Height, m）→ 隨樓層變化而改變的結果

因為樓層數是建築設計的決定因素，而高度是由樓層數推導出來的結果。

b. 計算相關係數 r r=Sxy/Sx Sy
r≈0.956
這表示高度與樓層數有 非常強烈的正相關（樓層越多，高度越高）。
