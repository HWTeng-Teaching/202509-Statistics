有一位學生被問了四個「是 / 否」的問題：
你是否有 Facebook、Twitter、Instagram 和 Snapchat 帳號？

數學上的解釋與計算
每個問題只有兩種答案（Yes / No），總共有 4 個問題。
因此，可能的組合數為：2的4次方等於16

樹狀圖架構
第一層：Facebook → Y 或 N
第二層：Twitter → Y 或 N
第三層：Instagram → Y 或 N
第四層：Snapchat → Y 或 N
每條路徑就是一個「單一事件」所有 16 種事件

編號	回答組合（Facebook, Twitter, Instagram, Snapchat）
1	  Y Y Y Y

2  	Y Y Y N

3	  Y Y N Y

4  	Y Y N N

5  	Y N Y Y

6	  Y N Y N

7  	Y N N Y

8  	Y N N N

9  	N Y Y Y

10	N Y Y N

11	N Y N Y

12	N Y N N

13	N N Y Y

14	N N Y N

15	N N N Y

16	N N N N
