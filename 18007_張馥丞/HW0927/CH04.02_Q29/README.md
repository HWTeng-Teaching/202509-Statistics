一位老師從他班上的 25 位幼兒園學生中隨機選出 1 位，並記錄該學生的性別以及是否上過幼兒園

a.建立樹狀圖並計算簡單事件數
這個實驗包含兩個變數：性別：男孩（Male）、女孩（Female）
是否上過幼兒園：上過（Preschool）、沒上過（No Preschool）
每個性別都可能對應兩種幼兒園經歷，因此樹狀圖會有以下分支：
簡單事件數：4 個 （男孩+上過、男孩+沒上過、女孩+上過、女孩+沒上過）

c. 隨機選到男孩的機率是多少？
男孩總人數：8（上過） + 6（沒上過） = 14 人 機率：14 / 25 = 0.56

d. 隨機選到「沒上過幼兒園的女孩」的機率是多少？
沒上過幼兒園的女孩人數：2 人 機率：2 / 25 = 0.08
