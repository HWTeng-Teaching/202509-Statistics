要用「表格（table）」的方式呈現所有可能的結果（樣本空間）
這種表格稱為 table of outcomes，常用在兩個變數同時發生的情況，例如：
擲兩顆骰子，拋兩枚硬幣
一個變數代表「你」的結果，另一個代表「朋友」的結果
關於記錄一個人的性別和髮色，屬於典型的分類資料（categorical data）問題。我們可以用「結果表格（Table of Outcomes）」來列出所有可能的簡單事件。
假設性別只有兩種：男性（Male） 和 女性（Female） 髮色有五種：金髮（Blonde）、棕髮（Brown）、黑髮（Black）、紅髮（Red）、其他（Other）
