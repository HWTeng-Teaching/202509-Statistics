手機禮儀（Cell Phone Etiquette）
《今日美國》的調查顯示，51% 的美國人認為一般人在使用手機講話時不太顧及他人感受。 假設隨機抽取 100 位美國人，請計算：有 60 位或以上的人表示「不太顧及他人」的機率是多少？
這是一個典型的 二項分布近似常態分布 的問題：

已知條件 n=100,p=0.51; 要計算 P(x ≥ 60)

令 X = 表示「認為不太體貼」的人數。

則 X∼Binomial(n=100,p=0.51)

(1)計算平均數與標準差

μ = np =100(0.51)=51


<img width="360" height="38" alt="image" src="https://github.com/user-attachments/assets/0e3be415-b265-45a1-b5c8-7703702588b2" />

(2)用常態分配近似二項分配
由於 n 大且 p 不極端，可用常態近似：
X∼N(μ=51,σ=5)
要算：P(x ≥ 60) 使用 連續性校正 (continuity correction)：連續性校正 (continuity correction) 是在用連續分配（例如常態分配 Normal distribution）去近似離散分配（例如二項分配 Binomial distribution 或超幾何分配）時，用來改善近似誤差的一種調整方法。
因為：離散分配只能取整數值（如 0, 1, 2, …）

常態分配是連續的，可以取任意實數

為了讓常態分配更好地近似離散分配的機率，我們在界限上加上 ±0.5 的修正。

P(X≥60)≈P(Y≥59.5)

(3)標準化

z=(59.5-51)/5=8.5/5=1.7

(4)查標準常態表

P(Z>1.7)=1− P(Z<1.7)=1−0.9554=0.0446

結果：P(X≥60)≈0.045 常態近似二項分布

(5)結論

有 60 人或更多人覺得「講手機的人不太體貼」的機率約 4.5%。

由於此機率低於 5%，可視為一個罕見事件。
