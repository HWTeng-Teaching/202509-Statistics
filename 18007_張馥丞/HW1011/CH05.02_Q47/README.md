a.這個隨機變數 x 是否符合二項分布？若是，請給出 n 和 p 的值。
是的，因為符合二項分布的四個條件：每一顆種子都是一次獨立試驗
每次試驗只有兩種結果：紅色花瓣（成功）或條紋花瓣（失敗）
成功的機率固定為 p=0.75
試驗次數固定為 n=10
所以：n=10; p=0.75

b. 計算 P(x≥9)：至少有 9 株紅色花瓣的機率
這是二項分布的累積機率問題：P(x≥9)=P(x=9)+P(x=10)
使用二項公式：

計算如下：
P(x=9)=10*0.0751*0.25 ≈ 0.1878
P(x=10)=1*0.0563*1 ≈ 0.0563
0.1878+0.0563=0.2441

c. 計算 P(x≤1)：最多只有 1 株紅色花瓣的機率
P(x≤1)=P(x=0)+P(x=1)
P(x=0)=1*1*0.000000954 ≈ 0.000000954
P(x=1)=10*0.75*0.00000381 ≈ 0.00002858
0.000000954+0.00002858=0.0000295

d. 若實驗結果為 1 株紅色花瓣、9 株條紋花瓣，是否屬於「不尋常」？可得出什麼結論？
根據統計學的慣例，若某事件的機率低於 0.05，則可視為「不尋常」。
P(x=1) ≈ 0.0000285，遠低於 0.05 → ✅ 不尋常
若實驗結果真的是 1 株紅色花瓣、9 株條紋花瓣，這與預期的 p=0.75 明顯不符。
可能的原因包括：原本的遺傳機率估計錯誤（實際 p 可能較低）
種子樣本不具代表性
實驗過程有誤或環境因素影響
