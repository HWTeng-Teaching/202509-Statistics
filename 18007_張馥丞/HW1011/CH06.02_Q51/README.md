美國男性的身高呈常態分布，平均值（μ）為 176.5 公分，標準差（σ）為 8.9 公分。唐納·川普總統的身高為 1.88 公尺。這個身高是否「不尋常」？
我們要判斷某個數值是否「不尋常」，通常會看它是否落在平均值 ±2 個標準差之外。也可以用 Z 分數來判斷。

步驟一：單位換算
川普的身高是：1.88 公尺=188 公分

步驟二：計算 Z 分數
Z 分數公式如下：

Z= x−μ /σ
μ為平均數   σ為標準差
代入數值：
Z= 188 − 176.5 / 8.9 = 11.5 / 8.9  ≈  1.29

步驟三：判斷是否「不尋常」

根據統計慣例：若 Z 分數超過 ±2，通常被視為「罕見事件」（機率 < 5%）

若 Z 分數 > 2 或 < -2，則屬於「不尋常」

Z = 1.29 落在 ±2 之內 → ✅ 不屬於不尋常

Z = 1.29 對應的累積機率約為 0.9015（即 90.15% 的人身高低於 188 公分）

這表示：約 9.85% 的美國男性身高高於 188 公分

雖然偏高，但不算罕見

結論：川普的身高 188 公分雖然高於平均，但 不屬於統計上的「不尋常」。

他大約比平均高出 1.29 個標準差，屬於偏高但仍在合理範圍內。
