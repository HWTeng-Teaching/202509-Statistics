a.列出樣本空間 S 並為每個事件指定機率
我們有 4 把鑰匙：K1,K2,K3,K4
可能的鑰匙嘗試順序共有 4!=24 種，每種順序的機率相同：
P(每個事件)=1/24

b. 定義隨機變數 x
令
x=找到能開門的鑰匙所需嘗試的次數
因此 x=1,2,3,4
我們要找：p(x)=P(X=x)

c. 計算 p(x)
由於每一種順序等可能：
X=1：正確鑰匙在第一個位置。			
→ 機率 = 1/4​			
			
X=2：正確鑰匙在第二個位置。			
→ 機率 = 1/4			
			
X=3：正確鑰匙在第三個位置。			
→ 機率 = 1/4			
			
X=4：正確鑰匙在第四個位置。			
→ 機率 = 1/4
