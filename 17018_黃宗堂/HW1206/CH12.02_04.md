# 簡單線性迴歸變異數分析 (ANOVA) 填空解題

這兩題是關於簡單線性迴歸 (Simple Linear Regression) 的 ANOVA 表格填空。在簡單線性迴歸中，我們有以下幾個關鍵關係：

1.  **自由度 (Degrees of Freedom, $df$):**
    * $df_{Regression} = 1$ (因為只有一個自變數)
    * $df_{Total} = n - 1$
    * $df_{Error} = df_{Total} - df_{Regression}$
2.  **平方和 (Sum of Squares, $SS$):**
    * $SS_{Total} = SS_{Regression} + SS_{Error}$
3.  **均方 (Mean Square, $MS$):**
    * $MS = SS / df$

---

## 第 4 題 (Exercise 4)

**已知數據：**
* $SS_{Regression} = 4.3$
* $df_{Total} = 19$
* $SS_{Total} = 12.5$

**計算步驟：**
1.  **找出 $df$：**
    * 因為是簡單線性迴歸，**$df_{Regression} = 1$**。
    * $df_{Error} = df_{Total} - df_{Regression} = 19 - 1 = \mathbf{18}$。
2.  **找出 $SS$：**
    * $SS_{Error} = SS_{Total} - SS_{Regression} = 12.5 - 4.3 = \mathbf{8.2}$。
3.  **找出 $MS$：**
    * $MS_{Regression} = SS_{Regression} / df_{Regression} = 4.3 / 1 = \mathbf{4.3}$。
    * $MS_{Error} = SS_{Error} / df_{Error} = 8.2 / 18 \approx \mathbf{0.456}$ (取小數點後三位)。

### 填空後的表格 (Table 4)

| Source | $df$ | SS | MS |
| :--- | :---: | :---: | :---: |
| Regression | **1** | 4.3 | **4.3** |
| Error | **18** | **8.2** | **0.456** |
| Total | 19 | 12.5 | |

## 第 5 題 (Exercise 5)

**已知數據：**
* $SS_{Regression} = 3$
* $df_{Error} = 14$
* $MS_{Error} = 2$

**計算步驟：**
1.  **找出 $df$：**
    * 因為是簡單線性迴歸，**$df_{Regression} = 1$**。
    * $df_{Total} = df_{Regression} + df_{Error} = 1 + 14 = \mathbf{15}$。
2.  **找出 $SS$：**
    * 利用 $MS$ 公式回推 $SS_{Error}$：
        * $MS_{Error} = SS_{Error} / df_{Error} \Rightarrow 2 = SS_{Error} / 14$
        * $SS_{Error} = 2 \times 14 = \mathbf{28}$。
    * $SS_{Total} = SS_{Regression} + SS_{Error} = 3 + 28 = \mathbf{31}$。
3.  **找出 $MS$：**
    * $MS_{Regression} = SS_{Regression} / df_{Regression} = 3 / 1 = \mathbf{3}$。

### 填空後的表格 (Table 5)

| Source | $df$ | SS | MS |
| :--- | :---: | :---: | :---: |
| Regression | **1** | 3 | **3** |
| Error | 14 | **28** | 2 |
| Total | **15** | **31** | |
