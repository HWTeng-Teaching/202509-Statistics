# 第 13 題：Sleep Deprivation (睡眠剝奪研究) 分析

**題目數據摘要：**
* **受試者人數 ($n$):** 10 (題目說明 "Ten subjects participated")
* **變數:**
    * $y$: Number of Errors (錯誤數量)
    * $x$: Hours without Sleep (無睡眠時數)
* **提供的 ANOVA 資訊:**
    * Regression SS = 72.2
    * Residual MS = 5.025
    * Regression F = 14.368
    * Coefficients: Intercept = 3, Slope ($x$) = 0.475

---

## a. 實驗中有多少對觀測值？ (How many pairs?)

根據題目描述 "Ten subjects participated in the study"，共有 **10** 對觀測值 ($n=10$)。

## b. 總自由度是多少？ (Total degrees of freedom?)

總自由度 ($df_{Total}$) 的計算公式為 $n - 1$。
$$df_{Total} = 10 - 1 = \mathbf{9}$$

## c. 完成 MS Excel 的 ANOVA 表格 (Complete the printout)

我們需要填補表格中標示為 `**` 的數值。

1.  **自由度 (df):**
    * **Regression (迴歸):** 簡單線性迴歸只有一個自變數，故 $df_{Regression} = \mathbf{1}$。
    * **Residual (殘差/誤差):** $df_{Residual} = n - 2 = 10 - 2 = \mathbf{8}$。
    * **Total (總和):** $df_{Total} = 9$ (如 b 小題所得)。
2.  **平方和 (SS):**
    * **Residual SS:** 利用 $MS = SS / df$ 推算。
        $$SS_{Residual} = MS_{Residual} \times df_{Residual} = 5.025 \times 8 = \mathbf{40.2}$$
    * **Total SS:** $SS_{Total} = SS_{Regression} + SS_{Residual}$。
        $$SS_{Total} = 72.2 + 40.2 = \mathbf{112.4}$$

### 填補後的 ANOVA 表格

| Source | df | SS | MS | F | Significance F |
| :--- | :---: | :---: | :---: | :---: | :---: |
| Regression | **1** | 72.2 | 72.2 | 14.368 | 0.0053 |
| Residual | **8** | **40.2** | 5.025 | | |
| Total | **9** | **112.4** | | | |

## d. 最小平方法預測方程式為何？ (Prediction equation)

根據提供的係數表 (Coefficients table)：
* Intercept (截距, $b_0$) Coefficients = 3
* x (斜率, $b_1$) Coefficients = 0.475

預測方程式為：
$$\hat{y} = 3 + 0.475x$$

## e. 預測 10 小時未睡眠的人會犯多少錯誤？

將 $x = 10$ 代入方程式：
$$\hat{y} = 3 + 0.475(10)$$
$$\hat{y} = 3 + 4.75 = \mathbf{7.75}$$

**預測結果：** 預計會犯 7.75 個錯誤。
